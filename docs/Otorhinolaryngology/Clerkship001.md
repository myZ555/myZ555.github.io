# 耳鼻咽喉头颈解剖生理_总论_（摘录）

## 耳科

### 声音传入内耳的两条途径

1. **空气传导途径**：声波-外耳道-鼓膜振动-听骨链机械放大-镫骨足板振动前庭窗-外淋巴液波动-基底膜行波-毛细胞换能-听神经放电【日常听觉的主要通路】
2. **骨传导途径**：声波直接振动颅骨-内耳骨迷路振动-外淋巴液波动-基底膜振动-毛细胞兴奋；绕过外耳与中耳，在气导通路受损时仍可维持部分听力
3. **气骨导差（ABG）**：骨导阈值反映耳蜗功能；气导阈值反映整个传导通路功能。气导-骨导差值≥10dB提示存在传导性听力损失成分
4. *Rinne试验*：正常和感音神经性聋时气导优于骨导（Rinne阳性），传导性聋时骨导优于气导（Rinne阴性）。是床旁听力评估的快速方法。

### 耳痛与耳漏

1. ==耳源性耳痛Otogenic==：急性外耳道炎牵拉耳廓或挤压耳屏时疼痛加剧（区别于中耳炎），急性化脓性中耳鼓膜穿孔前为深部搏动性剧痛，穿孔后因压力释放疼痛骤减。检查可见鼓膜充血、膨隆或穿孔表现。
2. ==牵涉性耳痛Referred==：三叉神经（牙痛、颞下颌关节）、舌咽神经（扁桃体炎、咽部肿瘤）、迷走神经（喉部病变）、颈丛（颈椎病变）均可放射至耳部。不明原因耳痛需系统排查上述区域，必要时行影像学检查。
3. ==浆液性耳漏Serous==：淡黄色清亮液体，见于分泌性中耳炎（鼓室积液经鼓膜穿孔或置管流出），也可见于脑脊液耳漏。后者须检查β2-转铁蛋白确诊，常提示颅底骨折，属于神经外科急症。
4. ==黏脓性/脓性耳漏Purulent==：黏脓性耳漏见于慢性单纯型化脓性中耳炎（无臭味、间歇性发作），脓性耳漏伴恶臭高度提示**胆脂瘤性中耳炎**。角化物质分解产生特殊臭味，可伴有听力下降，需尽早手术干预。

### 耳聋的分类体系与耳鸣的诊断提示

| 类型         | 病变部位           | 听力学特征                   | 常见病因                     |
| ------------ | ------------------ | ---------------------------- | ---------------------------- |
| 传导性聋     | 外耳、中耳         | 气骨导差≥10dB，骨导正常      | 耵聍栓塞、中耳炎、耳硬化症   |
| 感音神经性聋 | 内耳、听神经、中枢 | 气导骨导同步下降，无气骨导差 | 噪声性聋、老年性聋、突发性聋 |
| 混合性聋     | 传导+感音双重病变  | 气骨导差≥10dB且骨导也下降    | 慢性中耳炎合并耳蜗损伤       |

- 听神经瘤预警：单侧进行性高频耳鸣伴不对称听力下降，需行内听道MRI排除听神经瘤
- 突发性聋治疗窗口：72小时内启动糖皮质激素治疗

## 咽喉头颈

### 咽壁层次结构与咽肌功能

1. 咽壁四层结构：（由内向外）黏膜层、纤维层（咽腱膜）、肌层、外膜层。*纤维层*为咽壁提供结构支撑。*黏膜层*分泌黏液润滑食物通道。
2. **咽缩肌组**：包括上中下三对咽缩肌，自上而下依次收缩产生蠕动波，将食团推送入食管--吞咽动力的主要来源
3. **咽提肌组**：包括茎突咽肌、腭咽肌和咽鼓管咽肌。吞咽时上提咽部与喉部，协助会厌关闭喉口，防止食物误入气道，确保呼吸安全。
4. **腭帆肌组**：包括腭帆张肌和腭帆提肌。负责上提软腭封闭鼻咽通道，防止吞咽时食物和液体反流入鼻腔，维持鼻腔清洁。

### 声嘶常见原因与临床鉴别

- 急性喉炎导致声带充血水肿，是最常见的暂时性声嘶原因。通常1-2周内恢复
- 声带小结与息肉是慢性声嘶的常见原因。多见于用声过度人群。
- 喉癌预警：40岁以上吸烟者持续声嘶超过2周必须行喉镜检查排除喉癌
- 喉返神经损伤致声带麻痹，常见于甲状腺、食管癌及胸部术后。

### 喉源性呼吸困难的分类与分度

1. 吸气性呼吸困难：吸气时出现三凹征--胸骨上窝、锁骨上窝、肋间隙凹陷，是喉源性呼吸困难的特征性表现
2. 喉梗阻四度分度：一度活动后出现；二度安静时也有；三度烦躁发绀；四度昏迷需紧急抢救
3. 常见病因：先天性喉畸形、急性会厌炎、喉外伤、喉神经性疾病、喉水肿及喉肿瘤等
4. 急性会厌炎：起病急骤、进展迅速，可在数小时内从咽痛发展为完全性喉梗阻。耳鼻喉科最凶险的急症。

## 鼻科

### 各鼻窦炎的脓涕流向与头痛特点

| 鼻窦       | 脓涕特点                       | 头痛部位与特点                     | 鼻腔检查所见         |
| ---------- | ------------------------------ | ---------------------------------- | -------------------- |
| 上颌窦炎   | 脓涕多从前鼻孔擤出，量较多     | 面颊部或上颌磨牙区钝痛，午后加重   | 中鼻道后段脓涕       |
| 前组筛窦炎 | 脓涕量中等，可从前后鼻孔排出   | 鼻根部、内眦部钝痛或胀痛           | 中鼻道前段脓涕       |
| 额窦炎     | 脓涕量较少，晨起较多           | 前额部周期性疼痛，晨起重，午后减轻 | 中鼻道前端脓涕       |
| 蝶窦炎     | 脓涕多流向鼻咽部，常诉“涕倒流” | 头顶或枕部深部钝痛，定位不明确     | 嗅裂或上鼻道后部脓涕 |

### 鼻塞的鉴别诊断思路

| 鼻塞类型   | 临床体征                     | 常见病因                                     |
| ---------- | ---------------------------- | -------------------------------------------- |
| 单侧持续性 | 固定一侧鼻塞，进行性加重     | 鼻中隔偏曲、鼻腔肿瘤、鼻腔异物、后鼻孔息肉   |
| 双侧交替性 | 左右交替，侧卧时下侧加重     | 生理性鼻周期、血管运动性鼻炎、慢性单纯性鼻炎 |
| 双侧持续性 | 双侧鼻塞，持续不缓解         | 慢性肥厚性鼻炎、鼻息肉、腺样体肥大（儿童）   |
| 发作性     | 突发突止，伴喷嚏流清涕       | 变应性鼻炎、嗜酸性粒细胞增多性非变应性鼻炎   |
| 新生儿鼻塞 | 出生后即有张口呼吸、喂养困难 | 先天性后鼻孔闭锁（需紧急处理）               |

### 鼻漏（鼻涕）的性质与疾病关联

1. **水样鼻涕**：量多，清亮如水；见于变应性鼻炎（伴喷嚏、鼻痒）和急性鼻炎早期；单侧大量清水样需检测*β2-转铁蛋白*排除脑脊液鼻漏
2. **黏液性鼻涕**：黏稠透明或白色，见于慢性鼻炎和血管运动性鼻炎，*黏液腺分泌亢进*是主要机制
3. **黏脓性/脓性鼻涕**：黄绿色黏稠，是*鼻窦炎*的典型表现；脓涕有恶臭提示牙源性上颌窦炎、鼻腔异物或萎缩性鼻炎
4. **血性鼻涕**：可为鼻腔干燥糜烂、外伤或鼻腔手术后；单侧反复血涕需警惕鼻腔鼻窦*恶性肿瘤*
