# 气管/食管/头颈外科学

## 气管、食管解剖生理

### （一）气管、支气管

1. **气管（trachea）：**上与环状软骨相连，下于 **T5** 水平分为左右主支气管，随后再分为叶、段支气管。

	- 颈部气管：前有**胸骨舌骨肌、胸骨甲状肌**；第 2-4 气管环前有**甲状腺峡部**越过。

	- **“安全三角区”：**以胸骨上窝为顶，两侧胸锁乳突肌前缘为边。

	- 胸部气管：**气管隆嵴（carina）**位于 **T5** 水平，是左右主支气管的分界，**右主支气管**短而直，易入异物。

2. 气管壁：黏膜层、黏膜下层、纤维软骨环、外膜。

5. ##### 血供：主要来自**甲状腺下动脉**，回流至**甲状腺下静脉**，颈部气管前面有丰富的血管网。

### （二）食管

1. **食管（esophagus）：**环状软骨下缘~贲门，**C6~C10/11**。4 个生理狭窄：
	1. **入口：最狭窄，16 cm。**
	2. **主动脉弓：23 cm。**
	3. **左主支气管：27 cm。**
	4. **穿横膈裂孔处：40 cm。**
2. 食管管壁：黏膜层、黏膜下层、肌层、外膜层。
3. 血供：来自**甲状腺下动脉、锁骨下动脉**；回流入甲状腺下静脉、奇静脉、门静脉。

## 气管、支气管异物

1. **临床表现：幼儿**好发。

2. 分期：

	1. **异物吸入期：剧烈呛咳、呼吸困难、发绀，甚至窒息。**
	2. **安静期：只有轻微咳嗽，无其他症状。**
	3. **炎症期：咳嗽、肺不张、肺气肿等。**
	4. **并发症期：肺炎、肺脓肿、脓胸等。**

3. **喉异物：吸气性呼吸困难**甚至**窒息**伴**刺激性咳嗽**，可继发感染、变态反应，或咯血、皮下气肿。

4. **气管异物：剧烈呛咳、憋气、呼吸不畅、刺激性咳嗽**，异物在声门、支气管间运动可闻及**拍击音**。

5. **支气管异物：咳喘、发热**，可继发肺气肿、肺不张、支气管肺炎等。

6. 诊断：**异物吸入史**是最重要的诊断依据。

	1. 体检：活动性气管异物可在呼气末或咳嗽时闻及**声门拍击声**，伴颈部**撞击感**。注意继发病变体征。
	2. X 线：金属类异物可用胸部正侧位片诊断。胸透可发现**纵膈摆动（见于气管异物阻塞一侧支气管）**。
	3. 胸部CT：适用于异物吸入史不详、迁延性肺炎原因不明、胸片阴性者而临床怀疑者。
	4. ==支气管镜检查：金标准==。

7. 治疗：手术取出异物是唯一的方法，建议**全麻**下进行。

	| **直接喉镜取出**     | **喉前庭、声门区、声门下区、总气管**内异物                   |
	| -------------------- | ------------------------------------------------------------ |
	| **支气管镜取出**     | **气管、支气管**异物等                                       |
	| **经气管切开口取出** | 呼吸困难，**病情危急**；**异物较大或形状特殊**；已有明显**炎症**者 |
	| **经纤支镜取出**     | 更深的细支气管、硬镜无法插入                                 |
	| **开胸取出**         | **内镜无法取出**，已导致**支扩、肺脓肿**等                   |

8. 并发症：

	1. **气胸、纵隔气肿、皮下气肿：**暂停取出异物，**胸腔闭式引流**。
	2. 气管内出血：气管内注入 1:1000 肾上腺素。
	3. **急性呼衰：**置入喉镜前，**1%利多卡因喷喉**、选择**全麻**可预防。
	4. **肺炎、肺不张：**异物取出后抗生素治疗。

## 食管异物

1. **临床表现：吞咽困难**（异物位于环后隙、食管入口）**、吞咽疼痛、呼吸道症状**（呼吸困难甚至窒息）。
2. 诊断：**异物吸入史**+间接喉镜（食管上段）、**影像学（X 线、CT）+食管镜**。 **禁用钡餐造影！**
3. 并发症：**损伤性食管炎、食管穿孔、颈部皮下气肿、纵隔气肿、食管周围炎、颈间隙感染、纵隔炎、大血管破溃**（食管中段异物→主动脉弓/锁骨下动脉）**、气管食管瘘**（导致肺部反复感染）。
4. 治疗：**食管镜**/纤维食管镜下取出，或**颈侧切开/开胸取出（巨大异物、嵌顿、带金属钩、累及大动脉）**。

## 食管腐蚀伤*

**食管腐蚀伤（caustic injuries of esophagus）：**腐蚀剂引起食管黏膜损害。**碱性腐蚀剂穿透力比酸性强**。

- 病理：1 度（轻型）局限于食管黏膜，2 度（中度）深达肌层，3 度（重度）累及食管全层。

1. **临床表现：**
	1. **急性期（1~2 周）：疼痛、吞咽困难、声嘶/呼吸困难**、全身症状（发热、脱水、休克等）。
	2. **缓解期（1~2 周后）：**疼痛、吞咽困难缓解，饮食逐渐恢复。**轻者 2~3 周愈合**。
	3. **狭窄期（3~4 周后）：**病变累及肌层者，瘢痕挛缩，再度出现**进行性吞咽困难**。
2. 诊断：口腔/口咽黏膜、**X 线**（**急性期后**才可进行钡餐或碘油造影）**、食管镜**（**伤后 _2_ 周**才可检查）。
3. 治疗：
	1. 急性期：应用**中和剂**（**禁用苏打水！**）**、抗生素、糖皮质激素**、止痛、镇静、抗休克，喉阻塞症状严重时时**气管切开术**。
	2. 缓解期：继续应用**抗生素、糖皮质激素**，**急性期过后**才可进行**钡餐/碘油造影、食管镜**。
	3. 瘢痕期：食管瘢痕狭窄者，进行**食管镜下探条扩张术、吞线扩张术、支架扩张术、外科手术**等。

## 颈部应用解剖

1. **颈部肌肉：**胸锁乳突肌、舌骨上肌群、舌骨下肌群、颈深肌群（内侧-头/颈长肌、外侧-斜角肌）。
	1. **舌骨上肌群：**二腹肌、下颌舌骨肌、颏舌骨肌、茎突舌骨肌。
	2. **舌骨下肌群：**胸骨舌骨肌、胸骨甲状肌、甲状舌骨肌、肩胛舌骨肌。

2. **分部：**颈部两侧斜方肌前缘以前的部分称**颈前外侧部**，以后的部分称颈后部又叫**项部**。
	1. **以胸锁乳突肌为标志分：**颈前区（颈前三角区）、胸锁乳突肌区、颈外侧区（颈后三角区）。
	2. **颌下三角：**下颌骨下缘与二腹肌前、后腹间。
	3. **颏下三角：**两侧二腹肌前腹与舌骨体间。
	4. **颈动脉三角：**胸锁乳突肌上部前缘、肩胛舌骨肌上腹与二腹肌后腹间。
	5. **肌三角：**颈前中线、胸锁乳突肌前缘与肩胛舌骨肌上腹间。
	6. **锁骨上三角：**胸锁乳突肌后缘、肩胛舌骨肌下腹和锁骨间。
	7. **枕三角：**胸锁乳突肌后缘、斜方肌前缘与肩胛舌骨肌下腹间。
	8. **胸锁乳突肌区：**深面有**颈动脉鞘**，内含颈总动脉、颈内动脉、颈内静脉和迷走神经。
