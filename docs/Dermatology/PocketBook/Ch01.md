# 总论

### （一）皮肤的结构与功能

**皮肤（skin）：**由**表皮、真皮、皮下组织**构成。 皮肤的附属器官：**毛发、皮脂腺、汗腺、甲**。

##### 表皮（epidermis）：主要由角质形成细胞、黑素细胞、Langerhans 细胞、Merkel 细胞组成。

1. 角质形成细胞

	| **基底层（stratum basale）**     | 1 层立方形或圆柱状细胞，基底部借**半桥粒**与基底膜附着，**更替时间 28d** |
	| -------------------------------- | ------------------------------------------------------------ |
	| **棘层（stratum spinosum）**     | 4~8 层的多角型细胞，相邻细胞间以**桥粒**相连接               |
	| **颗粒层（stratum granulosum）** | 1~10 层梭形或扁平细胞构成，富含**透明角质颗粒，细胞核、细胞器溶解** |
	| **透明层（stratum lucidum）**    | 仅见于**表皮较厚的部位（掌跖）**，2~3 层扁平细胞构成         |

2. **黑素细胞（melanocyte）：**起源于外胚层，位于**基底层、毛囊**，电镜下可见黑素小体（melanosome）。

3. **Langerhans 细胞：**起源于**单核-巨噬细胞**，多位于基底层以上、毛囊上皮，特征性的 Birkeck 颗粒。

4. **Merkel 细胞：**分布于基底层细胞之间，含神经内分泌颗粒，可能具有**非神经末梢介导的感觉功能**。

5. 细胞连接：

	| 细胞连接                    | 功能                                                         |
	| --------------------------- | ------------------------------------------------------------ |
	| **桥粒（desmosome）**       | **主要**，由相邻细胞的细胞膜发生的卵圆形致密增厚构成，**抗牵张**功能<br />**桥粒破坏：**角质形成细胞之间相互分离，形成**表皮内水疱或大疱** |
	| **半桥粒（hemidesmosome）** | **基底层细胞与基地膜带**之间的主要连接结构，结构类似半个桥粒 |
	| **基底膜带（BMZ）**         | 由胞膜层、透明层、致密层、致密下层组成，具有**渗透、屏障**作用 |

	

##### 真皮（dermis）：分为浅层的乳头层（papillary layer）和深层的网状层（reticular layer）。

1. **胶原纤维（collagen fiber）：**含量最丰富，主要成分为 I 型胶原，韧性好、弹性差。
2. **网状纤维（reticular fibers）：**未成熟的胶原纤维，主要成分为 III 型胶原。
3. **弹力纤维（elastic fibers）：**波浪状、交织成网，弹性好。
4. **基质（matrix）：**无定形物质，主要成分为**蛋白多糖**，形成微孔隙分子筛立体构型。
5. 细胞：包括**成纤维细胞、肥大细胞**、巨噬细胞、Langerhans 细胞、噬色素细胞和少量淋巴细胞。

##### 皮下组织（subcutaneous tissue）：由疏松结缔组织、脂肪小叶构成，含血管、淋巴管、神经、汗腺。

1. **皮肤的附属器：**
1. **毛发（hair）：**毛囊（hair follicle）、毛球（hair bulb）、毛乳头（hair papilla）。
1. **毛发的生长周期：**生长期（anagen）~3 年、退行期（catagen）~3 周、休止期（telogen）~3 月。
2. **皮脂腺（sebaceous glands）：**分布广泛，由腺泡和导管构成，一个皮脂腺与一个毛囊相连。
3. **小汗腺（eccrine glands）：**位于真皮深部、皮下组织，遍布全身，**交感神经支配（ACh）**。
4. **顶泌汗腺（apocrine glands）：**位于皮下脂肪，位于腋窝、乳晕、肛周、会阴等，**交感神经支配（NE）**。
5. **甲（nail）：**甲板、甲半月、甲廓、甲根、甲床、甲母质。生长速度：指甲 1cm/3 月、趾甲 1cm/9 月。
2. **皮肤的屏障功能：**物理性损伤（缓冲、吸收光线）、化学性刺激（皮脂膜、角蛋白）、微生物防御（细胞排列紧密、广谱抑菌作用、角质脱落、共生菌）、防止营养物质丢失（半透膜功能，不显性出汗）。
3. **影响皮肤的吸收功能的因素：**部位（**阴囊>前额>大腿屈侧>上臂屈侧>前壁>掌跖**）、角质层的水合程度、被吸收物的理化性质（**脂溶性**容易吸收）、环境温度、环境湿度、病理情况。
4. **皮肤的分泌、排泄功能：**小汗腺、顶泌汗腺、皮脂腺。
5. **皮肤的免疫功能：**包括获得性免疫（特异性免疫）和天然性免疫（非特异性免疫）。
6. **其他：**感觉功能、体温调节功能（出汗、血管收舒）、代谢功能（糖、蛋白质、脂类、水和电解质）。

### （二）皮肤病的临床表现

#### 局部症状：

|**瘙痒**|常见于**荨麻疹、慢性单纯性苔藓、湿疹、疥疮**，恶性肿瘤、糖尿病、肝肾功能不全也可发生|
|---|---|
|**疼痛**|常见于**带状疱疹、疖肿、结节性红斑、淋病、生殖器疱疹**|
|**麻木**|见于**麻风病**|

##### **原发性皮损（primary lesion）：**

|**☆皮损**|**机制**|**临床表现**||**常见于**|
|---|---|---|---|---|
|**斑疹（macule）**|红斑（炎性/非炎性）、出血斑、|皮肤黏膜局限性**色素**|**≤1cm**|**丹毒**、鲜红斑痣、黄褐|

|**丘疹（papule）**|表皮/真皮浅层细胞增殖、代谢产物积聚、炎症细胞浸润|局限性、实质性的**表浅隆起型**皮损，直接**≤1cm**<br><br>*斑丘疹、丘疱疹、丘脓疱疹| |**疣**、扁平苔藓、色素痣、**银屑病、皮炎湿疹**|
|**斑块（plaque）**|丘疹扩大或融合|局限性、实质性的**表浅隆起型**<br><br>皮损，直接**>1cm**| |**银屑病**|
|**风团（wheal）**|真皮浅层水肿|**暂时性、隆起型**皮损，伴**瘙痒**<br><br>**发生快、此起彼伏、不留痕迹**| |**荨麻疹**|
|**水疱（vesicle）**|发生于角质层（壁薄）、棘层|局限性、隆起型、**内含**|**≤1cm**|白痱、**水痘、带状疱疹**、|
|**大疱（bulla）**|（壁稍厚）、表皮下（壁很厚）|**液体的腔隙性皮损**|**>1cm**|大疱性类天疱疮|

|**囊肿（cyst）**|发生于真皮或更深位置|具有**囊腔结构**，内含液体/细胞| |皮脂腺囊肿、表皮囊肿|

##### 继发性皮损（secondary lesion）：

|**皮损**|**临床表现**|**常见于**|
|---|---|---|
|**糜烂（erosion）**|局限性表皮或黏膜**上皮缺损**形成**红色湿润**创面<br><br>愈后一般**不留瘢痕**|**水疱、脓疱**破裂，**浸渍**处表皮脱落|
|**溃疡（ulcer）**|局限性皮肤或黏膜缺损形成创面，**深达真皮**<br><br>愈后常**遗留疤痕**|感染、损伤、肿瘤、血管炎|
|**鳞屑（scale）**|肉眼可见的**角质堆积**，角化异常所致|**银屑病、花斑糠疹、剥脱性皮炎**|
|**浸渍（maceration）**|角质层**吸收过多水分**而导致表皮**变软变白**|长时间浸水、潮湿部位|
|**裂隙（fissure）**|**线性**的皮肤裂口，**深达真皮**，又称**皲裂**<br><br>好发于掌跖、指、趾、口角|皮炎、角质层增厚、皮肤干燥|
|**萎缩（atrophy）**|表皮萎缩：**皮肤变薄、皮纹消失**，羊皮纸样<br><br>真皮萎缩：**局部皮肤凹陷**，皮纹正常，毛发变细<br><br>皮下组织萎缩：**局部皮肤凹陷**|退行性变|
|**瘢痕（scar）**|增生性：隆起、光滑、无毛发|烧伤、瘢痕疙瘩|
|                                             | 萎缩性：皮肤凹陷、表皮变薄、毛细血管扩张                     |红斑狼疮|
|**痂（crust）**|皮损表面的**液体与脱落组织、药物**混合凝结而成，可呈浆液性、脓性、血性| |
|**抓痕（excoriation）**|**机械性损伤**导致的线状或点状表皮/真皮浅层的剥脱性缺损，预后可遗留疤痕| |
|**苔藓样变**<br><br>**（lichenification）**|反复搔抓、摩擦引起的**皮肤局限性增厚**<br><br>**皮嵴隆起、皮沟加深**、境界清楚，**瘙痒**剧烈|**慢性单纯性苔藓、慢性湿疹**|

1. 体格检查：皮疹性质、大小、数目、颜色、边界、形状、表面、基底、部位及分布。
1. **皮肤划痕征：**皮肤经划写/抓挠后出现条状隆起/发红，可为生理性的体质异常反应或人工型**荨麻疹**。
2. **Nikolsky 征（尼氏征，棘层细胞松解）：**①手指**推压水疱一侧**，可使水疱沿推压方向**移动**；手指**轻压疱顶**，疱液可向四周**移动**；②**稍用力在外观正常皮肤上推擦**，表皮即**剥离**；③**牵扯已破损的水疱壁**时，可见水疱以外的**外观正常皮肤一同剥离**。见于大疱性表皮松解型药疹，金葡菌性烫伤样皮肤综合征、**天疱疮**、大疱性表皮松解症、家族性慢性良性天疱疮等。

### （三）皮肤病的诊断

##### 皮肤病理学：

|**病变**|**病理表现**|**常见于**|
|---|---|---|
|**角化过度（hyperkeratosis）**|角质层增厚|扁平苔藓、掌跖角化病、鱼鳞病|
|**角化不全（parakeratosis）**|角质层残留细胞核，颗粒层变薄/消失|**银屑病**、玫瑰糠疹、汗孔角化症|
|**棘层肥厚（acanthosis）**|棘层增厚，伴表皮突延长/增宽|**银屑病**、慢性皮炎|
|**疣状增生**<br><br>**（verrucous hyperplasia）**|**表皮角化过度、颗粒层增厚、棘层肥**<br><br>**厚、乳头瘤样增生**|**寻常疣**、疣状痣|
|**乳头瘤样增生（papillomatosis）**|**真皮乳头**不规则向上增生|黑棘皮病、皮脂腺痣|
|**细胞内水肿**<br><br>**（intracellular edema）**|**棘层细胞**水肿，体积变大、胞质变淡<br><br>高度水肿：**气球样变性、网状变性**|**病毒性**皮肤病、**接触性皮炎**|
|**细胞间水肿**<br><br>**（intercellular edema）**|**细胞间**液体增多、细胞间隙增宽，又<br><br>称海绵形成，严重时形成表皮内水疱|**皮炎湿疹**|
|**基底细胞液化变性**<br><br>**（liquefaction of basal cells）**|基底细胞空泡化、崩解，棘层与真皮<br><br>接触，常伴真皮内噬黑素细胞浸润|扁平苔藓、**红斑狼疮**|

##### **真菌镜检**

直接涂片、墨汁涂片（隐球菌）、涂片/组织切片染色（革兰染色-白念珠菌、孢子丝菌；瑞氏染色-组织胞浆菌；PAS 染色；荧光染色）、真菌培养。

##### 梅毒螺旋体检查：

1. **非特异性检查：快速血浆反应素环状卡片试验（RPR）**、性病研究实验室试验（V**R**DL）、不加热血清反应素试验（US**R**）、甲苯胺红不需加热血清试验（T**R**UST）。
1. 临床意义：**敏感度高、特异性低**，用于**疗效观察、判断复发/再感染**，**不用于确诊**。
2. **特异性检查：梅毒螺旋体颗粒凝集试验（TPPA）**、梅毒螺旋体血凝试验（TPH**A**）、荧光螺旋体抗体吸收试验（FTA-**A**BS）。
1. 临床意义：用于**确诊**。

1. **醋酸白试验：HPV 感染**的细胞产生异常的角蛋白，能被冰醋酸致白，**尖锐湿疣**皮损醋酸白试验阳性。
2. **斑贴试验：**以适当的浓度、剂型将受试物贴于皮肤，观察是否产生变态反应，用于**接触性皮炎**。
1. 方法：将受试物贴于背部或前壁屈侧健康皮肤，**48 小时**去除斑贴，**间隔 30 分钟**观察结果。
2. 结果：无反应为**阴性(-)**，淡红斑为**可疑(±)**，轻度红斑、浸润、少量丘疹为**阳性(+)**，水肿性红斑、丘疹或水疱为**强阳性(++)**，显著红肿、浸润、聚合性水疱、大疱为**超强阳性(+++)**。
3. **滤过紫外灯（Wood 灯）：**利用 320~400nm 的光波，用于**色素异常性皮肤病、皮肤感染、卟啉病**的诊断。
1. 铁锈色**小孢子菌**、羊毛状**小孢子菌（白癣菌）：亮绿色**荧光。
2. **黄癣菌：暗绿色**。 c) **马拉色菌（花斑癣）：棕色**荧光。

d) 紫色**毛癣菌**、断发**毛癣菌（黑点癣）**：**无**荧光。

### （四）皮肤病的治疗

1. **抗组胺（H1 受体）药物：**对抗组胺引起的毛细血管扩张、血管通透性增高、平滑肌收缩等效应。
2. **①第一代：氯苯那敏、苯海拉明、异丙嗪、酮替芬等；②第二代：氯雷他定、西替利嗪等。**
3. **糖皮质激素：**免疫抑制，抗炎、细胞毒、休克、增生。用于**变应性、自身免疫性、严重感染性**皮肤病。
	1. **不良反应：**轻度-满月脸、向心性肥胖、萎缩纹、皮下出血、痤疮、多毛，严重-糖尿病、高血压、白内障、感染、消化道黏膜损害、肾上腺皮质功能减退、骨质疏松、缺血性骨坏死、神经精神症状。

4. **抗生素：**青霉素类、头孢类、碳青霉烯类、氨基糖苷类、糖肽类、四环素类、大环内酯类、喹诺酮类、磺胺类、抗结核药、抗麻风药、甲硝唑/替硝唑。

5. **抗病毒：**①**核苷类-阿昔洛韦（ACV）**、更昔洛韦、伐昔洛韦、泛昔洛韦，用于 **HSV、VZV** 感染；②**膦甲酸**，用于耐 ACV 的 HSV、VZV 和 CMV 感染；③**阿糖腺苷：**用于 HSV、VZV、CMV、EBV 感染。

6. **抗真菌：**①**特比萘芬**-对**甲**真菌病、**角化过度**型手癣效果好；②**两性霉素 B**-对**深部**真菌效果好；③**制霉菌素**-用于消化道**念珠菌**感染；④**氟胞嘧啶（5-FC）-**用于隐球菌病、念珠菌病、着色真菌病；⑤**酮康唑****-**限外用；⑥**伊曲康唑-**用于甲真菌病、念珠菌病、隐球菌病、孢子丝菌病、着色真菌病、浅部真菌病；⑦**氟康唑-**用于深部真菌感染；⑧**灰黄霉素-**用于**头癣**治疗；⑨**碘化钾-**治疗**孢子丝菌病**。

7. **维 A 酸类药物：**调节上皮细胞生长分化，对一些恶性肿瘤生长有抑制作用，可调节免疫、炎症过程。
	1. 用于痤疮、掌跖角化病、**银屑病**、鱼鳞病、毛囊角化病、皮肤肿瘤。注意**致畸**反应。
8. **免疫抑制剂及调节剂：**环磷酰胺（CTX）、甲氨蝶呤（MTX）、硫唑嘌呤（AZA）、环孢素（CsA）、吗替麦考酚酯/霉酚酸酯（MMF）、干扰素（IFN）、卡介苗（BCG）、转移因子、胸腺肽、静注丙球（IVIg）。
9. 其他：生物之间（单抗）、羟氯喹、雷公藤总苷、钙剂、硫代硫酸钠。

##### 外用药物治疗原则：

1. 急性期皮疹：有渗出者建议使用**溶液湿敷**，无渗出建议使用**粉剂或者洗剂**。
2. 亚急性期皮疹：渗出不多使用**糊剂及油剂**，无糜烂使用**乳剂**。
3. 慢性皮炎：建议使用**乳膏、软膏及硬膏**。

1. 物理治疗：电料、光疗、微波、冷冻、激光、水疗、放疗。
1. 紫外线疗法：适用于玫瑰糠疹、银屑病、斑秃、慢性溃疡、痤疮、毛囊炎、疖病。
2. 激光：手术用于疣、鸡眼、良性肿瘤，理疗用于毛囊炎、接种、甲沟炎、带状疱疹、斑秃、溃疡等。
3. 微波治疗：适用于疣、皮赘、血管瘤、淋巴管瘤、汗管瘤等。
4. 光动力疗法：适用于肿瘤性疾病、病毒疣。
