## (一)皮肤的结构与功能
1. 皮肤skin
	1. 表皮epidermis
	2. 真皮dermis
	3. 皮下组织subcutaneous tissue
2. 皮肤的附属器
	1. 毛发hair
	2. 皮脂腺sebaceous glands
	3. 小汗腺eccrine glands
	4. 顶泌汗腺apocrine glands
	5. 甲nail
3. 皮肤的功能
	1. 屏障功能
	2. 分泌、排泄功能
	3. 免疫功能
	4. 其他: 感觉功能、体温调节功能(出汗、血管收舒)、代谢功能(糖、蛋白质、脂类、水和电解质)
## (二)皮肤病的临床表现
#### 体格检查
1. ==皮肤划痕征==：皮肤经划写/抓挠后出现条状隆起/发红，可为生理性的体质异常反应或人工型荨麻疹。
2. ==Nicolsky征（尼氏征、棘层细胞松解）==
	1) 手指推压水疱一侧，可使水疱沿推压方向移动；手指轻压疱顶，疱液可向四周移动；
	2) 稍用力在外观正常皮肤上推擦，表皮即剥离；
	3) 牵扯已破损的水疱壁时，可见水疱以外的外观正常皮肤一同剥离。
	4) 见于大疱性表皮松解型药疹，金葡菌性烫伤样皮肤 综合征、天疱疮、大疱性表皮松解症、家族性慢性良性天疱疮等。
#### 局部症状
1. **瘙痒**：荨麻疹、慢性单纯性苔藓、湿疹、疥疮，恶性肿瘤、糖尿病、肝肾功能不全也可发生
2. **疼痛**：带状疱疹、疖肿、结节性红斑、淋病、生殖器疱疹
3. **麻木**：麻风病

## (三)皮肤病的诊断
#### 皮肤病理学

| 病变       | 病理表现                             | 常见于            |
| -------- | -------------------------------- | -------------- |
| 角化过度     | 角质层增厚                            | 扁平苔藓、掌跖角化病、鱼鳞病 |
| 角化不全     | 角质层残留细胞核，颗粒层变薄/消失                | 银屑病、玫瑰糠疹、汗孔角化症 |
| 棘层肥厚     | 棘层增厚，伴表皮突延长/增宽                   | 银屑病、慢性皮炎       |
| 疣状增生     | 表皮角化过度、颗粒层增厚、棘层肥厚、乳头瘤样增生         | 寻常疣、疣状痣        |
| 乳头瘤样增生   | 真皮乳头不规则向上增生                      | 黑棘皮病、皮脂腺痣      |
| 细胞内水肿    | 棘层细胞水肿，体积变大、胞质变淡高度水肿；气球样变性、网状变性  | 病毒性皮肤病、接触性皮炎   |
| 细胞间水肿    | 细胞间液体增多、细胞间隙增宽，又称海绵形成；严重时形成表皮内水疱 | 皮炎湿疹           |
| 基底细胞液化变性 | 基底细胞空泡化、崩解，棘层与真皮接触，常伴有真皮内噬黑素细胞浸润 | 扁平苔藓、红斑狼疮      |
#### 真菌镜检
- 直接涂片
- 墨汁涂片（隐球菌）
- 涂片/组织切片染色（革兰染色-白念珠菌、孢子丝菌；瑞氏 染色-组织胞浆菌；PAS 染色；荧光染色）
- 真菌培养
#### 梅毒螺旋体检查
1. 非特异性检查：
	- 快速血浆反应素环状卡片试验（RPR）、性病研究实验室试验（VRDL）、不加热血 清反应素试验（USR）、甲苯胺红不需加热血清试验（TRUST）。 
	- 临床意义：敏感度高、特异性低，用于疗效观察、判断复发/再感染， *不用于确诊*。 
2. 特异性检查：
	- 梅毒螺旋体颗粒凝集试验（TPPA）、梅毒螺旋体血凝试验（TPHA）、荧光螺旋体抗 体吸收试验（FTA-ABS）。 
	- 临床意义：*用于确诊*
#### 醋酸白试验
- *HPV 感染*的细胞产生异常的角蛋白，能被冰醋酸致白，尖锐湿疣皮损醋酸白试验阳性。
#### 斑贴试验
- 以适当的浓度、剂型将受试物贴于皮肤，观察是否产生变态反应，用于*接触性皮炎*。 
- 方法：将受试物贴于背部或前壁屈侧健康皮肤，48 小时去除斑贴，间隔 30 分钟观察结果。 
- 结果：无反应为阴性(-)，淡红斑为可疑(±)，轻度红斑、浸润、少量丘疹为阳性(+)，水肿性红斑、 丘疹或水疱为强阳性(++)，显著红肿、浸润、聚合性水疱、大疱为超强阳性(+++)。
#### 滤过紫外灯/Wood灯
- 利用 320~400nm 的光波，用于色素异常性皮肤病、皮肤感染、卟啉病的诊断。 
- 铁锈色小孢子菌、羊毛状小孢子菌（白癣菌）：亮绿色荧光。 
- 黄癣菌：暗绿色。 
- 马拉色菌（花斑癣）：棕色荧光。 
- 紫色毛癣菌、断发毛癣菌（黑点癣）： 无荧光
## (四)皮肤病的治疗
1. **抗组胺（H1受体）**（对抗组胺引起的毛细血管扩张、血管通透性增高、平滑肌收缩等效应）
	1. 第一代：氯苯那敏、苯海拉明、异丙嗪、酮替芬等；
	2. 第二代：氯雷他定、西替利嗪等
2. **糖皮质激素**
	- 免疫抑制，抗炎、细胞毒、休克、增生
	- 用于变应性、自身免疫性、严重感染性皮肤病
	- ![[药物-效价-剂量.png]]
	- 不良反应：轻度-满月脸、向心性肥胖、萎缩纹、皮下出血、痤疮、多毛，严重-糖尿病、高血压、 白内障、感染、消化道黏膜损害、肾上腺皮质功能减退、骨质疏松、缺血性骨坏死、神经精神症状
3. **抗生素**
4. 抗病毒
	1. 核苷类-阿昔洛韦ACV（HSV、VZV 感染）
	2. 膦甲酸（耐 ACV 的 HSV、VZV 和 CMV 感染）
	3. 阿糖腺苷（HSV、VZV、CMV、EBV 感染）
5. 抗真菌
	1. 特比萘芬（甲真菌病、角化过度型手藓）
	2. 两性霉素B（深部真菌）
	3. 制霉菌素（消化道念珠菌）
	4. 氟胞嘧啶（5-FC）（隐球菌病、念珠菌病、着色真菌病）
	5. 酮康唑（限外用）
	6. 伊曲康唑（甲真菌病、念珠菌病、隐球菌病、孢子丝菌病、着色真菌病、浅部真菌病）
	7. 氟康唑（深部真菌感染）
	8. 灰黄霉素（头癣）
	9. 碘化钾（孢子丝菌病）
6. **维A酸类**
	- 调节上皮细胞生长分化，对一些恶性肿瘤生长有抑制作用，可调节免疫、炎症过程。 
	- 用于痤疮、掌跖角化病、银屑病、鱼鳞病、毛囊角化病、皮肤肿瘤。
	- 注意*致畸反应*。
7. 免疫抑制剂及调节剂
	- 环磷酰胺（CTX）、甲氨蝶呤（MTX）、硫唑嘌呤（AZA）、环孢素（CsA）、吗替 麦考酚酯/霉酚酸酯（MMF）、干扰素（IFN）、卡介苗（BCG）、转移因子、胸腺肽、静注丙球（IVIg）
8. 其他
9. 物理治疗
	1. 紫外线疗法：适用于玫瑰糠疹、银屑病、斑秃、慢性溃疡、痤疮、毛囊炎、疖病。 
	2. 激光：手术用于疣、鸡眼、良性肿瘤，理疗用于毛囊炎、接种、甲沟炎、带状疱疹、斑秃、溃疡等。 
	3. 微波治疗：适用于疣、皮赘、血管瘤、淋巴管瘤、汗管瘤等。
	4. 光动力疗法：适用于肿瘤性疾病、病毒疣。 
>[!Note] 外用药物治疗原则
>- 急性期皮疹：有渗出者建议使用溶液湿敷，无渗出建议使用粉剂或者洗剂
>- 亚急性期皮疹：渗出不多使用糊剂及油剂，无糜烂使用乳剂
>- 慢性皮炎：建议使用乳膏、软膏及硬膏
