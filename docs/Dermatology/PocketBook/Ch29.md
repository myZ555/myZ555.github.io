# 性传播疾病

## 性传播疾病

## （一）概述

1. **性传播疾病（sexually transmitted disease，STD）：**主要通过性接触传染的一组传染病。
2. 我国《性病防治管理办法》规定的 STD 包括**梅毒、淋病、生殖道沙眼衣原体感染、尖锐湿疣、生殖器疱疹、艾滋病**。

## （二）梅毒（syphilis）

1. **梅毒（syphilis）：梅毒螺旋体（_Treponema pallidum_，TP）**引起的一种慢性传染病。
2. 病因：**梅毒螺旋体**又名**苍白螺旋体**，系**厌氧**微生物，含非特异性（e.g. 心磷脂）、特异性抗原物质。
3. 传播途径：①**性接触传播**（主要）；②**垂直传播**；③其他：血液传播等。

9. **血清固定/血清抵抗：**梅毒患者规范治疗后，**非特异性试验**维持在一定滴度超过 3 个月。

## （二）淋病（gonorrhea）

1. **淋病（gonorrhea）：**由**淋病奈瑟菌（_Neisseria gonorrhoeae_）**引起的泌尿生殖系统**化脓性**感染。
2. 病因：淋病奈瑟菌为 **G-双球菌**，卵圆形或肾形，抵抗力弱，**人类是唯一宿主**。
3. 传播途径：主要通过**性接触传播**，淋病患者是主要传染源。少数可通过**接触传播、垂直传播**（产道）。

## 无并发症的淋病：

- 1. **男性急性淋病：**早期，尿**频、尿急、尿痛**，后出现**尿道口红肿**、稀薄黏液，1 天后转为**大量黄色脓性分泌物**，可出现终末血尿、血精、会阴部坠胀感，全身症状较轻，可向后尿道、上生殖道扩散。
2. **女性急性淋病：**多数无症状/症状轻微，好发于**宫颈、尿道**，分泌物初为黏液性，后转为**脓性**，可伴**尿道口红肿、脓性分泌物**，伴**尿频、尿急、尿痛**，挤压尿道旁腺可见**脓性分泌物**，可有**单侧前庭大腺红肿、疼痛**，严重时形成脓肿，可伴全身症状。
3. **淋菌性肛门直肠炎：**肛门瘙痒/烧灼感。重者里急后重、排出大量脓性或血性分泌物。
4. **淋菌性咽炎：**表现为急性咽炎或扁桃体炎，可伴发热、淋巴结肿大，可有
5. **淋菌性结膜炎：**成年人多为自我接种或被分泌物污染的物品感染、单侧，新生儿多为经产道感染、双侧，表现为**结膜充血水肿、脓性分泌物，角膜云雾状**，严重时角膜溃疡、穿孔、失明。

1. 淋巴并发症：
1. **淋球菌性前列腺炎：**急性者，**发热、尿频、会阴部疼痛**，直肠指检示**前列腺肿大、压痛**，分泌物检查可见上皮细胞、脓细胞、淋球菌，可形成脓肿，慢性患者晨起初次排尿可有**尿道口糊口**。
2. **淋菌性精囊炎：**急性者有**发热、尿频、终末尿浑浊带血**，直肠指检可触及**肿大的精囊**，慢性者无明显症状，直肠指检示**精囊变硬**。
3. **淋菌性附睾炎：**多为单侧，可有**发热、阴囊红肿、疼痛**，同侧**腹股沟、下腹部反射性抽痛**，尿浑浊。
4. **女性：淋菌性盆腔炎**（急性输卵管炎、子宫内膜炎、卵巢输卵管脓肿、盆腔脓肿、腹膜炎），易导致输卵管狭窄或闭塞，导致**不孕、宫外孕**、慢性下腹痛。
2. **播散性淋球菌感染：**少见，**发热、寒战**、全身不适，四肢关节附近出现皮损，**瘀斑基础上的脓疱、血疱、坏死**，散在分布。可伴关节炎、腱鞘炎、心内膜炎、心包炎、胸膜炎、肝周围炎、肺炎等。
3. 诊断：淋病奈瑟菌**涂片镜检（G-双球菌，中性粒细胞内或胞外）、培养、核算扩增**。
4. 治疗：
1. 淋菌性尿道炎/宫颈炎/直肠炎：**头孢曲松**肌注，或大观霉素肌注，头孢克肟口服，头孢噻肟肌注。
2. 淋菌性咽炎/眼炎/妊娠期：**头孢曲松**肌注，头孢噻肟肌注；新生儿眼炎用**头孢曲松**肌注或静注。
3. 淋菌性盆腔炎/附睾炎/前列腺炎/精囊炎/播散性淋病：**头孢曲松**肌注或静注 **10 天**以上，或大观霉素肌注。**淋菌性脑膜炎、心内膜炎治疗时间更长**。

## （四）尖锐湿疣（condyloma acuminatum，CA）

1. **尖锐湿疣（condyloma acuminatum，CA）：HPV** 所致，常发生于**外生殖器、肛门**，主要通过**性传播**。
2. 病因：人类是 HPV 的唯一宿主，引起尖锐湿疣的主要是 **HPV-6 型、HPV-11 型**。
3. **临床表现：**好发于性活跃的中青年，多见于**外生殖器及肛门周围的皮肤黏膜湿润区**。
1. 皮损初为**淡红色小丘疹，顶端尖锐**，质地**柔软**，后增大增多，疣体分**无柄型、有柄型（乳头状、菜花状、鸡冠状、蕈样状）**，疣体**白色/粉红色/污灰色**，表面易发生糜烂、渗出、破溃。
2. 少数患者疣体过度增生，成为巨大尖锐湿疣，与 HPV-6 感染有关，可恶变。
3. 实验室检查：**醋酸白试验阳性**（HPV 感染的角质形成细胞的角蛋白异常）。

## 治疗：局部去除疣体为主。

- 1. **物理治疗：**激光、冷冻、电灼、微波，**巨大者可手术切除**。注意：**妊娠期禁用物理治疗！**
2. **光动力治疗：**疣体较小者、尿道口尖锐湿疣，或物理/药物治疗后防止复发。
3. **外用药物：咪喹莫特、鬼臼毒素酊、氟尿嘧啶**，**妊娠期禁用！**
4. **抗病毒药物、提高免疫力的药物：**转移因子、胸腺素、α-干扰素凝胶。

## （五）其他 STD

1. **非淋菌性尿道炎（NGU）：**解脲脲原体、人型支原体引起，好发于性活跃人群，多数无症状。
1. **男性尿道炎：**类似淋病，但尿道分泌物为**浆液性、量少**，有时晨起发现**尿道口糊口**。
2. **女性黏液性宫颈炎：**白带增多、宫颈糜烂、水肿，可引起输卵管炎、子宫内膜炎、宫外孕、不孕等。
3. **新生儿感染：**经产道分娩时感染**沙眼衣原体**，引起**结膜炎、肺炎**。
4. 治疗：首选**阿奇霉素或多西环素**，**妊娠期禁用四环素类**，新生儿衣原体结膜炎选用**红霉素眼膏**。
2. **生殖器疱疹（GH）：**由**单纯疱疹病毒（HSV，多为 HSV-2）**感染引起的一种慢性、复发性、难治性 STD。
1. **初发性生殖器疱疹：**簇集/散在的**小水疱**，2~4 天后破溃、糜烂/浅溃疡、结痂自愈。自觉**疼痛**。
2. **复发性生殖器疱疹：**原发感染后 1~4 个月，皮损类似于原发性，但较轻、伴前驱症状、病程短。
3. **亚临床型生殖器疱疹：**无临床表现，或不典型皮损（微小裂隙、溃疡）。
4. 治疗：同单纯疱疹（首选**阿昔洛韦**）。
3. **艾滋病（AIDS）：**由**人类免疫缺陷病毒（HIV）**感染、破坏 **CD4+ T 细胞**引起的严重免疫缺陷。
1. 病因：HIV 为 **RNA 病毒（逆转录病毒）**，包膜蛋白 **gp120（结合 CD4）及 gp41** 组成。
2. 发病机制：HIV 选择有 CD4 受体的细胞结合，主要为 **CD4+ T 细胞**，引起 CD4+ T 细胞结构及功能损害而致病。还会感染巨噬细胞、Langerhans 细胞等。
3. 传播途径：性接触传播、血液传播、母婴传播（垂直传播）。
4. 临床表现：

- - 1. 皮肤表现：

①非感染性皮肤损害：多形性，可类似于脂溢性皮炎、鱼鳞病、毛发红糠疹、银屑病等。

②感染性皮肤损害：带状疱疹、单纯疱疹、疣、真菌感染（鹅口疮、隐球菌等）、细菌感染。

③皮肤肿瘤：**Kaposi 肉瘤**（**粉红色**斑疹，长轴与皮纹一致→**淡紫色/棕色**斑疹/斑块→**出血性皮损、结节**）、淋巴瘤、恶性黑色素瘤、鳞癌。

- 1. **治疗：高效抗反转录病毒疗法（HAART）——2NRTIs + 1PIs / 1NNRTIs。**
1. 其他：免疫调节治疗（干扰素、IL-2、IVIg、CSF 等）、抗感染治疗。
2. **Kaposi 肉瘤：**皮损内注射**长春新碱、放疗、联合化疗**。
