# 真菌性皮肤病

## 真菌性皮肤病

1. **头癣（tinea capitis）：**累及头发、头皮的皮肤癣菌感染。

| | | | |
|---|---|---|---|
||**病原体**|**临床表现**|**Wood 灯**|
|**黄癣**<br><br>**（tinea favosa）**|**许兰毛癣菌**|淡黄红色斑点，覆盖薄片鳞屑→黄豆大小的**淡黄色痂，蝶形（周边翘起、中央紧贴）**，去除痂后，下方为**潮红糜烂**<br><br>**面**，造成病发干枯无光泽，可引起**永久性脱发**，有**鼠臭味**|**暗绿色**|
|**白癣**<br><br>**（white ringworm）**|**小孢子菌**|群集性红色丘疹，上覆**灰白色鳞屑**，**母子斑**（**周围相同的**<br><br>**小皮损）**，病发**高出头皮 2~4mm** 后折断，**不造成脱发**|**亮绿色**|
|**黑点癣（black-dot**<br><br>**ringworm）**|**紫色毛癣菌**<br><br>**断发毛癣菌**|散在的**鳞屑性灰白色斑**，扩大成片，病发**刚出头皮即折断**，<br><br>**残根在毛囊口呈黑点状**，常遗留**局灶性**脱发、萎缩性瘢痕|**无**荧光|
|**脓癣（kerion）**|**亲动物性**的<br><br>皮肤癣菌|成群的炎性毛囊性丘疹→**炎性肿块**，毛囊口形成**蜂窝状的**<br><br>**排脓小孔**，皮损处**毛发松动**，愈后遗留**永久性秃发、瘢痕**|/|

黄癣 白癣 黑点癣 脓癣

- 1. 治疗：口服**伊曲康唑、特比萘芬**，剪去病发，硫磺皂或酮康唑洗头，**外用抗真菌药**，注意消毒。

1. **体癣（tinea corporis）、股癣（tinea cruris）：除去头发、毛发、掌跖、甲以外**的浅表部位真菌感染称为体癣。**腹股沟、会阴、肛周、臀部**浅表皮肤发生的癣菌感染称为股癣，属于特殊的体癣。
1. 病因：主要由**红色毛癣菌**、须癣毛癣菌、疣状毛癣菌、犬小孢子菌感染引起，**直接/间接接触传播**。
2. **体癣：**红色丘疹/水疱→**红色斑片伴鳞屑**→边缘扩展、**中央消退**→**环状/多环状**，**瘙痒**明显。
3. **股癣：**好发于**腹股沟**，基本皮损与体癣相同，部分出现**湿疹样改变**。**瘙痒**明显。
4. 治疗：**外用抗真菌药**（唑类、丙烯胺类，至少 **2 周/皮损消退后 1~2 周**）、口服**伊曲康唑/特比萘芬**。

体癣 股癣 足癣（水泡型） 足癣（鳞屑角化型） 足癣（浸渍糜烂型）

1. **手癣（tinea manus）、足癣（tinea pedis）：**指间、手掌、趾间、足跖、足跟足侧缘的浅表真菌感染。
1. 病因：**红色毛癣菌**（主要）、须癣毛癣菌、石膏样小孢子菌、絮状表皮癣菌，主要通过**接触传播**。
2. **临床表现：手癣常累及单侧，足癣常累及双侧**（一侧→另一侧），分 3 型。足癣易继发细菌感染。

| | | |
|---|---|---|
|**类型**|**好发部位**|**临床表现**|
|**水疱型**|**指/趾间、掌心、足趾、足侧缘**|针尖大小的**深在水疱，疱液清、壁厚**，不易破溃，**瘙痒**|
|**鳞屑角化型**|**掌跖部、足跟**|弥漫性皮肤**粗糙、增厚、脱屑、干燥**，易皲裂出血|
|**浸渍溃疡型**|**指/趾缝**（第 3~4/4~5 趾间）|皮肤**浸渍发白，松软**易脱落，露出**潮红糜烂面**，伴**瘙痒**|

- 1. 治疗：**外用药物为主**（水疱型-霜剂、水剂，浸渍糜烂型-硼酸湿敷→粉剂→霜剂，鳞屑角化型-可用剥脱作用较强的制剂），疗程 **1~2 个月**。可口服**特比萘芬/伊曲康唑**。合并细菌感染时加用抗生素。

1. **甲真菌病（onychomycosis）/甲癣（tinea unguium）：**各种真菌引起的甲板、甲板下组织感染。
1. 病因：**红色毛癣菌**（主要）、须癣毛癣菌、絮状表皮癣菌、念珠菌、马拉色菌等。
2. 临床表现：

| | |
|---|---|
|**白色浅表型（SWO）**|甲板浅层有点状/不规则**白色浑浊**，表面**失去光泽/稍凹凸不平**|
|**远端侧位甲下型（DLSO）**|最常见，甲的**远端**前缘、侧缘**增厚、灰黄浑浊**，甲板**凹凸不平或破碎**|
|**近端甲下型（PSO）**|**甲半月、甲根部**粗糙肥厚、凹凸不平或破损|
|**全甲毁损型（TDO）**|**整个甲板**破坏、增厚，**灰黄色/灰褐色**，甲板**脱落**，甲床残留粗糙**角化堆积物**|

- 1. 治疗：**外用药物可治疗 SWO、DLSO**（先去除病甲+外用冰醋酸或碘酊，或尿素软膏封包+抗真菌药，疗程 **2~3 个月**）、**口服伊曲康唑/特比萘芬**（间歇冲击疗法）。

1. **花斑糠疹（pityriasis versicolor）：马拉色菌**侵犯皮肤角质层引起的浅表感染。
1. 临床表现：好发于**青壮年男性**，多见于面颈部、胸背部、上臂、腋窝等**皮脂腺丰富的部位**，**以毛孔为中心**、境界清楚的**点状斑疹**→逐渐增大→相互**融合**，表面覆盖**糠秕状鳞屑**，无自觉症状，冬轻夏重。
2. Wood 灯：**黄色或黄绿色**荧光（总论里说是棕色……）。
3. 治疗：**外用抗真菌药**（酮康唑、咪康唑、克霉唑，**2~4 周**）。
2. **念珠菌病（candidiasis）：**念珠菌引起的皮肤、黏膜或内脏感染。

| | |
|---|---|
|**念珠菌性擦疹**|好发于腹股沟、会阴、腋窝、乳房下，局部**潮红、浸渍、糜烂**，边缘鳞屑|
|**念珠菌性甲沟炎、甲真菌病**|甲沟红肿但**不化脓**，有少量溢出液，甲小皮消失，自觉**痛痒**；<br><br>甲板**增厚浑浊**，出现**白斑、横沟或凹凸不平**，甲下角质堆积增厚|
|**口腔念珠菌病、口角炎**|【**鹅口疮**】颊、上腭、咽、牙龈、舌等部位出现**凝乳状白色斑片**，**难擦除**<br><br>口角出现界限不清、**灰白色的增厚斑**，后转为蓝白色，皮肤**红斑鳞屑样改变**|
|**外阴阴道念珠菌病**|白带增多，**豆渣样、凝乳样**，伴**腥臭味**，自觉瘙痒、灼痛|
|**念珠菌性包皮龟头炎**|包皮内侧、龟头**弥漫性潮红**，附着**乳白色斑片**，可伴**丘疹、红斑、脱屑**|

- 1. 治疗：**外用克霉唑、制霉菌素**等，**口服伊曲康唑、氟康唑**等。必要时**静脉注射**给药。

## 着色芽生菌病（chromoblastomycosis）：暗色真菌引起。

- 1. 临床表现：好发于暴露部位，炎性丘疹→**暗红色结节/斑块**，表面**疣状/菜花状**或覆盖有**痂**，揭开后可见颗粒状或乳头状**肉芽**，肉芽之间有**脓栓**，周围有暗红色炎性浸润带。
2. 治疗：口服伊曲康唑/特比萘芬至少 6 个月，外用含渗透剂的抗真菌药，物理治疗/手术切除。

1. **孢子丝菌病（sporotrichosis）：申克孢子丝菌复合体**引起的慢性感染。
1. **固定型：**最常见，局限于初发部位，多形性改变。
2. **淋巴管型：**原发皮损在四肢远端，**沿淋巴管向心性出现新病灶**。
3. 其他：**播散型、皮肤外型**。
4. 治疗：首选**碘化钾**，疗程 3~6 个月。局部温热疗法。
