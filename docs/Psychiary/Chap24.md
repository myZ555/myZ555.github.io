# 治疗学

> - ==精神药物==：亲脂性化合物；易于*肠道*吸收和通过*血脑屏障*
> 	- 多数精神药物血浆蛋白结合率高，过量中毒不易通过血液透析方法清除
> 	- 肝脏代谢--极性增强、亲水性增加--肾脏排泄（乳汁排泄）
> 	- 大部分精神药物的靶蛋白是内源性神经递质的受体或转运体
> 	- 锂盐：治疗指数低、安全性差
> - 物理治疗：<u>电抽搐治疗ECT</u>、经颅磁刺激TMS、迷走神经刺激VNS……改良电抽搐治疗

## 抗精神病药

##### 【机制】

1. 多巴胺受体阻断作用
2. 5-羟色胺受体阻断作用 5-HT~2A~
3. 肾上腺素受体阻断作用 α~1~
4. 胆碱受体阻断作用 M1受体
5. 组胺受体阻断作用 H1受体

##### 【分类】

1. 第一代抗精神病药 *FGAs*：氯丙嗪、奋乃静、氟哌啶醇[^1]、五氟利多、舒必利
2. 第二代抗精神病药 *SGAs*：氯氮平、利培酮/帕利哌酮、奥氮平、喹硫平、齐拉西酮、阿立哌唑、鲁拉西酮……
