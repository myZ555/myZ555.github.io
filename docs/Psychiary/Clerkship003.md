# 精神检查

## 检查大纲

1. 一般情况
  1. 意识：**意识状态**是否清晰；意识障碍的水平和内容
  	1. 水平：觉醒程度，如昏睡、昏迷等
  	1. 内容：涉及认知功能，如定向力、注意力、记忆力等
  2. 定向力：**时间、地点、人物定向和自我定向能力**（⚠️进行检查而不是问患者是否知道。如：<u>今天是几月几号</u>？<u>现在在哪里</u>？<u>旁边是谁</u>？<u>今年多大</u>？）
  3. **接触情况**：主动（*主动提问*）、被动（*需要多次引导*）、**交谈合作情况**（回答是否切题、有无抵触情绪、能否配合检查；分为**合作良好、合作部分、不合作**） 及程度，对周围环境的态度【<u>主动且合作良好</u>/被动但配合尚可/被动且合作差/不合作】
  4. **语言**：清晰程度、流畅性、逻辑性、意思表达准确性（**语速、语量、语调**，面部表情的变化，姿势，举止等信息）
  5. 日常生活：仪表；饮食、大小便及睡眠；经期情况；工作、学习、社交、个人生活料理情况

2. 认知活动
  1. 感觉：**减退、过敏、内感性不适**

  	1. 你觉得最近身体对疼痛、冷热、触摸的反应有没有变化？
  	2. 如果别人碰你一下、用针扎一下，你感觉和以前一样吗？
  	3. 有没有觉得有些刺激好像变得“迟钝”或“不太有感觉”？
  	4. 最近有没有一些原本不觉得强的声音、光线或触感，现在变得特别刺耳、刺眼或难受？

  2. 知觉：

  	1. **错觉**：客观事物的错误感知

  	2. **幻觉**：缺乏外界相应客观刺激作用于感觉器官时所出现的知觉体验

  	3. **感知综合障碍**（视物变形、非真实案）：指患者对客观事物能够正确认识,但是对部分属性如大小比例、形状结构、空间距离、物体的动静等产生错误的知觉体验。

  		---

  		==4W1H: When, Where, What, Who, How==

  	- 你最近有没有听到过一些别人听不到的声音？能描述一下它们是怎样的？
  	- 当这些声音出现的时候，你会怎么想？会不会和它们对话？

  3. 思维：==形式==：**思维迟缓**、**思维奔逸**、思维中断、思维破裂、思维贫乏、思维散漫；==内容==：**关系妄想**、**被害妄想**、**夸大妄想**、影响妄想

  	- “别人会不会觉得你说得很快、话题跳得快？”	 
  	- “回答问题的时候，会不会觉得脑子转得慢？”	
  	- “有没有觉得有人在暗示你、针对你？”
  	- “你最近有没有觉得有人想害你或对你不利？”
  	- “你觉得自己最近有什么特别的能力、身份或使命吗？”
  	- “你最近有没有觉得自己犯了很大的错误，无法弥补？”
  	- “你有没有觉得自己的身体或思想被某种力量（如机器、辐射、能量）控制或影响？ ”

  4. 注意力：是否集中；涣散的特点、影响因素

  	- 总体感受：“你最近觉得自己的注意力怎么样？”
  	- 具体情境：“看电视、看书、听别人讲话时，你能一直集中注意力吗？”
  	- 出现特点：“当注意力不集中的时候，你的表现是怎样的？（发呆、想别的事、反应变慢等）”
  	- 影响因素“你觉得是什么让你更容易分心？（疲劳、噪音、心情不好等）”

  5. 记忆力：记忆障碍；**记忆减退、记忆增强、遗忘、虚构、错构**

  6. 智能：一般常识（现任国家主席）、理解判断（成语解释）、抽象思维（桔子和香蕉）、计算能力（用100-7检测患者的简单计算力和注意力）、专业知识（根据职业/教育背景）

3. 情感活动：观察患者的面部表情、姿态，并询问其内心体验

	1. ==情感的基调==（情感性质的障碍）：**高涨、欣快（智能障碍基础上的不协调兴奋）、低落、焦虑、恐惧**
	2. ==情感的稳定性==（情感的始动功能失调）：**易激惹**、**情感不稳定（情感脆弱）**、病理性激情、情感迟钝、情感淡漠、强制性哭笑
		- **易激惹**：指患者情绪/情感极易诱发,轻微刺激即可引起强烈的情绪/情感反应,或暴怒发作。<u>“你最近是不是容易因为小事生气或发火？” “别人提醒或批评时，你的反应会是什么？”</u>
		- **情感不稳定（情感脆弱）**：患者的情感稳定性差,容易变动起伏,喜、怒、哀乐极易变化;常常从一个极端波动到另一个极端,一会儿兴奋,一会儿伤感；与外界环境有关的轻度的情感不稳定可以是一种性格表现,表现为极易伤感多愁,动辄呜咽哭泣,称为情感脆弱。<u>“你的情绪最近会不会变化很快？比如一会儿高兴、一会儿又难过？</u>
		- **病理性激情**：骤然发生的、强烈而短暂的情感爆发状态，常常伴有冲动和破坏行为,事后不能完全回忆。
		- **情感迟钝、情感淡漠**：患者对客观事物和自身情况漠不关心,缺乏应有的内心体验和情感反应,处于无情感状态。常见于精神分裂症。如果患者对客观刺激的情感反应虽然存在,但反应速度明显迟缓、强度明显减低,称为情感迟钝。常见于精神分裂症、痴呆。
		- **强制性哭笑**：突如其来的、不能控制的强哭或强笑现象,既无外因,也无相应的内心体验。这种症状常见于脑器质性精神障碍。
	3. ==情感的协调性==：
		- **倒错**：情感反应与环境刺激不相一致,或者面部表情与其内心体验不相符合。<u>如遇到愉快的事情表现悲痛,痛哭流涕</u>,多见于精神分裂症。
		- **幼稚**：患者的情感反应退化到童年时代的水平,容易受直觉和本能活动的影响,缺乏节制。多见于分离性障碍、痴呆
		- **矛盾**：指患者在同一时间内体验到两种完全相反的情感,但患者并不感到这两种情感的互相矛盾和对立,没有苦恼或不安:患者常将相互矛盾的情感体验同时显露出来,使别人不可理解。常见于精神分裂症。

4. 意志行为：意志增强、意志减退

	1. ==意志增强==：<u>有被害妄想的患者,反复上访,向有关部门申述和要求安全保障等。</u>
	2. ==意志减退==、意志缺乏；对日常生活料理情况；对学习、工作的积极性；对未来的打算
		- “最近你会主动去做家务、学习或工作吗？”
		- “如果有人提醒或催你，你会去做吗？”
		- “最近你有没有整天什么都不想做的情况？”

5. 行为：主要依赖仔细的观察，包括**自伤自杀行为**、**伤人毁物行为**、**强迫行为**、**怪异行为**、**外逃行为**、模仿行为、刻板行为、**木僵状态**、兴奋状态

6. 自知力：无自知力、部分自知力、完全自知力

	- 是否察觉到周围其他人发现自己有异常表现？
	- 自己是否也认为自己有异常？这种异常是否是自己精神方面的问题？
	- 这种精神方面的问题是否需要治疗？

## 检查后的心理支持和总结汇报

- 检查后的心理支持：举个例子，检查结束时可以跟患者讲，听起来您的情绪可能有些问题，如果您能配合我们的治疗，效果还是会比较好的……
- 检查后的总结与简要汇报：一般情况、认知活动、情感活动、意志行为和总体印象诊断。

#### 以抑郁为例：

患者王*，中年女性，因“心情差、眠差3个月”就诊。意识清楚，定向力完整，接触稍显被动，检查合作，对周围环境感到陌生，言语流畅、语速慢、语量少、语调低，对答切题，讲话条理性尚可，表情愁苦，食欲差、睡眠差，大便便秘，小便正常，近一个月体重下降1kg左右；未查及感觉减退、感觉过敏、内感性不适等感觉障碍，未查及错觉、幻觉等知觉障碍，未查及感知综合障碍，思维形式正常，未查及关系妄想、被害妄想等思维内容障碍，注意力和记忆力有所下降，智能粗测正常，自知力大部分存在；情绪显低落，兴趣减退，精力下降，伴焦虑不安，情绪稳定性尚可，情感反应与内心体验、外界环境相协调，意志减退，存在消极想法，否认轻生行为，否认强迫、冲动等其他异常行为。考虑患者目前为焦虑抑郁状态，最可能的诊断是抑郁障碍。
