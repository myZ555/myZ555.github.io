# 第 6 篇 第 4 章 气管、支气管异物

1. **临床表现：幼儿**好发。
    1. 分期：
        1. **异物吸入期：剧烈呛咳、呼吸困难、发绀，甚至窒息。**
        2. **安静期：只有轻微咳嗽，无其他症状。**
        3. **炎症期：咳嗽、肺不张、肺气肿等。**
        4. **并发症期：肺炎、肺脓肿、脓胸等。**
    2. **喉异物：吸气性呼吸困难**甚至**窒息**伴**刺激性咳嗽**，可继发感染、变态反应，或咯血、皮下气肿。
    3. **气管异物：剧烈呛咳、憋气、呼吸不畅、刺激性咳嗽**，异物在声门、支气管间运动可闻及**拍击音**。
    4. **支气管异物：咳喘、发热**，可继发肺气肿、肺不张、支气管肺炎等。
2. 诊断：**异物吸入史**是最重要的诊断依据。
    1. 体检：活动性气管异物可在呼气末或咳嗽时闻及**声门拍击声**，伴颈部**撞击感**。注意继发病变体征。
    2. X 线：金属类异物可用胸部正侧位片诊断。胸透可发现**纵膈摆动（见于气管异物阻塞一侧支气管）**。
    3. 胸部CT：适用于异物吸入史不详、迁延性肺炎原因不明、胸片阴性者而临床怀疑者。

### 支气管镜检查：金标准。

1. 治疗：手术取出异物是唯一的方法，建议**全麻**下进行。

|   |   |
|---|---|
|**直接喉镜取出**|**喉前庭、声门区、声门下区、总气管**内异物|
|**支气管镜取出**|**气管、支气管**异物等|
|**经气管切开口取出**|呼吸困难，**病情危急**；**异物较大或形状特殊**；已有明显**炎症**者|
|**经纤支镜取出**|更深的细支气管、硬镜无法插入|
|**开胸取出**|**内镜无法取出**，已导致**支扩、肺脓肿**等|

1. 并发症：
    1. **气胸、纵隔气肿、皮下气肿：**暂停取出异物，**胸腔闭式引流**。

### 气管内出血：气管内注入 1:1000 肾上腺素。

- 1. **急性呼衰：**置入喉镜前，**1%利多卡因喷喉**、选择**全麻**可预防。
    2. **肺炎、肺不张：**异物取出后抗生素治疗。
