# 第 3 篇 第 12 章 鼻源性并发症

1. **鼻源性眶内并发症：眶周蜂窝织炎、眼眶骨膜下脓肿、眶内蜂窝织炎/眶内脓肿、球后视神经炎。**

|   |   |   |
|---|---|---|
|**并发症**|**临床表现**|**治疗**|
|**眶周蜂窝织炎**|眼球水肿、轻压痛，**无眼球运动受限、眼球突出、视力减退**|积极治疗急性鼻窦炎|
|**眼眶骨膜下脓肿**|**眼球突出、移位**伴全身症状，可引起**眶尖综合征**（第 II、III 对<br><br>脑神经受损）|切开引流+<br><br>全身足量抗生素|
|**眶内蜂窝织炎**|**眼球明显突出、运动受限、视力减退、球结膜水肿**、全身症状|鼻窦手术引流+抗生素|
|**球后视神经炎**|**蝶窦炎/后组筛窦炎**引起，表现为**视力下降或失明**|手术+激素+抗生素|

1. **鼻源性颅内并发症：硬膜外脓肿、硬膜下脓肿、化脓性脑膜炎、脑脓肿、海绵窦血栓性静脉炎。**

|   |   |   |
|---|---|---|
|**并发症**|**临床表现**|**治疗**|
|**硬膜外脓肿**|**头痛加重（局限性）**，卧位加剧，伴**颅内压增高**表现|使用可穿透血脑屏障的抗生素；尽早行**病变鼻窦的开放术，充分引流、冲洗；**降颅压治疗|
|**硬膜下脓肿**|常伴化脓性脑膜炎，头痛、发热、颅内压增高、脑脊液改变|
|**化脓性脑膜炎**|**头痛、发热、癫痫、嗜睡、躁狂、昏迷**等|
|**脑脓肿**|多见于**额叶**，表现为头痛、呕吐、视盘水肿、视神经萎缩|
|**海绵窦血栓性静脉炎**|早期发热、头痛、畏光、复视、眶周水肿；后期出现**眼睑下**<br><br>**垂、眼球突出、麻痹、球结膜水肿、视力减退**等|
