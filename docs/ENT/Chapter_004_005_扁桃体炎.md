# 第 4 篇 第 5 章 扁桃体炎

### （一）急性扁桃体炎（acute tonsillitis）*

1. **急性扁桃体炎（acute tonsillitis）**：腭扁桃体的急性非特异性炎症，常伴咽黏膜和淋巴组织炎症。
2. 病因：最常见的是**乙型溶血性链球菌**。正常人咽部、扁桃体隐窝存在这些病原体，抵抗力下降时发病。
3. **临床表现：剧烈咽痛**伴**吞咽困难、下颌下淋巴结肿大**，**化脓性**扁桃体炎常伴**全身症状**（畏寒发热等）。
4. 检查：双侧**咽部黏膜充血水肿，腭扁桃体肿大**，表面可见**黄白色脓点**，或隐窝口有黄白色/灰白色**豆渣样渗出物**，可形成**假膜**。下颌下淋巴结肿大。
5. 并发症：扁桃体周围脓肿、急性中耳炎、急性鼻炎/鼻窦炎、急性喉炎、急性淋巴结炎、咽旁脓肿、风湿热、心肌炎、急性肾小球肾炎、急性关节炎、急性骨髓炎（全身并发症与对链球菌的超敏反应有关）。
6. 治疗：抗生素首选**青霉素**，酌情使用**糖皮质激素**，可加用局部、对症治疗，**急性炎症消退后**才可**手术**。

### （二）慢性扁桃体炎（chronic tonsillitis）

1. **慢性扁桃体炎（chronic tonsillitis）**多由于急性扁桃体炎反复发作或扁桃体隐窝引流不畅，演变成慢性炎症。主要致病菌是**链球菌和葡萄球菌**。
2. **临床表现：咽痛，易感冒、扁桃体炎急性发作**，平时可有咽干、发痒、异物感、刺激性咳嗽等，可伴口臭。**小儿**扁桃体过度肥大可引起**呼吸不畅、打鼾**、吞咽障碍、言语共鸣障碍。可引起胃肠、全身反应。
3. 体检：**双侧扁桃体、腭舌弓慢性充血**，黏膜暗红色，**隐窝口可见黄白色干酪样点状物**，常伴**下颌下淋巴结肿大**。 注意：扁桃体单侧进行性肿大需考虑扁桃体肿瘤！
4. 治疗：
    1. 非手术治疗：抗菌药物、增强免疫力的药物、具有脱敏作用的细菌制品、局部治疗、加强锻炼等。
    2. 手术治疗：**扁桃体切除术（tonsillectomy）**，注意**急性炎症期禁止手术！**
        1. 慢性扁桃体炎**反复发作**或多次并发**扁桃体周围脓肿**。
        2. 扁桃体过度肥大，**影响呼吸、吞咽、发声功能**。
        3. 慢性扁桃体炎**已成为其他脏器病变的病灶**，或与邻近器官病变有关联。
        4. **白喉**带菌者，保守治疗无效。 v. 扁桃体**良性肿瘤**（恶性肿瘤需谨慎）。
5. 扁桃体切除术的术后并发症及其处理：
    1. **出血：**术后 24h 内多为原发性，术中止血不彻底、残留或术后咽部活动过盛导致；继发性出血多见于术后 5~6 天，白膜脱落后不甚擦伤即可导致出血。处理：查明出血部位，**少量出血可用纱布或棉球压迫止血，活动性出血点予电凝止血，弥漫性出血不能压迫止血者用消毒棉球填塞止血**。
    2. **伤口感染：**术后 3 天体温突然升高或腭弓肿胀，创面不长白膜或白膜分布不均，咽痛加剧等。
    3. **肺部并发症：吸入性肺炎**，应行 CT、支气管镜检查并吸除血液、异物，使用足量抗生素。
