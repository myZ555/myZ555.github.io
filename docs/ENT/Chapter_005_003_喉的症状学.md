# 第 5 篇 第 3 章 喉的症状学

1. **声嘶（hoarseness）：**病变累及**声带**。轻度表现为声音变粗变低，重者声音嘶哑，严重者失声。
    1. **支配声带运动的神经肌肉受损：喉返神经**、迷走神经、喉上神经（罕见）。
    2. **喉部本身病变：**先天性畸形、炎症、**声带息肉/小结/囊肿/肉芽肿、喉肿瘤**、喉外伤、代谢性疾病。
    3. 癔症性声嘶、其他（激素水平变化）。
2. **吸气性呼吸困难（inspiratory dyspnea）：**可出现**三凹征（胸骨上窝、锁骨上窝、肋间隙）**，见于**喉部、气管**阻塞性疾病，也见于**下咽、口咽**部病变。
    1. **先天性疾病：**先天性喉蹼、先天性喉软骨畸形。
    2. **炎症性疾病：急性会厌炎**、急性喉炎、急性喉气管支气管炎、喉白喉、喉结核。
    3. **喉肿瘤：**良性（喉乳头状癌、纤维瘤、血管瘤）、恶性（喉癌、喉肉瘤）。
    4. **其他：**喉水肿、喉痉挛、喉异物、声带巨大息肉、会厌巨大囊肿、喉外伤、双侧喉返神经麻痹。

### 喉喘鸣（laryngeal stridor）：喉或支气管阻塞，患者用力吸气，气流通过狭窄处发出特殊声音。

- 1. 先天性喉喘鸣、先天性喉蹼；
    2. 急性会厌炎、喉炎、喉气管支气管炎；
    3. 外伤性喉气管狭窄；
    4. 双侧声带麻痹；
    5. 喉痉挛； f) 喉水肿； g) 喉肿瘤。

### 喉痛（laryngalgia）：见于

- 1. 喉的急性**炎症**；
    2. 喉关节病变；
    3. 喉外伤、异物；
    4. 喉恶性**肿瘤**；
    5. 喉的特异性炎症（结核）。

1. **咯血（hemoptysis）：喉及喉以下的呼吸道出血**，少量表现为痰中带血，大量表现为咯出大口鲜血。喉部病因：喉癌、喉结核、喉血管瘤、喉外伤或异物。
2. **吞咽困难（dysphagia）：**①参与吞咽的结构异常；②喉痛；③喉神经性疾病。
    1. 急性会厌炎；
    2. 喉软骨膜炎、喉脓肿；
    3. 喉疱疹；
    4. 喉结核；
    5. 环杓关节炎；
    6. 喉癌晚期；
    7. 喉神经麻痹（中枢性、周围性）； h) 喉外伤。
