# 第 2 篇 第 2 章 第 3 节 听力检查

1. 音叉试验：

|   |   |   |   |
|---|---|---|---|
|**试验**|**方法**|**传导性聋**|**感音神经性聋**|
|**林纳试验（RT）**|C256 音叉，气导骨导比较|**气导<骨导(-)**|**气导>骨导(+)**|
|**韦伯试验（WT）**|音叉置于颅面中点，双侧比较|**偏患侧**|**偏健侧**|
|**施瓦巴赫试验（ST）**|与正常人比较骨导听力|**延长(+)**|**缩短(-)**|

1. 纯音听力计检查法：
    1. **正常：气导、骨导听阈<25dB，气骨导听阈差<10dB。**
    2. **传导性聋：气道<骨导，低频区为主，上升型曲线。**

### 鼓膜穿孔：平坦型曲线，气骨导差 40dB。

- - 1. **听骨链损伤：气骨导差 60dB**（无鼓膜穿孔）。

### 感音神经性聋：气导、骨导一致下降，高频区为主，下降型曲线。

- 1. **混合性聋：气导、骨导均下降，但存在差值，低频区以传导性聋为主，高频区以感音神经性聋为主。**

1. **声导抗测试：**一种**中耳功能**检查的客观测试，对发现中耳病变及面神经病变的定位诊断有很大的价值。
    1. 由于中耳病变对质量和摩擦力的影响较小，通常影响的是劲度，所以中耳的声阻抗可以用鼓膜的顺应性声纳来描述。顺应性高表示阻抗小，顺应性低则表示阻抗大。声导抗仪是利用一定声压级的低频纯音导入外耳道，引起鼓膜、听骨链、卵圆窗、鼓室腔、咽鼓管以及中耳肌肉等结构的振动或变化，并测量从鼓膜返回来的声能，并由此推知中耳的状态。

### 鼓室声导抗：正常 A 型、鼓室硬化粘连 B 型、咽鼓管功能障碍 C 型。

- 1. **镫骨肌反射：**声刺激→**蜗神经**→双侧上橄榄核→双侧面神经核→**面神经**→镫骨肌支→镫骨肌收缩。
    2. **咽鼓管功能测试：**鼓膜完整时，**吞咽动作**通过咽腭肌肉改变咽鼓管状态，从而**改变中耳压力**，结合吞咽动作动态观察鼓室声导抗峰压的变化，可以了解咽鼓管的功能。

1. **耳声发射：**一种**产生于耳蜗**，经听骨链及鼓膜传导释放入外耳道的音频能量。
    1. 分类：自发性耳声发射（SOAE）、诱发性耳声发射（EOAE）。

### 听性脑干反应测试（ABR）：

- 1. Ⅰ波： 来自听神经纤维树突。
    2. Ⅱ波： 来自听神经进入脑干的近端。
    3. Ⅲ波： 来自耳蜗核或附近二级神经元活动。
    4. Ⅳ波： 来自桥脑中第三级神经元活动。
    5. Ⅴ波： 来自下丘脑区。
    6. Ⅵ波： 来自丘脑的内膝体。
    7. Ⅶ波： 来自丘脑和皮层间的听放射。
