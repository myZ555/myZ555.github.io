# 第 4 篇 第 11 章 OSAHS

### 阻塞性睡眠呼吸暂停低通气综合征（obstructive sleep apnea hypopnea syndrome，OSAHS）：睡眠时上

**气道塌陷阻塞**引起的呼吸暂停和低通气，常伴**打鼾、睡眠结构紊乱、频繁 SaO2↓、嗜睡、记忆力下降**等，可导致高血压、冠心病、糖尿病等多器官多系统损害。 **肥胖中年男性**好发。

1. 概念：

|   |   |
|---|---|
|**呼吸暂停（apnea）**|睡眠中口鼻气流均消失（下降≥90%），分中枢性、阻塞性、混合性|
|**低通气（hypopnea）**|口鼻气流强度下降≥30%伴 SaO2 下降≥4%，持续≥10s<br><br>口鼻气流强度下降≥50%伴 SaO2 下降≥3%或微觉醒，持续≥10s|
|**微觉醒（arousal）**|非快速动眼睡眠（NREM）中≥3s 的EEG 改变（θ 波、α 波、>16Hz）|
|**呼吸努力相关微觉醒（RERA）**|未达到呼吸暂停或低通气标准，但有≥10s 的异常努力呼吸伴觉醒|
|**睡眠低氧血症（sleep hypoxemia）**|睡眠状态下，由于呼吸暂停或低通气引起的 SaO2<90%的状态|
|**睡眠呼吸暂停低通气指数（AHI）**|**AHI=(呼吸暂停次数+低通气次数)/睡眠时间**|
|**睡眠呼吸紊乱指数（RDI）**|平均每小时发生的呼吸暂停、低通气、RERA 总次数|

### 病因：

- 1. **上气道解剖结构异常或病变：**
        1. **鼻腔、鼻咽部狭窄：**鼻中隔偏曲、鼻息肉、慢性鼻炎/鼻窦炎、鼻甲肥大、腺样体肥大等。
        2. **口咽部狭窄：最常见**，腭扁桃体肥大、软腭/咽侧壁肥厚、悬雍垂过长、舌根肥厚、舌体肥大。
        3. **喉咽、喉腔狭窄：**婴儿型会厌、会厌组织塌陷。 iv. **上、下颌骨发育不良、畸形**。
    2. **上气道扩张肌张力异常：**颏舌肌、咽侧壁肌肉、软腭肌肉，导致 OSAHS 患者气道反复塌陷阻塞。
    3. **呼吸中枢调节异常：**呼吸中枢对高 CO2、高 H+、低O2 的反应异常。
    4. **全身因素：肥胖、**妊娠、绝经、围绝经期、甲减、糖尿病、异常等。

1. **临床表现：**
    1. **睡眠时打鼾、呼吸暂停：仰卧位**加重。
    2. **白天嗜睡**。
    3. **记忆力、注意力**减退，**反应**迟钝。
    4. **晨起**口干、咽喉异物感、头痛、高血压。
    5. **性功能障碍**、溢尿。
    6. **性格改变**（烦躁易怒、抑郁等）。
    7. 儿童**颌面部发育障碍、生长发育迟缓、胸廓发育畸形、学习成绩下降**。
2. **诊断：**

|   |   |   |
|---|---|---|
|**☆程度**|**AHI**|**SaO2min**|
|**轻度**|**5~15**|**85%~90%**|
|**中度**|**15~30**|**80%~85%**|
|**重度**|**>30**|**<80%**|

- 1. **多导睡眠图（polysomnography，PSG）：**首选。
    2. 嗜睡程度评价：Epworth 嗜睡量表（ESS）、斯坦福嗜睡量表（SSS）、多次睡眠潜伏期实验（MSLT）。
    3. 阻塞平面定位：**纤维/电子鼻咽喉镜+Muller 法（捏鼻闭口吸气）、上气道持续压力测定（阻塞平面以上压力传感器无变化）**、X 线头颅测量、上气道 CT/MRI、诱导睡眠纤维/电子内镜。

### 治疗：

- 1. **一般治疗：减肥**、戒烟戒酒、**侧卧**、良好生活习惯、避免过度劳累等。
    2. **非手术治疗：无创正压通气治疗（最有效）、口腔矫治器（下颌后缩者）**、药物（无确切疗效）。
    3. **手术治疗：**根据病因，如鼻息肉摘除、鼻中隔偏曲矫正、扁桃体、腺样体切除、**悬雍垂腭咽成形术**。
