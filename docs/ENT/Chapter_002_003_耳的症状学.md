# 第 2 篇 第 3 章 耳的症状学

1. **耳痛（otalgia）：炎症性**（耳廓软骨膜炎时剧痛）**、创**

**伤性、恶病性**（坏死性外耳道炎、中耳癌，伴外耳道

流血）**、神经性**（Hunt 综合征、三叉神经痛）**、牵扯性**（牙、下颌关节、咽、喉、颈、呼吸道、消化道）。

1. **耳漏（otorrhea）：**耳溢液。

|   |   |
|---|---|
|**脂性（油耳）**|稀薄酱油色，与遗传有关|
|**浆液性**|稀薄透明，常见于**外耳道湿疹、变应性中耳炎**|
|**黏液性**|黏稠，常见于**慢性化脓性中耳炎**|
|**水样**|多见于**脑脊液耳漏**|
|**脓性**|见于**急慢性化脓性中耳炎、外耳道疖、弥漫性外耳道炎**|
|**血性**|见于**大疱性鼓膜炎、中耳胆固醇性肉芽肿、中耳癌、中耳颈静脉体瘤、中耳胆脂瘤伴肉芽**|

1. **耳聋（hearing loss）：外耳/中耳~传导性聋，内耳（螺旋器）~感音性聋、螺旋神经节到蜗神经核~神经性聋、蜗神经核~听觉中枢~中枢性聋**。感音性聋、神经性聋统称为感音神经性聋。

### 耳鸣（tinnitus）：生理性/病理性，传导性耳聋者多为低调轰鸣，感音神经性聋多为高调蝉鸣。

- 1. **他觉性：**血管性（e.g. 动静脉瘘）、肌源性（e.g. 腭肌/镫骨肌痉挛）、气流性（e.g. 咽鼓管异常开放）、其他（e.g. 颞下颌关节囊松弛）。
    2. **主观性：**耳部疾病、全身性疾病、心理因素、其他。

1. **眩晕（vertigo）：**机体对空间定位障碍而产生的运动性或位置性错觉。

|   |   |
|---|---|
|**耳源性**|**突然**发病、持续时间**短**，与**头位**有关，伴**耳鸣、耳聋、眼震**、自主神经功能紊乱|
|**中枢性**|起病**慢**、持续时间**长**，与头位**无关**，**不伴**耳鸣、耳聋，可伴眼震，**眩晕轻、步态不稳重**|
|**全身疾病性**|表现不一，如漂浮感、麻木感、倾斜感、直线幻动等|
