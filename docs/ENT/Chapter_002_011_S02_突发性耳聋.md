# 第 2 篇 第 11 章 第 2 节 突发性耳聋

1. 耳聋的分级（**平均听阈**取 **500Hz、1000Hz、2000Hz** 听阈的平均值）：

|   |   |   |   |   |   |   |
|---|---|---|---|---|---|---|
||**正常**|**轻度聋**|**中度聋**|**中重度聋**|**重度聋**|**极重度聋**|
|**平均听阈**|<25dB|26~40dB|41~55dB|56~70dB|71~90dB|>91dB|

### 耳聋的分类：

- 1. **传导性聋（conductive hearing loss）：**见于外耳、中耳疾病，**气导<骨导，低频**为主。
    2. **感音神经性聋（sensorineural hearing loss）：**耳蜗、听神经或中枢病变，**气导=骨导，高频**为主。
    3. **混合性聋（mixed hearing loss）：**中耳、内耳病变同时存在。
    4. **功能性聋（functional having loss）：精神心理因素**引起，多为双耳，可伴其他障碍，反射正常。
    5. **伪聋（malingering）：**无器质性病变，听力正常，故意伪装。

1. **突发性耳聋（sudden hearing loss，sudden deafness）：突然发生（<3d）、原因不明的感音神经性**听力↓。
2. 病因：血管性疾病（**迷路动脉**）、感染、肿瘤（**听神经瘤**）、中毒、先天性发育异常（**大前庭水管综合征**）。
3. **临床表现：突发性听力下降、耳鸣（90%）、耳闷胀感（50%）、眩晕/头晕（30%）**、听觉过敏、重听、耳周感觉异常、精神心理症状。
4. 需要排除：脑卒中、听神经瘤、鼻咽癌、梅尼埃病、中耳炎、Hunt 综合征、流行性腮腺炎、全身因素。
5. 治疗：低钠饮食、**糖皮质激素**、血管扩张剂（e.g. CCB）、溶栓/抗凝药（e.g. **巴曲酶**）、高压氧治疗。
