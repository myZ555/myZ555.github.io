## 我的

主诉：发现双眼上睑肿物，右眼8月余，左眼2月

现病史：8月前因工作劳累右眼上睑出现肿物，肿物进行性缓慢增大，初始有痒感，无压痛，边界清楚，活动度可。病程中无视力下降及复视，无畏光流泪，无异常眼部分泌物；劳累后有眼部干涩感。3月前因肿物持续增大至浙江大学附属第二医院就诊，具体诊断不详，给予“眼药水”、“药膏”，并建议热敷处理，无明显好转。2月前左眼上睑亦出现一类似肿物，并逐渐增大。现患者以求进一步诊治来院就诊。

自病以来患者神志清，精神可，胃纳、睡眠可，二便无殊，体重无明显改变。

既往史：患者过去体质正常，无高血压、无糖尿病；无心脏病；无肾病史；无肺结核；无病毒性肝炎；食物、药物过敏无；曾于肩胛骨处有外伤；无手术史；无输血史；无中毒史；无常期用药史；无可能成瘾药物、疫苗接种按国家规定进行。

个人史：出生并成长于湖南省永州市，职业为物业，学历为大专。无疫区拘留史。无冶游史。有吸烟史10年，平均20支/天。偶尔饮酒。无毒物及放射性物质接触史。

婚育史：患者于28岁结婚，配偶身体健康。育有1子0女，子女体健。

家族史：父母情况不详，1姐1弟1妹均体健，直系亲属无类似疾病。患者否认二系三代有遗传病史。患者否认有遗传倾向的疾病。

专科检查：

眼科检查：右眼视力1.0（裸眼），左眼视力1.0（裸眼）；眼压：右眼15.5mmHg，左眼16.1mmHg。双眼上睑皮下可及圆形肿块，左眼约1.0cm* 1.0cm，右眼约0.5*0.5cm。肿块表面光滑，无明显触痛，与皮肤无粘连，对应睑结膜面局限性充血，角膜透明，前房清，深浅可，瞳孔圆，直径约3mm，对光反应灵敏，晶体透明，眼底视盘界清，网膜平伏，黄斑中央凹反光见。

 

辅助检查：无殊。

 

病例特点：

1. 患者29岁青年男性，慢性病程。因“发现双眼上睑肿物，右眼8月余，左眼2月”来院就诊。
2. 双眼上睑无痛性肿物，进行性缓慢增大。病程中伴随劳累后眼部干涩感，无视力及视野改变，无异常眼部分泌物，无压痛，肿物边界清楚、活动度可。
3. 既往有肩胛骨外伤史；否认高血压、糖尿病及传染病史。有吸烟史10年（平均10支/天）。婚育史及家族史无殊。

初步诊断：睑板腺囊肿 

诊断依据：

1. 病史： 发现双眼上睑肿物，右眼8月余，左眼2月。肿物呈进行性缓慢增大，无明显痛感。前期经外院局部用药及热敷等保守治疗无明显好转。

2. 体征： 双眼上睑可触及局限性结节，左眼约1.0cm * 1.0cm，右眼约0.5*0.5cm，触诊无压痛，边界清楚，活动度可。

3. 辅助检查： 无殊。

	

鉴别诊断：

1. **麦粒肿（睑腺炎）**：两者均可表现为眼睑局部的结节样肿物。但麦粒肿为眼睑腺体的急性化脓性炎症，临床典型表现为局部的红、肿、热、痛及明显的触痛。本例患者病程呈慢性进展，查体表现为无痛性肿块，局部无触痛及压痛，故不支持该诊断。

2. **睑板腺癌**：多发于上睑，表现为逐渐增大的肿物。多见于中老年人，肿瘤质地坚硬，边界通常不清，后期易致局部睫毛脱落，且表面结膜可呈黄白色结节或菜花状溃疡。本例患者双眼肿块边界清楚，活动度可，目前恶性指征不明显。最终排除确诊需依赖术后肿物组织病理学检查。

3. **眼睑皮样囊肿**：表现为眼睑皮下或眶缘的无痛性包块，质软，表面光滑。该病多属先天性发育异常，常见于婴幼儿或儿童期发病，且好发于眶外上缘。本例患者发病年龄较晚，呈后天继发，结合发生部位不支持该诊断。

4. **睑板腺囊肿继发感染**：睑板腺囊肿若发生继发性细菌感染，可突发急性炎症反应，临床表现演变为类似内麦粒肿的红肿痛及压痛。本例患者现阶段局部皮肤正常，无局部炎症反应体征，故不支持。

 

诊疗计划：

1. 拟在1-2天内完善各项相关术前检查，排除手术禁忌症；
2. 择期局部麻醉下行睑板腺囊肿切除手术；
3. 费用大约1000元，住院时间大约1天；
4. 若切口愈合良好，无感染、出血等并发症，病情稳定，可考虑出院。
