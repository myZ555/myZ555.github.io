# 第 16 章 屈光不正

## （一）概述

1. **屈光（refraction）：**光从一种介质进入另一种折射率不同的介质时，光线在界面发生偏折现象。
    1. **正视（emmetropia）：**眼调节的**放松状态**下，**无穷远处**的物体所成的像**正好聚焦在视网膜上**。
    2. **非正视（ametropia）/屈光不正（refractive error）**：包括**近视（myopia）、远视（hypermetropia）、散光（astigmatism）、老视（presbyopia）**。
2. 光线在界面的偏折程度可用**屈光力（refractive power）**表示，屈光力的大小用**焦距（f）**表示。**屈光度（diopter，D）**是屈光度的单位，即 **D=1/f**。 _1D=100_ 度。
3. 眼的**屈光力（refractive power）**和**眼轴长度（axial length）**是否匹配是决定屈光状态的关键。
4. 模型眼：
    1. Gullstrand 精密模型眼：**角膜 43D、晶状体 19D、视轴 24mm**。总屈光力：**静止 58.64D、最大 70.57D**。
    2. Emsley 简略眼：**总屈光力 60D**。
5. 眼的调节与集合：
    1. **调节（accommodation）：为看清近物而改变眼的屈光力。**
        1. 视**近**物时，睫状肌**收缩**，晶状体悬韧带**松弛**，晶状体变**凸**，屈光力**增强**。
        2. **调节幅度（amplitude，AMP）：**年龄越大，AMP 越小。最小调节幅度 **AMPmin=15-2.5×年龄**。
        3. 调节范围：**调节放松**的情况下，能看清的最远一点为**远点（far point）**，最近一点为**近点（near point）**，远点与近点的间距为**调节范围**。
    2. **集合（convergence）：**产生调节的同时会引起**双眼内转**。
    3. **近反应：调节（accommodation）、集合（convergence）、瞳孔缩小（miosis）**的三联动现象。

## （二）屈光不正与老视

1. **近视（myopia）：调节静止**时外界**平行光线**经眼的屈光系统后焦点落在**视网膜之前**。
    1. 分类：①**屈光性近视：**角膜/晶状体屈光度过大；②**轴性近视：**眼轴过长。
    2. 分度：**轻度≤-3.00D<中度≤-6.00D<重度**。
    3. **临床表现：**
        1. **单纯性近视：**近视力好，视远物模糊；集合功能减弱，易引起**外隐斜或外斜视**；**常<-6.00D**，

**无眼底病变**、用适当镜片**可矫正**。

1. **病理性近视（pathological myopia）：常>-6.00D**，除远视力差外，常伴**夜间视力差、飞蚊症、漂浮物、闪光感**等；常伴**巩膜葡萄肿**；眼底组织常伴**病理变化**，如**豹纹状眼底、漆裂纹、Fuchs斑、视网膜周边格子样变性、视网膜下新生血管**等，易发生**视网膜脱离、黄斑出血**等。
    
    1. **防治：**
        1. 中轻度：**凹透镜**矫正。
        2. 重度：光学矫正的基础上，重视定期**眼底筛查**，根据眼底病变进行相应处理。

1. **远视（hyperopia）：调节静止**时外界**平行光线**经眼的屈光系统后焦点落在**视网膜之后**。
    1. 分度：**轻度≤+3.00D<中度≤+5.00D<重度**。
    2. **临床表现：**

|**显性远视（manifest hyperopia）**|常规验光即可表现（即**无需**麻痹睫状肌/散瞳）|
|---|---|
|**隐性远视（latent hyperopia）**|**常规验光不易发现**，与睫状肌生理性紧张有关，会转为显性远视|
|**全远视（total hyperopia）**|**显性远视+隐性远视**（睫状肌麻痹下可接受最大凸透镜的度数）|
|**绝对性远视（absolute hyperopia）**|**调节无法代偿**的远视，即需要凸透镜矫正|
|**随意性远视（facultative hyperopia）**|**自身调节掩盖**的原始，但验光时可发现，会转为绝对性远视|

1. **并发症：**
        1. **屈光性弱视（refractive amblyopia）：高度远视且未予矫正的<6 岁**儿童。
        2. **内斜视（esotropia）：**集合功能增强，产生**内隐斜或内斜视**。
    2. 矫正：**凸透镜**，但**轻度且无症状者**无需矫正。

1. **散光（astigmatism）：眼球在不同子午线上屈光力不同**，形成**两条焦线和最小弥散斑**的屈光状态。
    1. 分类：两条子午线相互垂直者为**规则散光（regular ~）**，否则为**不规则散光（irregular ~）**。
        1. **顺规散光（astigmatism with the rule）：最大**屈光力主子午线位于 **90°±30°**。**最常见**。
        2. **逆规散光（astigmatism against the rule）：最大**屈光力主子午线位于 **180°~30°、150°~180°**。
        3. **斜轴散光（oblique astigmatism）：最大**屈光力主子午线位于 **30°~60°、120°~150°**。
        4. 逆规散光对视力影响比顺规散光**大**。
    2. **临床表现与治疗：**

|**☆分类**||**光学**||**治疗**|
|---|---|---|---|---|
|**单纯近视散光（simple myopic ~）**|   |一主子午线聚焦在**视网膜上**，另一在**之前**|   |**凹柱镜**|
|**单纯远视散光（simple hyperopic ~）**|   |一主子午线聚焦在**视网膜上**，另一在**之后**|   |**凸柱镜**|
|**复合近视散光（compound myopic ~）**|   |两主子午线聚焦均在**视网膜前**，先后不同|   |**凹球镜+凹柱镜**|
|**复合远视散光（compound hyperopic ~）**|   |两主子午线聚焦均在**视网膜后**，先后不同|   |**凸球镜+凸柱镜**|
|**混合散光（mixed astigmatism）**|   |一主子午线聚焦在**视网膜前**，另一在**之后**|   |**凹柱镜+凸柱镜**|
|c) 等效球镜：|**等效球镜度数=球镜度数+柱镜度数/2**|   |。|   |

d) 散光矫正原则：应**同时矫正度数和轴向**，**初配**时常用**等效球镜或散光欠矫**。

1. **屈光参差（anisometropia）：**双眼屈光参差<**1.00D** 为生理性，>**1.00D** 可出现视觉问题。
    1. 屈光参差患者，在非矫正情况下，总是存在**一眼清晰、一眼模糊**状态（双眼调节活动等同性）。
    2. 屈光参差完全矫正后，双眼视网膜上**成像大小不一**。一般**屈光参差>2.50D** 时出现**融像困难**，特别是佩戴**框架眼镜**者，**佩戴角膜接触镜可相对减轻**。
2. **老视（presbyopia）：**一种生理性显像，**睫状肌调节功能降低**，大约 **45 岁**开始，所有人均会出现。
    1. 早期：感觉将目标**放的远才看得清**，**光线不足**时更明显。
    2. 典型症状：**①视近困难；②阅读需要更多光；③视近不持久**。
    3. 危险因素：屈光不正（远视比近视跟易发）、用眼方式（精细工作者易发）、身体素质（身高高者易发）、地理位置（热带易发）、药物（胰岛素、抗焦虑抑郁/精神病药、抗组胺药、解痉剂、利尿剂）。

## （三）治疗

1. 屈光力的记录：e.g. **OD：-3.50DS / -1.50DC×165（右眼-3.50 球镜联合-1.50 柱镜，轴子午线 165°）**。
    1. **右眼 OD（R）、左眼 OS（L）、双眼 OU。**
    2. 远用 DV、近用 NV。
    3. **球镜度数 DS、柱镜度数 DC。**
    4. /：表示联合
2. **球镜、柱镜转换公式：①远球镜、柱镜代数和相加→球镜度数（不变号）；②柱镜度数变号，轴向变为正交轴向（原轴向≤90°，则+90°；原轴向≥90°，则-90°）。**

e.g. OD：-3.50DS / -1.50DC×165 ↔ OD：-5.00DC / +1.50DS×75。

1. **角膜接触镜（contact lens）/隐形眼镜：**接触镜与角膜接触，减少放大率问题，可利用泪膜矫正散光等。
2. **屈光手术：**
    1. **角膜屈光手术：**放射状角膜切开（RK）、角膜基质环植入术（Intacs）、准分子激光角膜切削术（PRK、准分子激光角膜原位磨镶术（LASIK）、微小切口角膜基质透镜取出术（SMILE）。
    2. **眼内屈光手术：**晶状体摘除（clear lens extraction）、有晶体眼人工晶体植入术（ICL）。
    3. **巩膜屈光手术：**后巩膜加固术（posterior scleral reinforcement）。
