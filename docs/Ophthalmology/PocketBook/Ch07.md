# 第 8 章 角膜疾病

## （一）概述

1. **角膜（cornea）：**从前向后分为**上皮层（可再生）、前弹力层（不可再生）、基质层（损伤后不再透明）、后弹力层（可再生）、内皮层（不可再生）**。上皮层表面覆盖**泪膜**。
    
    1. 角膜代谢所需的营养物质来自**房水**的葡萄糖和**泪膜**中弥散的氧。
    2. 光学特性：**中央接近球面，周围扁平**，总屈光力约 **43D**（占 74%）。
    3. 病理生理：角膜上皮是第一道屏障，易感染，**前弹力层、内皮层受损后不能再生，基质层受损后失去透明性**。角膜病变尤其是**中央部病变**将严重影响视力。角膜处于**免疫赦免状态**，病变时可失去。
2. **☆角膜炎（keratitis）**总论：
    1. 病因：感染性（细菌、病毒、真菌、寄生虫）、内源性（自身免疫性、缺乏 Vit A）、局部蔓延。
    2. 病理变化：
    
    	| **阶段**       | **病理**                                                     | **临床表现**                           |
    	| -------------- | ------------------------------------------------------------ | -------------------------------------- |
    	| **浸润期**     | **角膜混浊（corneal infiltration）**：局限性灰白色浑浊灶     | **刺激症状、视力下降（可恢复）**       |
    	| **溃疡形成期** | **角膜溃疡（corneal ulcer）**→角膜基质变薄→变薄区靠近后弹力层→**后弹力层膨出（descemetocele）**→病变穿破后弹力层→**角膜穿孔（corneal perforation）→房水涌出、虹膜脱出→位于中央的穿孔区不能愈合→**角膜瘘（corneal fistula） | 易继发**眼内感染**，可致眼球萎缩、失明 |
    	| **炎症消退期** | 炎症消退、溃疡减轻、基质坏死脱落停止                         | 症状、体征明显改善                     |
    	| **愈合期**     | 根据角膜溃疡深浅，常遗留厚薄不等的瘢痕<br />1. **角膜薄翳（corneal nebula）：薄**如云雾，**仍可看清虹膜纹理**；<br>2. **角膜斑翳（corneal macula）：**浑浊**厚**，瓷白色，**仍可看清虹膜纹理**；<br>3. **角膜白斑（corneal leucoma）：**浑浊**厚**，瓷白色，**不可看清虹膜纹理**；<br>4. **粘连性角膜白斑（adherent leucoma）：**角膜瘢痕组织中**镶嵌有虹膜**；<br>5. **角膜葡萄肿（corneal staphyloma）：**混杂有虹膜组织的**角膜瘢痕膨出形成紫黑色隆起**。 |                                        |
    
    	1. 内因性角膜炎：常发生在**角膜基质层**，**不引起角膜溃疡**，瘢痕位于角膜深层，可有**新生血管**
    	2. 严重的角膜炎可引起**虹膜睫状体炎**，多为**无菌性、反应性**。真菌在角膜未穿孔时也可侵入。
    
    3. 临床表现：**眼部刺激症状伴视力下降**。
    
    	1. **眼部刺激症状：眼痛、畏光、流泪、眼睑痉挛。**
    	2. **视力下降：**发生在**角膜中央区**的更明显。
    
    4. 裂隙灯检查：角膜上形成**粗糙的切面**，荧光素染色可显示上皮缺损区。
    
    5. 典型体征：**睫状充血、角膜浸润、溃疡形成**。
    
    6. 继发**虹膜睫状体炎：**房水闪辉、房水混浊、前房积脓、瞳孔缩小、虹膜后粘连等。
    
    7. **治疗原则：**控制感染、减轻炎症反应、促进溃疡愈合、减少瘢痕形成。
    
    	1. 细菌性角膜炎：敏感抗菌药；真菌性角膜炎：抗真菌药物（少）；HSV 角膜炎：抗疱疹病毒药。
    	1. **糖皮质激素：细菌性角膜炎急性期、真菌性角膜炎禁用**，细菌性角膜炎慢性期愈合后可用， HSV 角膜炎仅用于**非溃疡性角膜基质炎**。
    	1. 并发**虹膜睫状体炎：**轻者用短效**散瞳剂**，重者阿托品散瞳； **溃疡穿孔时应采取角膜移植**。

## （二）☆感染性角膜炎

1. **细菌性角膜炎（bacterial keratitis）：病情多较危重**，可导致角膜穿孔、眼内感染。
    1. 病原学：最常见的是**金黄色葡萄球菌、铜绿假单胞菌、肺炎链球菌、大肠杆菌**。
    2. 诱发因素：局部（**角膜外伤、剔除角膜异物、佩戴角膜接触镜、慢性泪囊炎、干眼**、局部使用糖皮质激素、眼表疾病、角膜上皮异常）、全省因素（老年、**Vit A 缺乏**、糖尿病、免疫缺陷、酗酒）。
    3. **临床表现：眼部刺激症状（畏光、流泪、疼痛、眼睑痉挛）、视力障碍**，眼睑、球结膜**水肿**，**睫状充血**或混合性充血。角膜上皮溃疡，溃疡表面**脓性分泌物**，可伴**前房积脓**。_G+_局限，_G-_易扩散！
        1. **金黄色葡萄球菌角膜炎：**常见于**已经发生病损的角膜，**圆形或椭圆形局灶性脓肿，周围**灰白色浸润区**，**边界清晰**。
        2. **肺炎链球菌角膜炎：**常见于**外伤或慢性泪囊炎**，表现为**中央基质深部**椭圆形溃疡，带**匍匐性边缘，后弹力膜有放射性褶皱**，常伴有**前房积脓、角膜后纤维素沉着**。
        3. **铜绿假单胞菌角膜炎：**常见于**角膜异物剔除或戴角膜接触镜**，**迅速发展**的角膜液化性坏死，起病急、病情重，伴严重混合性充血、球结膜水肿，**基质广泛液化性坏死**，溃疡表面**大量黏稠的脓性黄绿色分泌物**，溃疡周围**灰白色或黄白色浸润环**，伴大量前房积脓。
        4. **G-杆菌**引起的角膜炎症：**前房炎症反应轻微**。
        5. **奈瑟菌角膜炎：发展迅猛**，眼睑高度水肿、球结膜水肿、大量脓性分泌物，伴角膜基质浸润、坏死、溃疡，**新生儿**常致角膜穿孔。
    4. 诊断：**开始治疗前**，从浸润灶刮取病变组织，细菌培养+药敏试验。
    5. **治疗：**初诊患者**局部应用广谱抗生素或多种抗菌药物（头孢类+氨基糖苷类/喹诺酮类）**。
        1. **G+：头孢菌素**是首选药物，e.g. 头孢唑林。
        2. **G-：氨基糖苷类**是首选药物，e.g. 妥布霉素或庆大霉素。
        3. **链球菌、淋球菌：**首选**青霉素 G**，耐药者使用**头孢曲松**。
        4. 二线用药：万古霉素。 **喹诺酮+头孢类：**用于**威胁视力**的角膜炎。
        5. 最有效途径：**局部使用**抗生素。急性期**高浓度眼药水频繁滴眼**，**眼膏、凝胶**更适用于**儿童**。
        6. **结膜下注射：**一般效果不优于滴眼，适用于**角膜溃疡即将穿孔或滴眼液依从性不佳**。
        7. **全身应用抗生素：**一般不用，除非**向眼内或全身播散、巩膜化脓、角膜/巩膜穿孔等**。
2. **真菌性角膜炎（fungal keratitis）：温热潮湿**气候高发。
    1. 病因：主要由**曲霉菌、镰孢菌属、弯孢菌属、念珠菌**引起，**植物性外伤**是主要诱因。
    2. 临床表现：多有**植物性外伤**，或**长期使用激素、抗生素**病史。**起病缓慢，刺激症状轻**。
        1. 角膜浸润灶：白色/乳白色，**致密，表面欠光泽（牙膏样、苔垢样）**，周围有**免疫环**。有时周围可见**伪足或卫星样浸润灶**。前房积脓呈灰白色、糊状/黏稠。
    3. 诊断：实验室检查找到**真菌、菌丝**可确诊。角膜刮片、培养阴性者可考虑做角膜活检。
    4. 治疗：**局部使用抗真菌药物**，首选**两性霉素 B/氟康唑+那他霉素**联合用药，疗程至少 **6 周**。
        1. **丝状真菌：那他霉素**、伏立康唑；**酵母菌：两性霉素 B**、氟康唑、那他霉素。
        1. **一般不采用结膜下注射。 **
        1. **不宜使用糖皮质激素！**

3. *单纯疱疹病毒性角膜炎（herpes simplex keratitis，HSK）：**HSV 引起，**最常见的致盲性角膜病**。

    1. 病原学：**DNA 病毒**，眼部感染主要为 **HSV-1**。HSV 感染分为原发性、继发性。
    2. **原发性 HSV 感染：**常见于**幼儿**，眼部多不受累，表现为**滤泡性结膜炎、假膜性结膜炎、眼睑皮肤疱疹、点状/树枝状角膜炎**。主要为角膜上皮病变，临床症状不典型。
    3. **复发性 HSV 感染：**常有典型的临床表现。

        1. **上皮性角膜炎：最常见**（>2/3）。特点是**树枝状溃疡、地图样溃疡、角膜知觉减退**。
        2. **神经营养性角膜炎：**病因包括基底膜损伤、泪液分泌减少、神经受损，**抗病毒药物加重病情**。多发生在HSK 的**静止期或恢复期**，溃疡圆形或椭圆形，位于**睑裂区，浸润轻微**。
        3. **基质性角膜炎：**常伴**上皮性**角膜炎。

            - **免疫性基质性角膜炎：**最常见的类型是**盘状角膜炎**，角膜中央基质盘状水肿。

            - **坏死性基质性角膜炎：**角膜基质内黄白色坏死浸润灶、基质溶解坏死、上皮广泛性缺损。
        4. **角膜内皮炎：**分为**盘状（最常见）、线性、弥漫性**。
    4. 诊断：角膜刮片发现**多核巨细胞或细胞核内包涵体**，角膜病灶内分离到 HSV。
    5. **治疗：抑制 HSV 复制、减轻角膜损害**（_≠_根除_HSV_！）。

        1. **抗病毒药物治疗：**常用**更昔洛韦（GCV，首选）、阿昔洛韦（ACV）**等。
        2. **糖皮质激素治疗：免疫反应引起的基质角膜炎**。

4. **棘阿米巴角膜炎（acanthamoeba keratitis）：**棘阿米巴原虫引起，严重威胁视力。

    1. 临床表现：多与**角膜接触镜**使用有关，也与**角膜外伤、角膜移植、接触污染水源**等。
        1. 多为**单眼**发病，患眼**畏光、流泪、剧烈眼痛，视力减退**，病程**长**。
        2. 感染初期表现为**上皮浑浊、微囊样水肿、假树枝状**，少部分出现特征性的**放射状角膜神经炎**。
        3. 后期，出现**中央或旁中央环状浸润**，伴上皮缺损，也可表现为**中央盘状病变**。
    2. 诊断：角膜病灶取材，**涂片染色**找棘阿米巴原虫或**角膜刮片培养**棘阿米巴。
    3. 治疗：早期试行病灶区**角膜上皮刮除**，药物治疗选**氨基糖苷类**、聚双胍类、双咪/联唑/咪唑类，也可**口服伊曲康唑、酮康唑**。疗程>**4 月**。 **糖皮质激素一般不使用**。

## （三）非感染性角膜炎

|**类型**|**临床特点**|**治疗**|

## （四）其他

**==角膜变性（corneal degeneration）==：既往疾病**引起的角膜组织退行性变和功能减退。

|**类型**|**临床特点**|**治疗**|
|---|---|---|
|**角膜老年环**|角膜**周边部基质**内**类脂质**沉着，双侧发病<br>**白色环形浑浊，外侧清楚、内侧模糊**，与角膜缘间有**透明带**|无需治疗|
|**带状角膜病变**|**前弹力层钙化**变性，见于慢性葡萄膜炎、甲旁亢、CKD 等<br>**睑裂区角膜边缘**部**灰白色**钙质沉着→**带状浑浊**|治疗原发病<br>**Na2-EDTA**|
|**边缘性角膜变性**<br>**=Terrien 边缘变性**|无痛、畏光、视力进行性下降<br>角膜**边缘部变薄、扩张**，**鼻上象限**多见，变薄区可融合<br>易穿孔，变薄区有新生血管，进展缘类脂质沉积|**手术**治疗，药物无效|
|**角膜脂质变性**<br>|脂质在角膜的异常沉积，原发性、继发性<br>表现为**致密的灰色或黄白色**病灶，**无新生血管区域**|穿透性**角膜移植**术|
|**大泡性角膜病变**<br>|角膜内皮细胞功能障碍，引起**角膜基质水肿、上皮下水疱**<br>患眼**雾视**，**晨重**暮轻，重者刺激症状明显，水疱破裂时明显|局部**高渗剂**<br />角膜移植|

**==角膜营养不良（corneal dystrophy）==：基因异常**引起的角膜结果和功能的进行性损害。

|**类型**|**临床特点**|**治疗**|
|---|---|---|
|**上皮基底角膜营养不良**<br>**=地图-点状-指纹状营养不良**|自发性、反复性刺激症状、视力模糊<br>灰白色点/斑片/地图/指纹状细小线条|局部使用 5% NaCl 眼药水、眼膏，人工泪液等黏性润滑剂|
|**颗粒状角膜基质营养不良**|双眼视力下降，眼红、畏光<br>灰白色点状浑浊，合成团块，其间正常|晚期角膜移植|
|**Fuchs 角膜内皮营养不良**<br>**（→大泡性角膜病变）**|角膜后弹力层滴状赘疣，突出前房<br>后弹力层弥漫性增厚，内皮面色素沉着|间歇性角膜水肿时予高渗剂、糖皮质激素等|

==角膜先天异常==：

|**类型**|**临床特点**|
|---|---|
|**圆锥角膜（keratoconus）**|角膜中央/旁中央**锥形扩张**，角膜基质变薄，导致严重**散光、近视**，视力严重下降，难矫正，可见褐色 **Fleischer 环、Vogt 线纹、Muson 征（角膜褶皱）**|
|**大角膜（megalocornea）**|角膜直径比正常大，眼压、眼底、视力**正常**|
|**小角膜（microcornea）**|角膜直径比正常小，**多伴有其他先天性异常**|
|**扁平角膜（applanation）**|**角膜曲率低于正常**，常伴其他异常，导致**远视**|

1. 角膜接触镜的并发症：
    1. **中毒性结膜炎：**结膜充血、点状上皮脱落、糜烂。
    2. **过敏反应：**结膜充血、上皮点状角膜炎、上皮下浸润浑浊。
    3. **巨乳头结膜炎：上睑结膜>1mm** 的巨大乳头增生，类似春季卡他性结膜炎。
    4. **角膜上皮损害：**角膜中央上皮**水肿**，**灰白色浑浊（Satter 幕）**，可引起视力模糊。
    5. **角膜内皮变化：可逆**，内皮细胞大小不均，出现巨大细胞，失去六角形形态。
    6. **角膜新生血管：角膜周边部**多见，一般位于**浅层**，<2mm。
    7. **感染性角膜炎：细菌性**角膜溃疡最常见，可见真菌性、棘阿米巴性等。**最严重**的并发症。
2. 准分子激光角膜屈光手术的角膜并发症：
    1. **层间碎屑：**物质进入并滞留于层间，影响视力者需手术清除。
    2. **角膜神经营养性上皮病变：**角膜**知觉下降、营养障碍**，伴角结膜干燥。
    3. **弥漫性层间角膜炎（diffuse lamellar keratitis）/撒哈拉综合征：**角膜瓣界面弥漫性白色粉末状颗粒，可使用**糖皮质激素**治疗。
    4. **感染性角膜炎：**常见的致病菌为**非结核分枝杆菌**，其他如金葡菌、草绿色链球菌等。
    5. **进行性角膜扩张：**角膜进行性变薄、下方角膜变陡、角膜曲率增加，类似**圆锥角膜**。
