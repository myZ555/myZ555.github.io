# 第 11 章 青光眼

## （一）概述

1. **青光眼（glaucoma）：**一组以特征性**视神经萎缩、视野缺损**为共同特征的疾病，**病理性眼压增高**是主要危险因素。青光眼是**全球第二位的致盲眼病**。
    1. 正常眼压：**10~21mmHg**。双眼差异**<5mmHg**，昼夜波动**<8mmHg**。
    	1. 眼压>21mmHg 而**无视神经损害、视野缺损**的称为**高眼压症（ocular hypertension）**。
    	2. **眼压正常**，而有视神经损害、视野缺损的称为**正常眼压青光眼（normal tension glaucoma，NTG）**。
    2. 房水循环：**睫状体→后房→瞳孔→前房→①（【主】小梁网通道）前房角→小梁网→Schlemm 管**→静脉；②（葡萄膜巩膜通道）**前房角**→前房角睫状体→睫状肌间隙→睫状体、脉络膜上腔→出眼。
    3. 眼压高低取决于：**①房水生成速率；②房水通过小梁网流出的阻力；③上巩膜静脉压**。==青光眼的病因多是房水外流阻力升高/房水引流系统异常（开角型）/虹膜堵塞引流系统（闭角型）==。
    4. 视神经损害的机制：**机械学说**（视神经直接受压）、**缺血学说**（视神经供血不足）。

2. 青光眼的诊断：**眼压、房角（开角型/闭角型）、视野（金标准）、视盘（客观依据）**。

## （二）原发性闭角型青光眼（primary angle-closed glaucoma，PACG）

1. **==原发性闭角型青光眼（primary angle-closed glaucoma，PACG）==：周边虹膜堵塞小梁网/与小梁网永久性粘连，房水外流受阻**，引起眼压升高和视神经损害的一类青光眼。发病机制：
    1. **瞳孔阻滞型：**虹膜与晶状体紧密接触，房水越过瞳孔阻力增加，**后房压力增加，虹膜向前膨隆**，造成**前房角狭窄**。
    2. **非瞳孔阻滞型：**周边虹膜肥厚型、睫状体前位型。 c) 多种机制共存型。
2. **==☆急性闭角型青光眼（acute angle-closed glaucoma）==**：**房角突然关闭，眼压**急剧↑**。**>50 岁、女性**多见。
    1. 患者常有远视，双眼发病，情绪激动、暗室停留、抗胆碱药物、长时间阅读、疲劳、疼痛可诱发。
    2. **典型临床表现：**
    	1. 临床前期：无自觉症状，但具有**前房浅（e.g. ≤2.5CT）、虹膜膨隆、房角狭窄**等表现
    	2. 先兆期：一过性或反复的**小发作**；多在傍晚（**暗**），突感**虹视、雾视**，可伴患侧**额部疼痛、鼻根酸胀**检查发现**眼压>40mmHg**，前房浅，局部轻度充血，**角膜上皮轻度水肿**，**房水无浑浊**，**房角**关闭**，瞳孔轻度**扩大**（区别虹膜睫状体炎）、**对光反射迟钝**
    	3. 急性发作期：
    		1. **剧烈头痛、眼痛、畏光、流泪、视力严重减退（指数/手动）**，可伴恶心、呕吐
    		2. 体检：眼睑水肿、混合性充血、**角膜上皮水肿**（**→虹视**），角膜后色素沉着、前房极浅，虹膜缺血坏死→**房水混浊**，**瞳孔中等散大，对光反射消失**，房角**完全关闭**，较多色素沉着，**眼压>50mmHg**，眼底可见**视网膜 A 搏动、视盘水肿、视网膜血管阻塞**
    		3. 缓解后，**眼前段**留下永久性损伤，如扇形虹膜萎缩、色素脱失、局限性后粘连、瞳孔散大固定、房角广泛性粘连，**晶状体前囊下可见小片状白色浑浊（青光眼斑/Vogt 斑）**
    	4. 间歇期：**小发作**后自行缓解，房角重新开放，小梁网**未**受严重损害，不用药/少量缩瞳剂**可维持**眼压
    	5. 慢性期：**大发作或反复小发作**后，**房角广泛粘连，小梁功能严重损害，眼压中度升高**；眼底可见**青光眼性视盘凹陷、视野缺损**
    	6. 绝对期：高眼压持续过久，**视神经已受严重损害，视力无光感**、无法挽救
    3. 诊断：
    	1. 先兆小发作，可利用**暗室试验**检查
    	2. 大发作：**房角镜**检查证实房角关闭是重要的诊断依据。**加压房角镜**可鉴别虹膜根部是否与小梁粘连。
    	3. ==鉴别虹膜睫状体炎==（眼压下降后，房水混浊）：①**角膜后沉着物为棕色色素**而非灰白色细胞；②**前房极浅**；③**瞳孔扩大**而非缩小；④**虹膜节段性萎缩**；⑤可有**青光眼斑（Vogt 斑）**；⑥可有小发作病史；⑦对侧眼前房浅、虹膜膨隆、房角狭窄。
    	4. 急性虹膜睫状体炎多**无角膜上皮水肿**，眼压**低**、瞳孔**缩小**，前房可见**前房闪辉**、纤维素样渗出。

3. **==慢性闭角型青光眼（chronic angle-closed glaucoma）==**：房角粘连由点到面**逐步发展**，小梁网损害**渐进性**，眼压**逐步**升高。发病机制除了瞳孔阻滞，还有其他机制参与。无眼压急剧升高的症状（急性发作期），不易引起警惕，视野进行性损害。病程与原发性开角型青光眼相似，但视神经损害发展更快。
4. 诊断试验：
	1. **暗室试验：**暗室中静坐 1h，眼压升高≥8mmHg。
	2. **暗室俯卧试验：**暗室内俯卧 1.5h（眼球不受压），眼压升高≥8mmHg。

## （三）原发性开角型青光眼（primary open angle glaucoma，POAG）

1. **==原发性开角型青光眼（primary open angle glaucoma，POAG）==：**特点是眼压升高时**房角始终开放**。即：房水外流受阻发生于**小梁网-Schlemm 管**系统。
2. **☆临床表现：**
    1. **症状：**发病隐匿，少数出现**雾视、眼胀**等，多数无不适（**无痛性眼压升高**）。
    2. **眼压：**早期**波动性升高**（不是一直高！）；总体眼压**略高于**正常范围。
    3. **眼前节：**前房**正常或较深（_e.g. ≥4.0CT_）**，虹膜平坦（**无虹膜膨隆**），**房角始终开放**。
    4. **眼底：**①**视盘凹陷**进行性扩大、加深；②视盘上下方局限性盘沿变窄，**杯盘比（C/D）≥0.6 或双眼差值>0.2**；③视盘或盘周浅表**线状出血**；④视网膜**神经纤维层**缺如。
    5. **视觉功能：视野缺损**。典型的早期表现为**孤立的旁中心暗点和鼻侧阶梯**。后期，旁中心暗点发展为**弓形暗点，周边视野向心性缩小**，形成**象限型/偏盲型缺损**。晚期，仅残存**管状视野、颞侧视岛**。
3. 诊断：**眼压升高、视盘损害、视野缺损**三大指标，其中 **2 项+房角检查为开角**即可诊断。
4. **正常眼压青光眼（normal tension glaucoma，NTG）：**特征性的视盘损害和视野缺损，但眼压在正常范围内。可能与视神经本身缺陷、**对眼压耐受性下降**有关，多伴血管痉挛性疾病。

## （四）☆原发性青光眼的治疗



|**药物类别**|**代表药物**|**作用机制**|**临床应用**|
|---|---|---|---|
|**拟副交感药/缩瞳剂**|**毛果芸香碱（pilocarpine）**|缩瞳→接触阻塞→**开放房角**|**闭角型**青光眼**一线用药**|
|**β 受体阻滞剂**|**噻吗洛尔（timolol）**|**减少房水生成**|注意β 阻剂的禁忌症|
|**α2 受体激动剂**|**溴莫尼定（brimonidine）**|**减少房水生成**<br />促进房水经葡萄膜巩膜外流**||
|**前列腺素衍生物**|拉坦前列素、曲伏前列素|**促进房水经葡萄膜巩膜外流**|**开角型**青光眼**一线用药<br>**不宜联用毛豆芸香碱！|
|**碳酸酐酶抑制剂**|**乙酰唑胺（diamox）**|**减少房水生成**|不宜长期使用|
|**高渗剂**|50%甘油、**20%甘露醇**|吸收眼组织水分入血|**急性发作期**|

## （五）继发性青光眼（secondary glaucoma）

|**青光眼睫状体炎综合征**|眼压升高、**羊脂状角膜后沉积物**、房角开放、房水无浑浊，可自行缓解|
|---|---|
|**糖皮质激素性青光眼**|长期应用糖皮质激素者，类似原发性开角型青光眼|
|**眼外伤导致的青光眼**|与前房积血、小梁网损伤有关；特殊：溶血性青光眼/血影细胞性青光眼、房角后退性青光眼、继发性闭角型青光眼|
|**晶状体源性青光眼**|继发于白内障者，类似急性闭角型青光眼（白内障膨胀期）或急性开角型青光眼（白内障过熟期）/晶状体脱位（e.g. Marfan 综合征）/球状晶状体|
|**虹膜睫状体炎继发性青光眼**|房水无法通过瞳孔进入前房，**尘样 KP**|
|**新生血管性青光眼**|继发于广泛视网膜缺血，虹膜出现新生血管，房角关闭，眼压升高、剧痛|
|**睫状环阻塞性/恶性青光眼**|多见于**内眼手术**后，主要为后方的房水不能进入前房而后逆流、积聚|
|**视网膜玻璃体术后继发性~**|晶状体-虹膜隔前移（闭角型）、前房炎症堵塞小梁网（开角型）|
|**虹膜角膜内皮综合征（ICE）**|与疱疹病毒感染有关，进行性虹膜萎缩、虹膜痣综合征、Chandler 综合征|
|**色素性青光眼**|脱落色素沉积于小梁网，房水外流受阻（开角型），常染色体显性遗传|
