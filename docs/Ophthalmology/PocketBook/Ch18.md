# 第 19 章 眼外伤

## （一）概述

1. **眼外伤（ocular trauma）：**眼球及其附属器官因受外来的机械性，物理性或化学性伤害，发生各种病理性改变而损伤其正常功能者。分类：
    1. 按致伤因素：机械性；非机械性。 
    2. 按轻重程度：轻伤；中度伤；重伤。
    3. 新分类法：**闭合式（挫伤；板层裂伤）；开放式（破裂伤 eyeball repture；撕裂伤 laceration[贯通伤 penetrating wound、眼内异物 intraocular foreign body、穿通伤 perforating injury]）**。
2. **处理原则：**
    1. 首先抢救危及生命的脏器损伤。
    2. 穿通伤时切忌挤压眼球
    3. 化学伤**抓紧时间**大量水冲洗**。**
    4. 合理应用抗生素
    5. 开放性**损伤应注射**破伤风血清。

## （二）机械性眼外伤

1. **==☆眼球钝挫伤（blunt trauma）==：**机械性钝力引起，可造成多处间接损伤。
    1. **角膜挫伤：**
        1. **角膜上皮擦伤：疼痛、畏光、流泪伴视力减退**。可致角膜溃疡。 涂**抗生素眼膏**后**包扎**。
        2. **角膜基质层水肿：**角膜基质层增厚、水肿浑浊，后弹力层褶皱。 **糖皮质激素/高渗剂**滴眼。
    2. **虹膜睫状体挫伤：**
        1. **虹膜与瞳孔异常：**①**虹膜瞳孔缘撕裂、瞳孔括约肌断裂**；②**虹膜根部离断（iridodialysis）**——虹膜根部半月形缺损、**瞳孔 D 字形**，可伴单眼复视；③**外伤性瞳孔扩大：**中度扩大，瞳孔**不圆**，对光反射迟钝；④**睫状肌、支配神经受损：**调节麻痹、视近物障碍。治疗：瞳孔缘或基质裂口无需处理；虹膜缝合术；戴眼镜矫正视力。
        2. **前房积血（hyphrema）：**【少量】房水中出现红细胞；【较多】**液平面**——<1/3 为 I 级，1/3~2/3为 II 级；>2/3 为 III 级；【严重】房水**黑色**。多能自行吸收，但积血量大时可有**吸收中再次出血、继发性青光眼**。角膜内皮损害、高眼压、出血多可导致**角膜血染（blood staining of cornea）**，角膜机制棕黄色、中央盘状浑浊，逐渐褪色，严重者角膜无法恢复透明。
        	1. 处理：**半卧位，糖皮质激素**滴眼，**_5_ 天后**才可散瞳，应用降眼压药物，必要时凝血块切除术。
        3. **外伤性青光眼：**可为开角型或闭角型，发生继发性青光眼者需药物或手术治疗。
        	     2. **外伤性低眼压：**常因**睫状体分离**引起。表现为**视力下降、视物变形、前房变浅、视盘水肿、视网膜静脉扩张、黄斑水肿、星状皱纹、眼轴变短**。可引起黄斑、视神经功能损害。
        		     1. 处理：1%**阿托品散瞳**，口服**糖皮质激素**。药物无效者，手术缝合睫状体。
    3. **晶状体挫伤：**
        1. 晶状体脱位、半脱位：晶状体悬韧带**全部或部分断裂。瞳孔区可见部分晶状体赤道部，可有**虹膜震颤、散光、单眼复视**。晶状体全脱位时，可脱入前房，导致**继发性青光眼、角膜内皮损伤**；或脱入后房，出**现前方变深、虹膜震颤、高度远视**。 需手术治疗。
        2. 外伤性白内障：晶状体浑浊，常伴晶状体脱位或半脱位。 必要时手术治疗。
    4. **玻璃体积血：**睫状体、视网膜、脉络膜出血引起；出血量大、无法观察时需做 **B 超**检查。处理：有黄斑损伤、脉络膜破裂、视网膜脱离时，需手术治疗。
    5. 脉络膜、视网膜挫伤：
        1. **脉络膜破裂（choroidal rupture）：**多位于**后极、视盘**周围，弧形，凹面对向视盘，出血吸收后显露出**白色瘢痕**，延伸到黄斑中心的破裂严重影响视力，破裂处可出现新生血管。
        2. **视网膜震荡、挫伤：**外伤后**后极部**出现**一过性视网膜水肿、视网膜变白、视力下降**。处理：**伤后早期大剂量糖皮质激素**治疗。
        3. **外伤性黄斑裂孔：**多为全层，因局部挫伤坏死、玻璃体牵拉导致，少数出现**视网膜脱离**。
        4. **锯齿缘断裂：**眼外伤引起**视网膜脱离**的典型形式。 需行巩膜外垫压术、玻璃体手术等。
    6. **眼球破裂：**常见于角巩膜缘或眼外肌下，常有**眼组织脱出或嵌顿**。眼压降低，前房或玻璃体积血，球结膜出血、水肿，角膜变形，眼球运动受限，视力差。 辅助检查：**B 超、CT**。
    7. **隐匿性巩膜破裂伤（occult scleral rupture）：**破裂位于眼外肌下或后部巩膜，外部检查不易发现。专科处理：初期**眼球缝合术**，术后用**抗生素、糖皮质激素**，术后根据情况行**玻璃体手术**。

2. **==☆眼球贯通伤==：由锐器刺入、切割眼球壁的全层裂开**，伴或不伴眼内容物的脱出。
	1. 分类与临床表现：
		1. **角膜穿通伤：**①**单纯性：**伤口小、可自行闭合；②**复杂性：**伤口大，常伴**虹膜脱出、嵌顿，前房变浅**，可伴晶状体破裂、白内障、眼后段损伤。
		2. **角巩膜穿通伤：**可引起**虹膜睫状体、晶状体、玻璃体**损伤脱出，**眼内出血**，伴**眼痛、刺激症状、视力下降**。
		3. **巩膜穿通伤：**较小的仅可见结膜下出血，大的常伴**脉络膜、玻璃体、视网膜**损伤出血。
	2. 治疗：伤后**立即包扎伤眼**，两部手术——①初期**缝合**伤口；②**防治感染**等；③必要时**二期手术**。
	3. 并发症：
		1. **外伤性感染性眼内炎（traumatic endophthalmitis）：**主要由 **G+**引起，**眼痛、头痛、眼部刺激症状、视力下降**。球结膜充血水肿，角膜混浊，前房炎症/积脓，玻璃体雪球样浑浊/脓肿形成。处理：局部、全身应用**大剂量抗生素和糖皮质激素（e.g. 万古霉素 1mg+头孢他啶 2mg+地塞米松 0.4mg）**，需先做细菌培养、药敏试验。**玻璃体腔内注药**是有效办法。*对于严重感染，需**紧急行玻璃体切割、玻璃体内药物灌注**；炎症控制不良者可重复。**
		2. **交感性眼炎（sympathetic ophthalmia）：一眼**开放性眼外伤/内眼手术后发生**双侧肉芽肿性葡萄膜炎**。临床表现为**伤眼的葡萄膜炎持续不退**、一定**潜伏期**后**另一眼出现类似的葡萄膜炎**。预防：伤后**早期缝合伤口，切除或还纳眼组织**。 处理：按葡萄膜炎予**糖皮质激素、散瞳**治疗。
		3. **外伤性增生性玻璃体视网膜病变：**过度的修复反应，**纤维组织增生引起牵拉视网膜脱离**。

3. **==眼异物伤==：**多为**铁磁性金属物质**。

	1. **眼球外异物：**
		1. *眼睑异物：**多见于爆炸伤。 对较大的异物，用镊子钳出。**
		2. 结膜异物：**多隐藏在睑板下沟、穹隆部、半月褶皱，可引起**刺激症状**。处理：表面麻醉后用**盐水棉签**拭出异物。**
		3. 角膜异物：**有**明显的刺激症状（畏光、流泪、刺痛、眼睑痉挛）**，铁质可引起锈斑。**
			1. 处理：浅层的，表面麻醉后**盐水棉签**拭出异物；较深的，**无菌注射针头**剔除；进入前房的，**显微手术摘除**异物，必要时缝合角膜。
		4. **眶内异物：**引起**局部肿胀、疼痛**，可形成眼眶蜂窝织炎、瘘管，一般**不必勉强摘除**。
			1. 手术指征：①眼眶与鼻窦/颅脑**沟通**；②异物**引起组织反应**、不易愈合；③异物大，表面粗糙，临近视神经等**重要结构**；④**铜或植物性**异物。

	2. **眼内异物（intraocular foreign body）：**
		1.  **铁质沉着症（siderosis）：**铁易在上皮组织、瞳孔括约肌/开大肌、无色素睫状上皮、晶状体上皮、视网膜沉着，易影响**光感受器、色素上皮细胞**。损害后引起**夜盲、向心性视野缺损、失明**。
		2. **铜质沉着症（chalcosis）：**典型表现为**角膜后弹力层沉着**，**绿色房水颗粒**，**虹膜**变**绿色**，**向日葵样白内障**，**棕红玻璃体混浊**，条索形成，**视网膜血管上、黄斑区有金属斑**。
	3. 诊断：**穿通伤**的体征+**角膜线状伤口、全层瘢痕、虹膜相应位置穿孔、晶状体局限性浑浊**表明有异物进入眼内。必要时做前房角镜、三面镜检查。 影像学：**X 线、B 超、CT、超声生物显微镜**。
	4. 治疗：**尽早手术取出**。
		1. **前房、虹膜异物：**靠近异物方向，**角膜缘切口**取出。磁性物质可用电磁铁吸引。
		2. **晶状体异物：晶状体浑浊者，连同异物摘除**。
		3. **眼后段异物：**异物较**小**、已完全**包裹**，**不必勉强取出**。采用**外路法或玻璃体手术**取出异物。

4. **==眼附属器、视神经外伤==**：

	1. **眼睑外伤：眼睑挫裂伤**（处理：先冷敷，再热敷，尽早清创缝合）、**泪小管断裂**（需手术）。
	2. **眼眶外伤：眼眶骨折、眼眶穿通伤**（处理：清创缝合，必要时眶减压术）**、眶出血**（处理：早期冷敷/加压包扎，后期湿热敷，应用止血药物、抗生素）**、眶气肿**（绷带加压，避免用力/急促呼吸）。
	3. **视神经外伤：**①**视神经挫伤/外伤性视神经病变（traumatic optic neuropathy）：**视力障碍、视神经萎缩，预后差；②**视神经撕脱（avulsion of the optic nerve）：**视力完全丧失，无有效治疗。

## （三）非机械性眼外伤

1. **酸碱化学伤（chemical injuries）：**
    1. 损伤机制：①**酸性烧伤（acid burns）：**对蛋白质有凝固作用，组织损伤**相对较轻**；②**碱性烧伤*（alkaline burns）：**可溶解蛋白质、脂肪，**烧伤后果更严重**。
    2. 临床表现：
    	1.  **轻度：眼睑、结膜**充血水肿，**角膜上皮**点状脱落、水肿。数日后恢复，**不留瘢痕、并发症**。
    	2. **中度：眼睑**水疱、糜烂，**结膜**水肿、小片缺血坏死，**角膜明显**浑浊、水肿，上皮层完全脱落或形成白色凝固层。 治愈后可遗留**角膜斑翳，影响视力**。
    	3. **重度：强碱**引起，**结膜广泛**缺血性坏死，**角膜全层**灰白色、溃疡穿孔，可引起**葡萄膜炎、继发性青光眼、白内障**等。可遗留**角膜白斑、粘连性角膜白斑、角膜葡萄肿眼球萎缩，视力丧失**。
    3. **☆急救：现场大量清水彻底冲洗眼部，>30min**，应翻转眼睑、转动眼球、暴露穹隆部。
    4. 早期治疗：①**抗感染**；②1%**阿托品散瞳**；③**糖皮质激素**（局部/全身）；④**降眼压**药物。
    	1. 可应用：EDTA（石灰烧伤）、胶原酶抑制剂（防止角膜穿孔）、半胱氨酸滴眼液、四环素类、Vit C。
    5. 晚期治疗：针对**并发症**进行。如角膜移植、药物降低眼压等。

2. **眼部热烧伤（thermal burns）：**眼睑红斑、水疱，结膜充血、水肿，角膜轻度浑浊，严重者组织坏死。处理原则：防止感染、粘连，促进创面愈合，局部应用**散瞳剂、抗生素，去除坏死组织**。
3. **辐射性眼损伤（radiation injuries）：**电磁波、放射线。
	1. **可见光损伤：日光性视网膜病变（solar retinopathy）/视网膜的光损伤（photic injury）**。
	2. **紫外线损伤（ultraviolet radiation injury）/电光性眼炎（electric ophthalmia）/雪盲**。
	3. **离子辐射性损伤：**X 线、γ 射线、中子束、质子束可引起**放射性白内障、视网膜病变、视神经病变、角膜炎、虹膜睫状体炎**等。
