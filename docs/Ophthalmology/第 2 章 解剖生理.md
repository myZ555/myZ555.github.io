# 第 2 章 解剖生理

## （一）解剖学与组织学

1. **眼球**：近似球形，前面是 **透明的角膜（cornea）** ，其余为 **乳白色的巩膜（sclera）**。
	- 眼球前后径：新生儿 **16mm**，3 岁时 23mm，**成年人 24mm**；垂直径约 **23mm**。前后径 **±1mm↔±1D**。
	- 眼球向前平视时，一般 **突出外侧眶缘 12~14mm，两眼球突出度相差<2mm**。
2. 眼球壁：
	1. **外层——纤维膜**: 主要由 _胶原纤维组织_ 组成，保护眼内组织、维持眼球形态。
	        1. ==角膜（cornea）==: 眼球前部中央，略向前凸，透明。 屈光度约 _43D_。
		        - 组织学分层：上皮细胞层（非角化鳞状上皮）、前弹力层（Bowman membrane）、基质层（胶原纤维）、后弹力层（Descemet membrane）、内皮细胞层。
	        2. ==巩膜（sclera）==: 质地坚韧，乳白色，由 **胶原纤维** 组成。前接角膜，后部与视 N 交接处分 2 层（外 2/3 移行于视 N 鞘，内 1/3 网眼状——**巩膜筛板**——视 N 纤维束穿入眼球）。
		        - 组织学分层：表层巩膜（**致密血管结缔组织、巩膜内血管丛**）、巩膜实质、棕黑板层。**巩膜导管** 内有 A、V、N 通过，其余部分 **无血管**
		        - 巩膜表面被 **眼球筋膜（Tenon capsule）** 包裹，前面又被 **球结膜** 包裹，于 **角膜缘** 处相互融合。
		        - **角膜缘（limbus）**：角膜、巩膜移行处。生理意义：**①前房角、房水引流系统所在部位；②内眼手术切口标志；③角膜干细胞存在之处；④易破裂**。
		        - **前房角（anterior chamber angle）**：位于周边角膜与虹膜根部的连接处。
			    1. 角膜缘内面的凹陷为 **巩膜内沟**，沟内有 **小梁网、Schlemm 管**。沟的后内侧突出部分为 **巩膜突**。
			    2. **前房角是房水排出眼球的主要通道。**
	    2. **中层——葡萄膜（uvea）**: 富含黑色素和血管
	        1. 虹膜（iris）: 自睫状体伸展到晶状体前面，将眼球前部腔隙分为 **前房、后房**。虹膜中央圆孔为 **瞳孔（pupil）**， 直径 **2.5~4mm**。距瞳孔缘约 1.5mm 的虹膜卷缩轮将虹膜分为瞳孔区、睫状区。虹膜根部易受伤离断。
		        - 组织学：由前面的 **基质层（内含 A、V、N，瞳孔括约肌）** 和后面的 **色素上皮层（内含瞳孔开大肌）** 组成。
	        2. 睫状体（ciliary body）: 虹膜根部与脉络膜之间，基底部附着于 **巩膜突**。前 1/3 称为睫状冠（pars plicata ）， 内含 **睫状突（ ciliary processes）**；后 2/3 为扁平部（pars plana），为视网膜、玻璃体手术入路，与脉络膜连接处称锯齿缘。
			- 组织学：主要由 **睫状肌（平滑肌，外纵/中放射/内环，受副交感 N 支配）、睫状上皮细胞** 组成。
	        		- 功能：①形成 **房水**；②调节 **晶状体曲度**。
	        3. 脉络膜（choroid）: 锯齿缘~视乳头，介于视网膜、巩膜之间，内含 **血管、黑色素**，由 **3 层** 血管组成（**外层大血管/中层中血管/内侧小血管**），借 **玻璃膜（Bruch membrane）** 与视网膜色素上皮相连。
	    3. **内层——视网膜（retina）**: 后极部的 **无血管** 凹陷区成为 **中央凹（fovea）/黄斑（macula lutea）**，富含黄色素，其中央的小凹成为 **中心小凹（fovleola）/黄斑中央凹（fovea centralis）**，是视网膜上 **视觉最敏锐** 之处。
		1. **视盘（optic disc）/视乳头（optic papillae）**：距离黄斑 **鼻侧** 3mm，是视网膜神经节细胞轴突汇聚成 **视神经** 之处。视盘中央的小凹陷区称为 **视杯/杯凹（optic cup）**。视盘上有 **视网膜中央 A、V** 通过。杯盘比（_C/D_）_<0.6_，双眼差_<0.2——_杯盘比升高是原发性开角型青光眼的诊断标准
		2. 组织学：①**视锥、视杆层**（光感受器细胞内、外节）；②**外界膜**；③**外核层**（光感受器细胞核）；④**外丛状层**；⑤**内核层**（双极细胞、水平细胞、无长突细胞、Muller 细胞的核）；⑥**内丛状层**；⑦**神经节细胞层**（神经节细胞核）；⑧**神经纤维层**（神经节细胞轴突）；⑨**内界层**。
		3. **光感受器细胞**：外节、连接绒毛、内节、体、突触，视锥细胞、视杆细胞。
		4. **神经冲动传递：光感受器细胞→双极细胞→神经节细胞→视神经。**
3. **眼球内容物**：房水、玻璃体、晶状体。
	1. **房水（aqueous humor）**：充满**前房（anterior chamber）、后房（posterior chamber）**——**瞳孔**为界。
	2. **晶状体（lens）：双凸透镜**，由晶状体悬韧带、睫状体冠部联系固定。 屈光度约 _19D_。
		- 晶状体由**晶状体囊和晶状体纤维**组成。随年龄增长，晶状体**弹性减弱**（屈光度调节能力_↓_）。
	3. **玻璃体（vitreous body）：**透明胶质体，充满玻璃体腔，占眼内容物容积的 **4/5**。玻璃体前面有晶状体凹，其他部分与视网膜、睫状体相贴。
4. 眼附属器：
    1. **眼眶（orbit）：**由**额骨、蝶骨、筛骨、腭骨、泪骨、上颌骨、颧骨**组成。
        1. **视神经孔（optic foramen）、视神经管（optic canal）：**通过**视 N、眼 A**、交感 N 纤维。
        2. **眶上裂（superior orbital fissure）：**通过**动眼 N、滑车 N、展 N、三叉 N 眼支（第 1支）**、眼上 V、交感 N 纤维。
        3. **眶下裂（inferior orbital fissure）：**通过**三叉 N 上颌支（第 2 支）、**眶下 N、眶下 V。
        4. 眶上切迹/孔：通过眶上 N、三叉 N 眼支（第 1 支）、血管、
        5. 眶下孔：通过眶下神经、三叉N 上颌支（第 2 支）。
        6. 其他：泪腺窝、滑车窝、泪囊窝、泪前嵴。
    2. **眼睑（eye lids）：**位于眼眶前部，分**上睑、下睑**。游离缘称为**睑缘（palpebral margin）**，上、下睑缘之间的裂隙称为**睑裂（palpebral fissure）**，内外连接**内眦、外眦**。内眦处的肉样隆起称为**泪阜**。
        1. 睑缘有**前唇、后唇**。前缘有睫毛、皮脂腺（Zeis 腺）、变态泪腺（Moll 腺），后缘接触眼球。
        2. 灰线与后缘之间有**睑板腺开口**。上下睑缘内侧的乳头状突起上有**泪点**。
        3. 从外向内：①**皮肤**；②**皮下组织**；③**肌层**（**眼轮匝肌**_-_面 _N_ 支配、**上睑提肌**_-_动眼_N_ 支配）；④**睑板层**（内含**睑板腺**，与**睑缘垂直**_——_切口设计）；⑤**结膜层**（睑结膜）。
        4. 血供：来自颈外动脉-**面动脉**、颈内动脉-**眼动脉**，形成睑缘动脉弓；浅静脉回流入颈内、颈外 V，深静脉会流入**海绵窦**。

16. **结膜（conjunctiva）：**覆盖于眼睑后面（**睑结膜 palpebral conjunctiva**）、部分眼球表面（**球结膜 bulbar conjunctiva**）、眼睑到眼球的折返部分（**穹隆结膜 fornical conjunctiva**）。三个部分的结膜形成囊状间隙，称为**结膜囊（conjunctival sac）**。
        1. 血供：来自眼睑 A 弓、睫状前 A。
        2. 神经支配：**三叉 N-眼 N** 支配感觉。
    2. **泪器（lacrimal apparatus）：**泪腺、泪道。
        1. **泪腺（lacrimal gland）：**位于**眼眶外上方的泪腺窝**，泪腺排出管开口于**外侧上穹隆结膜**。血供来自于颈内 A-**眼 A**-泪腺 A；受三叉 N-眼N 的交感纤维、面 N 的副交感纤维、颅内动脉丛的交感纤维支配。 
    2. **泪道（ lacrimal passages ）：** 包括**泪点** （lacrimal puncta，位于上下睑缘后唇）、**泪小管**（lacrimal canaliculi，泪点~泪囊）、**泪囊**（lacrimal sac，位于泪囊窝）、**鼻泪管**（nasolacrimal duct，开口于**下鼻道**）。

1. **眼外肌（extraocular muscle）：**上直肌、下直肌、内直肌、外直肌、上斜肌、下斜肌。

|**眼外肌**|**主要动作**|**次要动作**|**神经支配**|

|**内直肌**|**内转**|无|**动眼神经（III）**|
|**外直肌**|**外转**|无|**展神经（VI）**|
|**上直肌**|**上转**|内转、内旋|**动眼神经（III）**|
|**下直肌**|**下转**|内转、外旋|**动眼神经（III）**|
|**上斜肌**|**内旋**|下转、外转|**滑车神经（IV）**|
|**下斜肌**|**外旋**|上转、外转|**动眼神经（III）**|

1. **视路（visual pathway）：视神经→视交叉→视束→外侧膝状体→视放射→枕叶视觉中枢。**
    1. **视神经（optic nerve）：**眼内段（视神经乳头）、眶内段、管内段、颅内段。
    2. **视交叉（optic chiasm）：鼻侧交叉，颞侧不交叉**。
    3. **视束（optic tract）：**下半部分视网膜的纤维位于外侧，上半部分视网膜的纤维位于内侧。

## （二）生理生化

1. **泪膜（tear film）：**覆盖于眼球前面的一层液体，分为眼球前泪膜、角膜前泪膜，分**脂质层、水液层、黏蛋白层**。生理作用：润滑、防止干燥、保持角膜光学特性、供氧、冲洗、抗感染、抵御异物等。
2. **瞳孔光反射（light reflex）：**包括直接对光反射（同侧）、间接对光反射（对侧）。
	- 传导通路：视 N→视交叉→视束→四叠体上丘臂→中脑顶盖前核→双侧 E-W 核→动眼 N→睫状 N 节。
3. **瞳孔近反射（pupil near reflux）：**视近物时**瞳孔缩小、调节、聚合**。
	- 传导通路：……→枕叶视皮层→枕叶-中脑束→E-W 核、内直肌核→动眼 N→效应肌。
4. **房水循环：睫状体→后房→瞳孔→前房→前房角→小梁网→Schlemm 管**→集液管、房水 V→睫状前 V。

## （三）眼科用药

1. 常用剂型：

| **类型**                          | **用法用途**                                                       | **特点**                                |
| ------------------------------- | -------------------------------------------------------------- | ------------------------------------- |
| **滴眼液（eyedrop）**                | 滴于下方结膜囊内                                                       | 只有少量药物被吸收                             |
| **眼膏（ointments）/油膏**            | **脂溶性**药物                                                      | 优点：**润滑、衬垫**作用<br><br>缺点：造成**视物模糊**   |
| **眼周注射（periocular injection）**  | 结膜下注射（**眼前段**病变）、球旁注射（**虹膜睫状体**病变）、球后注射<br><br>（**眼后段、视神经**疾病） |                                       |
| **眼内注射（intraocular injection）** | 前房内注射、玻璃腔内注射                                                   | 剂量、浓度小，疗效好<br><br>用于**感染/炎症、视网膜黄斑疾病** |
