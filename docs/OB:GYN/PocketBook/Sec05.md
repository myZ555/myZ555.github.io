# 生殖医学与计划生育

#### （一）不孕症（infertility）

## 不孕症与辅助生殖技术

- 1. **不孕症（infertility）：**女性无避孕性生活至少 12 个月而未孕。男性称为**不育症**。
2. 病因：
1. **女方因素：**①**盆腔因素（最主要）**-输卵管病变、盆腔粘连、盆腔炎症、子宫病变、子宫内膜异位症、先天性发育畸形；②**排卵障碍**-下丘脑病变、垂体病变、卵巢病变等。
2. **男方因素：**精液异常、性功能障碍等。 c) **不明原因不孕：**男女双方因素均不能排除。
3. 诊断：
1. **男方：**病史采集、体格检查、精液分析（正常值：**精液量 2~6mL**、pH 7.0~7.8、**液化时间 30min、精子密度≥20×109/L、精子活力≥50%**）。
2. 女方：病史采集、体格检查、**妇科 B 超、性激素测定、子宫输卵管造影（评价输卵管通畅性）**。
4. 治疗：
1. 针对输卵管病变：**输卵管成形术**，适用于**输卵管周围粘连、远端梗阻、轻度积水**。
2. 子宫病变、卵巢肿瘤、子宫内膜异位症：建议手术治疗。 c) 生殖器结核：抗结核治疗。

1. **诱导排卵：氯米芬（clomiphene）、hMG、hCG、来曲唑**（letrozole，抑制 T→E，使 Gn 分泌↑）。
2. 不明原因不孕症：**年轻、卵巢功能好者期待 3 年；>30 岁、卵巢功能开始衰退者宫腔内人工授精**。

### （二）辅助生殖技术（assisted reproductive techniques，ART）

- 1. **辅助生殖技术（assisted reproductive techniques，ART）：**

| | | |
|---|---|---|
|**技术**|**方法**|**临床应用**|
|**人工授精（artificial insemination，AI）**|将精子通过**非性交方式**注入<br><br>女性生殖道内（夫精、供精）|**夫精：宫腔、宫颈、阴道**疾病<br><br>**供精：**男方精液因素|
|**体外受精-胚胎移植（IVF-ET）**|药物刺激卵巢→监测卵泡发育成熟→取卵→培养液中受<br><br>精→体外培养 3~5 日→植入|**输卵管性不孕症、不明原因不孕症、子宫内膜异位症、男性不**<br><br>**孕症、排卵异常、宫颈因素**|
|**卵胞浆内单精子注射（ICSI）**|刺激排卵、取卵+显微注射|严重**少/弱/畸形精子、梗阻性无**<br><br>**精子**、体外受精失败、顶体异常|
|**胚胎植入前遗传学诊断/筛查（PGD/PGS）**|对体外受精胚胎进行细胞、<br><br>分子遗传学分析|**遗传病、染色体病**等|
|**配子移植技术**<br><br>**（输卵管内 GIFT、宫腔内 GIUT）**|男女生殖细胞取出，经适当<br><br>处理后植入女性体内|**双侧输卵管梗阻、缺失**|

- 1. **体外受精-胚胎移植（_in vitro_ fertilization and embryo transfer，IVF-ET）**：
1. **控制性超促排卵（controlled ovarian hyperstimulation，COH）：**用药物在可控制的范围内诱发多卵泡同时发育成熟，以获得更多高质量的卵子，从而获得更多可供移植的胚胎，提高妊娠率。
2. 并发症：
1. **卵巢过度刺激综合征（ovarian hyperstimulation syndrome，OHSS）：**轻度表现为腹胀、卵巢增大，重度表现为大量腹腔积液、胸腔积液、血液浓缩、血栓形成等严重并发症。
2. **多胎妊娠：**增加母婴并发症、流产、早产几率，增加围产儿患病率、死亡率。

## 计划生育

#### （一）避孕（contraception）

1. **宫内节育器（intrauterine device，IUD）：**惰性宫内节育器（第一代 IUD）、活性宫内节育器（IUD）。
1. 避孕原理：①对精子、胚胎的**毒性作用**；②**干扰着床**（主要）。
2. 禁忌症：①**妊娠**或可疑妊娠；②生殖道**急性炎症**；③人流出血多或怀疑妊娠组织物残留、感染，中期妊娠引产、分娩、剖宫产胎盘娩出后，子宫收缩不良或潜在感染可能；④生殖器肿瘤；⑤生殖器畸形；⑥宫颈内口过松、重度陈旧性宫颈裂伤或子宫脱垂；⑦严重的全身性疾病；⑧**宫腔<5.5cm或>9.0cm**；⑨仅 3 个月**月经失调、阴道不规则流血、月经量多**；⑩铜过敏史。
3. 放置时间：①**月经干净 3~7 日**无性交；②产后 42 日恶露已净；③自然流产转经后放置，药流 2 次正常月经后放置；④哺乳期放置排除早孕；⑤性交后 5 日内放置（紧急避孕）。
4. 副作用：常见**不规则阴道流血**，表现为**经量增多、经期延长、少量点滴出血**，一般无需处理。
5. 取出指征：①不再需要避孕；②防止期限已满；③**绝经过渡期，停经 1 年以内**；④改用其他措施避孕或绝育；⑤**并发症、副作用**；⑥**带器妊娠**。
6. 取器时间：①**月经干净 3~7 日**；②带器妊娠人流/诊刮时取出；③子宫不规则出血者随时可取。
2. **激素避孕（hormonal contraception）：**女性使用甾体激素达到避孕。

#### 避孕机制：抑制排卵、改变宫颈黏液性状、改变子宫内膜形态功能、改变输卵管功能。

- 1. 分类：口服避孕药（复方短效口服避孕药 COC、复方长效口服避孕药）、长效避孕针、探亲避孕药、缓释避孕药。
2. **禁忌症：**①严重**心血管疾病、血栓**性疾病；②严重**肝、肾**功能不全；③恶性**肿瘤**、癌前病变、④内分泌疾病（糖尿病、甲亢）；⑤**哺乳期**；⑥>35 岁的吸烟妇女；⑦精神病患者；⑧严重偏头痛。
3. 副作用：
1. **类早孕反应：**食欲缺乏、恶心呕吐、头晕乏力等，一般**无需特殊处理**，坚持服药数周即消失。
2. **不规则阴道流血：轻者**点滴出血，**不用处理**；**流血偏多**者，每晚服用避孕药时**加服雌激素**，或在流血时间**接近月经期时停止服药**。
3. 其他：闭经、体重增长、皮肤色素沉着、头痛、乳房胀痛、复视等。

1. **紧急避孕（emergency contraception）：**无保护性生活后几小时或几日内，为防止非意愿性妊娠而采取的补救措施。方法包括**宫内节育器（5 日内放置）、紧急避孕药（72 小时内服用）**等。
2. 外用避孕：**阴茎套/避孕套（condom，首选）**、阴道套、外用杀精剂、安全期避孕（排卵前后 4~5 日避免性生活）等。
3. **输卵管绝育术：**经腹输卵管结扎术（tubal sterilization operation）、经腹腔镜输卵管绝育术。
1. 禁忌症：①T≥37.5℃；②全身状况不佳；③严重的神经官能症；④各种疾病急性期；⑤腹部皮肤感染灶、急慢性盆腔炎。
2. 手术时间：**非孕妇女在月经干净后 3~4 日，人流或分娩后 48 小时内手术**。

### （二）避孕失败的补救措施

1. **方式选择：<孕 7 周（停经 49 天）→药物流产；孕 7~10 周→负压吸引术；孕 10~14 周→钳刮术。**
2. **药物流产（medical abortion / medical termination）：**常用为**米非司酮、米索前列醇**。**带器妊娠禁用！**
1. **米非司酮（抗孕激素）禁忌症：**肾上腺等内分泌疾病、妊娠期皮肤瘙痒史、血液病、血栓性疾病。
2. **米索前列醇（前列腺素类）禁忌症：**青光眼、心血管疾病、哮喘、癫痫、结肠炎。
3. **手术流产的禁忌症：生殖道炎症**、各种疾病的急性期、全身状况不良、术前两次T≥37.5℃。
4. 人流的并发症：

| | |
|---|---|
|**出血**|可在扩张宫颈后在宫颈注射**缩宫素**病尽快取出绒毛组织|
|**子宫穿孔**|手术时突然感到**无宫底感觉**，穿孔小者注射**缩宫素**保守治疗；穿孔大者**剖腹/腹腔镜探查**|
|**人流综合反应**|恶心呕吐、心动过缓、心律不齐、面色苍白、头昏胸闷、大汗淋漓等**迷走神经兴奋症状**<br><br>一经发现，即可**停止手术+吸氧**，严重者予**阿托品** 0.5~1mg 静注|
|**漏吸、空吸**|**漏吸：**人流术**未吸出**胚胎、绒毛，应再次负压吸引术；**空吸：异位妊娠**误诊为宫内妊娠|
|**吸宫不全**|人流术后部分妊娠组织物残留，表现为**术后阴道流血时间长**，血量多或止血后再次流血，<br><br>**血/尿 hCG 检测、B 超检查**有助于诊断。无感染者立即**刮宫**；有感染者限控制感染|
|**感染**|急性子宫内膜炎、盆腔炎性疾病|
|**羊水栓塞**|少见|
|**远期并发症**|宫颈/宫腔粘连、慢性盆腔炎、月经不调、继发性不孕|

|---|---|
