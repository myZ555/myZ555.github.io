## 早中期病理妊娠

### 1. 异位妊娠(§8-2)

【概述】

- ==异位妊娠ectopic pregnancy/宫外孕extrauterine pregnancy==：受精卵在子宫体腔外着床
- 位置：*输卵管妊娠*最常见；少见的包括卵巢妊娠、腹腔妊娠、宫颈妊娠、阔韧带妊娠[^1]
- 输卵管妊娠：*壶腹部*最常见，其次为峡部、伞部、间质部
- 病因：*输卵管炎症（主要）*、输卵管妊娠史/手术史、输卵管发育不良/功能异常、辅助生殖技术、避孕失败、子宫肌瘤/卵巢肿瘤压迫输卵管、输卵管子宫内膜异位症。

【病理】

1. 输卵管
	- 输卵管妊娠胚胎停止发育并吸收：若 hCG 低，常被诊断为未知部位妊娠（PUL）。 
	- $陈旧性宫外孕$：长期反复出血形成的血肿不消散，与周围组织粘连，形成机化性包块。 
	- $继发性腹腔妊娠$：输卵管妊娠流产或破裂后，胚胎落入腹腔或阔韧带，少数可继续发育。

| 类型     | 输卵管妊娠流产 | 输卵管妊娠破裂             | 宫角妊娠/输卵管间质部妊娠  |
| -------- | -------------- | -------------------------- | -------------------------- |
| 部位     | 输卵管壶腹部   | 输卵管峡部                 | /                          |
| 时间     | 停经8-12w      | 停经6w                     | 停经12-16w                 |
| 临床表现 | 腹痛、出血较少 | 腹痛剧烈、出血多、可致休克 | 腹痛剧烈、出血多、可致休克 |

2. 子宫
	- 类似妊娠，子宫变大变软，子宫内膜出现蜕膜反应
	- *三角形蜕膜管型（decidual duct）*：有时蜕膜完整剥脱，随阴道流血排出，特征性。
	- *Arias-Stella 反应（A-S 反应）*：子宫内膜过度增生、分泌反应

【症状】==停经+腹痛+阴道流血==三联征

1. 停经：一般6-8w，输卵管间质部妊娠可能更长
2. 腹痛：一侧下腹部隐痛/酸胀感→一侧下腹部撕裂样疼痛→下腹部疼痛、肛门坠胀感→全腹痛，甚至出现肩胛部放射性疼痛、胸部疼痛。
3. 阴道流血、休克：特征是*休克程度与阴道流血量不成正比* （内出血，鉴别流产）。
4. 腹部包块：陈旧性宫外孕者，血肿机化粘连，形成包块。

【体征】

- 腹部检查：<u>一侧下腹部</u>压痛、反跳痛，但肌紧张不明显。出血量大时可有<u>移动性浊音(+)</u>。 
- 妇科检查：子宫稍增大、变软，*阴道后穹窿饱满，宫颈举痛、摇摆痛，甚至出现子宫漂浮感*。

【诊断】

1. 超声检查（阴道B超）：宫旁探及低回声区，可见卵黄囊、胚芽、原始心管搏动； 未探及时也不能排除
2. hCG 测定：hCG(+)但低于宫内妊娠，**血清 hCG≥3500U/L（或 2000U/L）** 应怀疑异位妊娠
3. 经阴道后穹窿穿刺：适用于疑似腹腔内出血（异位妊娠破裂→休克）时，*穿刺抽出暗红色不凝血为(+)* **注意：穿刺阴性不能排除异位妊娠**
4. 其他：孕酮测定、腹腔镜检查（不再是金标准，治疗性）、诊断性刮宫（有绒毛-宫内妊娠，无-异位）。

【鉴别诊断】

|                | 输卵管妊娠                               | 流产                                         |
| -------------- | ---------------------------------------- | -------------------------------------------- |
| 停经           | 多有                                     | 有                                           |
| 腹痛           | 突然撕裂样剧痛，自下腹一侧开始向全腹扩散 | 下腹中央阵发性坠痛                           |
| 阴道流血       | 量少，暗红色，可有蜕膜管型排出           | 开始量少，后增多，鲜红色，有小血块或绒毛排出 |
| 休克           | 程度与外出血不成正比（内出血）           | 程度与外出血成正比                           |
| 体温           | 正常，有时低热                           | 正常                                         |
| 盆腔检查       | 宫颈举痛，直肠子宫陷凹有肿块             | 无宫颈举痛，宫口稍开，子宫增大变软           |

|                |                                          |                                              |

【治疗】

1. 期待疗法：适用于病情稳定、hCG<1500U/L 且呈下降趋势者。 
2. 手术治疗：
	1) 适用于①**生命体征不稳定**；②**异位妊娠有进展（hCG>3000U/L** 或升高，或有胎心搏动、 附件区包块大者）；③随诊不可靠；④药物治疗禁忌或无效；⑤**持续性异位妊娠者**。
	2) 方法： 
		1) 保守手术：适用于有生育要求的年轻妇女，特别是对侧输卵管已切除或有明显病变者。 术后需密切监测 hCG，*若 hCG 不减或下降慢，可能为持续性异位妊娠*（persistent ectopic pregnancy），可予甲氨蝶呤（MTX）治疗，必要时再次手术治疗。 
		2) 根治手术：适用于无生育要求、内出血并发休克的急症患者，对侧输卵管正常者更合适。 
		3) 药物治疗：全身（i.m.）或局部（超声引导下/腹腔镜下）使用**甲氨蝶呤（MTX）**。 
			- i. 适应症：① 未发生破裂；②**妊娠囊<4cm**；③**hCG<2000U/L**；④ 无明显内出血。 
			- ii. 禁忌症：①生命体征不稳定；②异位妊娠破裂；③妊娠囊≥4cm 或≥3.5cm+胎心搏动；④药物 过敏、慢性肝病、血液病、活动性肺部疾病、免疫缺陷、消化腺溃疡；⑤宫内妊娠+宫外妊娠



### 2. 自然流产(§8-1)

【概述】

- ==流产abortion/miscarriage==：胚胎或胎儿未具有生存能力而妊娠中止者。
- 我国：孕<28 周、胎儿<1kg。 
- 分类 1：自然流产（spontaneous abortion）、人工流产（artificial abortion）。 
- 分类 2：早期流产（80%）<孕 12 周<晚期流产。 
- ==隐性流产clinically silent miscarriage/生化妊娠chemical abortion==：发生在月经期前的流产。

【病因】

1. 胚胎异常：*染色体异常是早期流产最常见的原因*。包括数目异常（主要是三体，e.g. 13-三体、16- 三体、18-三体、21-三体、22-三体）、结构异常（平衡易位、倒置、缺失、重叠、嵌合体等）。 
2. 母体因素：全身性疾病（包括 TORCH 感染）、<u>生殖器畸形（子宫畸形、子宫腺肌病、宫腔粘连、 宫颈机能不全~晚期流产）</u>、内分泌异常（黄体功能不全、高催乳素血症、多囊卵巢综合征、甲减、 糖尿病）、强烈应激、不良习惯、免疫功能异常。 
3. 父体因素：精子染色体异常等。 
4. 环境因素：放射线、化学物质等。

【临床表现】==停经、腹痛、阴道流血三联征==

| 类型     | 先兆流产 threatened | 难免流产 inevitable | 不全流产 incomplete | 完全流产 complete |
| -------- | ------------------- | ------------------- | ------------------- | ----------------- |
| 出血量   | 少                  | 可导致休克          | 可导致休克          | 不再出血          |
| 下腹痛   | 轻                  | 加重                | 减轻                | 无                |
| 组织排出 | 无                  | 无                  | 部分                | 全部              |
| 宫颈口   | 关                  | 开                  | 开/组织嵌顿         | 无                |
| 子宫大小 | =孕周               | =孕周或稍小         | <孕周               | =未孕或稍大       |
| 处理原则 | 保胎、对因治疗      | 尽早排出胚胎、胎盘  | 尽快刮宫、清宫      | 无需特殊处理      |

### 2. 妊娠期肝内胆汁淤积症 ICP(§8-5)

 【概述】妊娠中晚期特有、病因不明、皮肤瘙痒、血清总胆汁酸升高、产后症状迅速消失且生化指标逐渐恢复正常。是一种良性疾病。

【主要生化特征】母体-胎儿循环及羊水高胆汁酸水平

【病因】

- 雌激素：多发生于妊娠晚期；雌激素可使Na-K-ATP酶活性下降导致胆汁酸代谢障碍；雌激素可作用于肝细胞表面雌激素受体改变肝细胞蛋白质合成、导致胆汁回流增加
- 遗传和环境因素：冬季高于夏季；黄色人种常见；家族史/既往病史高发

【ICP对母儿的影响】

- 孕妇：影响较小；伴发脂肪痢时，VitK的吸收减少可导致产后出血
- 胎儿/新生儿：主要的影响。胎儿缺氧、胎儿窘迫、早产、羊水粪染；新生儿窒息、颅内出血、RDS。严重者：不能预测的突发的胎死宫内。

【临床表现】**①瘙痒 ②黄疸 ③皮肤抓痕** （其他：恶心、呕吐、食欲缺乏、腹痛、轻度脂肪痢）

【诊断】*排他性诊断*

1. 临床表现：瘙痒、黄疸
2. 实验室检查：
	1. 空腹TBA≧10umol/L、随机TBA≧19umol/L
	2. 肝功能异常：ALT↑
	3. 病毒学检查：排除肝炎病毒、EB病毒、巨细胞病毒感染
	4. 肝脏超声：排除肝脏、胆囊的基础疾病

【鉴别诊断】

- 皮肤瘙痒：湿疹？荨麻疹？妊娠特异性皮炎？过敏反应？瘙痒性毛囊炎？尿毒症性瘙痒？
- 肝功能异常：病毒性肝炎？肝胆石症？急性脂肪肝？子痫前期？HELLP综合征
- TBA升高：原发性胆汁性肝硬化？家族性肝内胆汁淤积？

【治疗】

- 母胎监测
- 降胆汁酸治疗

### 3. 妊娠期高血压疾病(§8-4)

【概述】妊娠期特有的疾病；==一过性高血压、蛋白尿等症状==，分娩后随即消失

【子痫前期】是一种综合征，主要包括在中孕期新发高血压的进展。常伴随蛋白尿。

【病因】子宫**螺旋小动脉**重铸不足

- 正常妊娠时固定绒毛滋养细胞沿螺旋动脉逆行浸润，逐渐取代血管内皮细胞，并使血管平滑肌弹性层为纤维样物质取代，使血管腔扩大、血流增加，以更好营养胎儿。这一过程称remould of vascular血管重塑，入侵深度可达子宫肌层内1/3

- 子痫前期患者滋养细胞侵入螺旋小动脉不全，子宫肌层小动脉未发生重铸，异常狭窄的螺旋动脉使胎盘灌注减少和缺氧，最终导致子痫前期的发生。滋养细胞入侵仅达蜕膜血管，少数血管不发生重塑，胎盘浅着床，导致早期滋养细胞缺氧影响胎儿发育。

	其他：炎症免疫过度激活学说、血管内皮细胞受损、遗传因素、营养缺乏等

【发病机制】

【病理生理变化】

1. **脑：小动脉痉挛** 脑组织缺血缺氧--脑水肿、血栓形成、脑出血。<u>表现：头痛、呕吐、鼾声、唾液外流、抽搐昏迷、脑溢血、感觉迟钝、脑疝、视物模糊失明</u>
2. **肾脏：肾小动脉痉挛** ①缺血缺氧--肾小球肿胀--血浆蛋白漏出--蛋白尿--标志妊娠高血压的严重程度 ②肾血流量、肾小球滤过量下降--血尿酸、肌酐浓度升高--少尿和肾功能衰竭、肾缺血
3. **肝脏：肝小动脉痉挛** 肝功能异常、各种转氨酶升高；肝动脉周围阻力增加、门静脉周围坏死；肝包膜下血肿形成、肝破裂
4. **心脏：冠状小动脉痉挛** 血管阻力增加、血压升高；<u>心脏前负荷和心脏输出量降低</u>；左心室后负荷增加；心肌缺血、间质水肿；严重致心衰
5. **血液：全身小动脉痉挛** ①容量：血管壁渗透性增加、红细胞比容升高。②凝血：伴有一定量的凝血因子缺乏/变异所致的高凝状态；重症患者可发生微血管病性溶血
