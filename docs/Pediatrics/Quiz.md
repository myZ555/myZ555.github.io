1. 幼儿期的定义是：**1周岁-3周岁**

	| 分期     | 时间                                     | 特点                                 |
	| -------- | ---------------------------------------- | ------------------------------------ |
	| 胎儿期   | 受精卵-胎儿娩出                          | ≤8周：胚胎；≥8周：胎儿               |
	| 新生儿期 | 脐带-28天                                | 围生期：妊娠28周-产后1周             |
	| 婴儿期   | 出生前-1周岁                             | 出生后第一个生长发育高峰             |
	| 幼儿期   | 1周岁-3周岁                              |                                      |
	| 学龄前   | 3周岁-6/7周岁                            |                                      |
	| 学龄     | 6/7周岁-11/12岁                          |                                      |
	| 青春期   | 女11/12岁-17/18岁<br />男13/14岁-18/20岁 | 生殖系统快速发育、第二个生长发育高峰 |

2. 遗尿的诊断标准是发生不随意排尿的年龄大于？？==5岁==

3. 一正常男婴体检，体重6kg，身长63cm，能抬头，会微笑，可咿呀发声，其骨骼发育最可能的是：**2个月**

	- 脊椎生理性弯曲：3月-颈椎前凸-抬头；6月-胸椎后凸-坐；1岁-腰椎前凸-行走。
	- 骨化中心：≤1岁-膝部；年长儿-左手腕部（腕部骨化中心=年龄+1）
	- 乳牙：数量=月龄-（4～6）4-10月开始萌出、3岁前出齐
	- 运动：二抬四翻六会坐，七滚八爬周会走，一二三，走跳跑
	- 前囟：出生时1-2cm，2周岁前关闭。6月前⬆️，6月后⬇️
	- 后囟：0.5cm，6-8周关闭
	- 身高/身长：出生～50cm，1岁～75cm，2岁～85cm
	- 头围：出生～34cm，1岁～46cm，2岁～48cm
	- 胸围：出生～32cm，1岁～46cm（=头围），≥1岁=头围+年龄-1
