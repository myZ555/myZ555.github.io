## 概述

1. 脑的发育特点：①新生儿神经元数目接近成人，但树突、轴突短而少；②胎儿期脑发育最快；③新生儿髓鞘发育不完善，因此对外来刺激反应慢，且易于泛化，不易形成兴奋灶，易疲劳进入睡眠状态。

2. 脊髓的发育特点：**新生儿**脊髓末端位于 **L2**，**4 岁**左右脊髓末端位于 **L1**，婴幼儿腰穿位置选择 **L4/5**。
3. 神经反射：

| **原始反射**   | 拥抱反射、吮吸反射、觅食反射、握持反射等          | **出生时即出现，2~7 月**前陆续消失 |
| -------------- | ------------------------------------------------- | ---------------------------------- |
| **浅反射**     | 腹壁反射、提睾反射                                | 出生时**无**，4 月~1 岁才开始出现  |
| **深反射**     | 肱二头肌反射、膝反射、踝反射                      | **出生时即存在，**但婴幼儿**较弱** |
| **病理反射**   | Babinski 征、Chaddock 征、Gordon 征、Oppenheim 征 | **<2 岁 Babinski 征可双侧阳性**    |
| **脑膜刺激征** | 颈项强直、Kernig 征、Brudzinski 征                | **<3~4 月 Kernig 征可为弱阳性**    |

## 化脓性脑膜炎

> 化脓性脑膜炎（purulent meningitis）/急性细菌性脑膜炎（acute bacterial meningitis）：各种化脓性细菌引起的脑膜炎，**以急性发热、惊厥、意识障碍、颅内压增高、脑膜刺激征、脑脊液脓性改变为特征**。
>

1. 病因：肺炎链球菌以冬春季为主，脑膜炎奈瑟菌、流感嗜血杆菌以春秋季为主。

2. | 年龄                | 病原                                                       |
	| ------------------- | ---------------------------------------------------------- |
	| **<3 月婴儿**       | G-（**大肠埃希菌**、铜绿假单胞菌）**、金黄色葡萄球菌**     |
	| **3 月~3 岁婴幼儿** | **流感嗜血杆菌、肺炎链球菌**、脑膜炎双球菌                 |
	| **学龄前、学龄期**  | **脑膜炎双球菌**、肺炎链球菌、流感嗜血杆菌、金黄色葡萄球菌 |

	发病机制：**血行传播**（最常见）、邻近器官感染（中耳炎、乳突炎）、颅骨骨折、颅脑手术、皮肤窦道等。

3. 病理：<u>软脑膜、蛛网膜和表层脑组织的炎症反应。</u>广泛性血管充血、大量中性粒细胞浸润和纤维蛋白渗出；弥漫性<u>血管源性</u>和<u>细胞毒性</u>脑水肿；**轻者**炎性渗出物在大脑顶部、逐渐蔓延至大脑基底部和脊髓表面，**严重者**有血管壁坏死和灶性出血，灶性脑梗死。

4. **临床表现**：

	1. **感染中毒及急性脑功能障碍症状** 发热，烦躁不安；**脑膜炎双球菌**感染可见**淤点瘀斑**、休克。30%有惊厥，流脑患儿有瘀点、瘀斑、休克。
	2. **颅内压增高表现** 头痛、呕吐，婴儿出现**前囟饱满、头围增大**；合并**脑疝**时出现**呼吸不规则、瞳孔不等大**
	3. **脑膜刺激征** <u> 颈项强直（最常见）</u>、Kernig 征、Brudzinski 征

> **新生儿、3 个月以下**婴儿的不典型表现：①体温**可高可低**，甚至体温不升；②颅内压增高**不明显**，可能有吐奶、尖叫、**颅缝分离/前囟饱满**；③惊厥不典型、不明显。（_≈_新生儿败血症_+_颅缝分离_/_前囟饱满）

5. 实验室检查：
	1. **脑脊液检查：**严重颅内压增高者**必须先降低颅内压**，否则可能诱发脑疝。压力明显增高，外观**浑浊脓性**；**WBC≥1000×106/L，中性粒细胞**为主；**糖、氯化物明显↓，蛋白明显↑**【二高二低】；脑脊液涂片、培养可见细菌【脑脊液细菌学检查阳性为确诊依据】
	2. 其他：**WBC↑、N↑，PCT>0.5ng/mL**（细菌感染），**血培养、淤点瘀斑涂片（脑膜炎双球菌）**，CT、MRI。

6. 并发症

	1. ==硬膜下积液（最常见）== **最常见**，多见于<1 岁儿童，与①血管通透性↑、②脑膜静脉炎性栓塞→渗出、出血有关**临床表现：**有效治疗、脑脊液好转，但体温不退或**体温下降后再升高，或一般状况好转后又出现**意识障碍、惊厥、前囟隆起或颅内压增高症状应怀疑本并发症（好了又坏）。诊断：**头颅透光试验、头颅 CT**；确诊依赖于**硬膜下穿刺放液**（诊断+治疗）<u>【确诊标准：液体 > 2ml，蛋白 > 0.4g/L】</u>
	2. ==脑室管膜炎（病死率、致残率高）==  常见于**治疗被延误**的患儿，有效治疗下**发热不退，惊厥、意识障碍不改善，进行性颈项强直，脑脊液无法正常化**（一直不好），CT 提示**“脑室扩大”**，确诊依赖于**侧脑室穿刺**
	3. ==脑积水== 可引起**交通性脑积水**（脑脊液流出通道堵塞）**、非交通性脑积水**（脑脊液重吸收障碍） **临床表现：**患儿烦躁不安、嗜睡、呕吐、惊厥，头颅进行性增大、颅缝分离、前囟饱满、头颅破瓮音、头皮静脉扩张，晚期大脑皮质进行性萎缩→**进行性智力、神经功能减退**
	4. ==抗利尿激素异常分泌综合征== 炎症刺激垂体→**ADH↑→低钠血症、血渗透压↓**，可加重脑水肿，导致惊厥、意识障碍
	5. ==脑脓肿==  化脓菌进入脑组织引起炎症改变，进一步导致脓肿形成。邻近脑组织有严重的水肿和胶质细胞增生。感染途径：血行播散、邻近感染灶直接扩散、开放性颅脑外伤。【影像学特征】<u>脑炎早期表现</u>：CT平扫病灶呈边界模糊的低密度，增强扫描有时可有斑片状强化，邻近皮质内见脑回状强化。<u>脓肿期表现</u>：平扫病灶呈低密度，周围见密度稍高的环。增强扫描该环明显强化，脓肿可呈单房或多房。脓肿周围常有明显水肿。

7. 后遗症--**神经功能障碍** 炎症波及耳蜗迷路致神经性耳聋；癫痫；智力低下；视力障碍；行为异常

8. 鉴别诊断

	|              | 压力     | 外观   | 潘氏试验 | 白细胞 10^6^/L    | 蛋白      | 糖  CL^-^ | 其他        |
	| ------------ | -------- | ------ | -------- | ----------------- | --------- | --------- | ----------- |
	| 化脑         | 高       | 浑浊   | 2-3+     | 百-千，多核为主   | 增高明显  | 低        | 涂片、培养+ |
	| 结脑         | 阻塞时高 | 毛玻璃 | 1-3+     | 十-百，淋巴为主   | 增高      | 低        | 涂片、培养+ |
	| 病脑         | 正常     | 多清   | -～+     | 正常-百，淋巴为主 | 正常/稍高 | 正常      | 病毒培养+   |
	| 真菌性脑膜炎 | 高       | 不清   | 1-3+     | 十-百，单核为主   | 高        | 低        | 墨汁涂片+   |
	| 中毒性脑病   | 高       | 清     | -～+     | 正常              | 正常/稍高 | 正常      |             |

	- **Reye‘s综合征[^1]**：婴儿期和儿童期的一种以<u>急性脑病、肝脂肪变性</u>为主要临床特征的综合征。发病年龄为6个月到15岁，成人比较少见。

9. **治疗：**
	1. **一般治疗：**密切监测生命体征，控制惊厥发作，维持水、电解质、渗透压、酸碱平衡。
	2. **抗生素治疗：**首选药物为**三代头孢**（头孢曲松、头孢噻肟、头孢他啶）
		1. 肺炎链球菌：青霉素或第三代头孢，10-14天
		2. 脑膜炎球菌：大多数仍青霉素敏感，7天
		3. 流感嗜血杆菌：氨苄青霉素，第三代头孢联合美洛培南或氯霉素，10-14天
		4. 金黄色葡萄球菌：萘夫西林、万古霉素、利福平，21天以上
	3. **肾上腺皮质激素**的应用：抑制炎症反应，减轻脑水肿、颅内压增高。一般使用地塞米松 2~3 天。
	4. 并发症治疗：
		1. 硬膜下积液：积液量大、引起颅内压增高时**穿刺放液**，放液量**每次、每侧≤15mL**，迁延不愈者**手术引流**
		2. 脑室管膜炎：侧脑室穿刺引流+抗生素脑室内注入
		3. 脑积水：正中孔粘连松解术、导水管扩张术、脑脊液分流术

## 结核性脑膜炎

> 小儿结核病中最严重的类型；常在结核原发感染后1年以内发生；3岁以内

- 发病机制：**血行播散**（全身粟粒性结核-穿透BBB-结脑）；**直接蔓延**（脑实质/脑膜的结核病灶溃破-进入蛛网膜下腔及脑脊液-结脑）；偶见脊椎、颅骨或中耳与乳突的结核灶侵犯脑膜
- 病理：
	- **脑膜病变**：软脑膜充血水肿、炎性渗出、形成结核结节；蛛网膜下腔大量炎性渗出物积聚
	- **脑神经损害**：面神经、舌下神经、动眼神经、展神经障碍
	- **脑部血管病变**：早期是急性动脉炎；晚期栓塞性动脉内膜炎，脑梗死、缺血、软化致偏瘫
	- **脑实质病变**：结核性脑膜脑炎、结核瘤
	- **脑积水及室管膜炎**：室管膜及脉络丛受累---脑室管膜炎；室间孔粘连狭窄---脑室扩张；脑脊液循环受阻----脑积水
	- **脊髓病变**：脊膜、脊髓、脊神经根受累，蛛网膜下腔完全闭塞
- 影像学：<u>脑积水非常常见</u>；脑梗塞-基底节和丘脑；晚期钙化明显
- 临床表现：
	- 早期-前驱期：1-2w；性格改变
	- 中期-脑膜刺激期：1-2w；颅高压、脑膜刺激征、脑神经障碍、脑炎症状及体征、眼底特征性改变
	- 晚期-昏迷期：1-3w；昏迷、惊厥、消瘦、水电解质紊乱、脑疝
	- <u>不典型表现</u>：婴幼儿进展快；早期脑实质损害-舞蹈症、精神症状；早期脑血管损害-肢体瘫痪；颅外结核病变极端严重掩盖脑膜炎表现；抗痨治疗过程中表现为顿挫型
- 诊断：
	- 病史：结核接触史、卡介苗接种史、既往结核病史、近期急性传染病史
	- 临床表现：性格改变、头痛、呕吐、嗜睡或烦躁不安交替、顽固性便秘、眼底检查有脉络膜粟粒结节
	- 脑脊液检查（见前）外观毛玻璃样、糖氯化物低、蛋白高、涂片+、<u>脑脊液沉淀物涂片抗酸染色阳性</u>
- 并发症：脑积水、脑实质损害、脑出血、脑神经障碍
- 后遗症：脑积水、肢体瘫痪、智能低下、失明、失语、癫痫、尿崩症
- 治疗：
	- 一般治疗：休息、护理、营养
	- 抗结核治疗
		- 强化治疗阶段：INH+RFP+PZA+SM，疗程3-4个月
		- 巩固治疗阶段：INH+RFP或INH+EMB；RFP或EMB 9-12个月
	- 降低颅高压：<u>脱水剂-甘露醇；利尿剂-乙酰唑胺</u>；侧脑室穿刺引流；腰椎穿刺减压；分流手术
	- 糖皮质激素：抑制炎症；降低颅高压；减轻中毒症状及脑膜刺激征；利于脑脊液循环；需早期使用
	- 对症支持治疗：惊厥、水电解质紊乱（稀释性低钠血症：3%Nacl 6-12ml/kg；脑性失盐综合征：2:1等张含钠液，酌情补 3%Nacl）、低钾血症（0.2%Kcl的等张溶液）

## 热性惊厥

- **热性惊厥（febrile seizures，FS）：**婴幼儿期最常见的惊厥性疾病，需排除 CNS 感染及其他疾病。
- 特点：①多见于 **3 月~6 岁**，一般体质较好；②多发生于**病初体温骤升时**，发作前后一般状况良好；③**无神经系统体征**；④热退 1 周后 EEG 正常；⑤**反复发作**倾向。（肺炎时不是 _FS_，而是缺氧中毒性脑病）
- 单纯型：①**全面性发作**，无局灶发作特征；②发作时间**<15min**；③24h 内/同一病程中**仅发作 1 次**。
- 复杂型：①**局灶性发作**；②发作时间**>15min**；③24h 内/同一病程中发作**≥2 次**。
- 治疗：首选**苯二氮䓬类（地西泮）**；**新生儿**首选**苯巴比妥**；惊厥**持续状态**首选**苯妥英钠（鲁米那）**。

[^1]: 临床表现主要有一些前驱症状，初始发病有发热、咳嗽和流涕、咽痛等上呼吸道感染及持续性呕吐。数天后出现急性脑病症状，随着病情的加重，可能出现意识改变、惊厥、淡漠、嗜睡、昏迷，严重者在数小时，因为脑水肿引起脑疝、呼吸衰竭，直接导致死亡。肝病表现轻微，肝轻度增大和不增大，一般没有脾大和黄疸。神经系统检查出现病理反射、角弓反张、颅内压增高的眼底改变。
