# 免疫系统

- 1. 细胞免疫特点：

## 概述

- - 1. 胸腺：T 细胞分化成熟的场所，出生时与体重之比**最大**。
2. T 细胞：出生时数量**已达**成人水平，已具有免疫应答能力；**CD4/CD8 较高**，2 岁时达成人水平。
3. 细胞因子：调节免疫应答及炎症反应，新生儿向 **Th2** 偏移，易患过敏性疾病。

1. 体液免疫特点：
1. 骨髓：B 细胞分化成熟的场所。
2. B 细胞：抗原刺激下诱导分化为浆细胞，产生免疫球蛋白（Ig），足生儿 B 细胞数量略高于成人。
3. 免疫球蛋白（Ig）：分为 **IgG、IgA、IgM、IgD、IgE** 五类。
1. IgG：**唯一能通过胎盘**的 Ig，母体 IgG 在 **6 个月时消失**，3~4 个月最低，**6~7 岁**达成人水平。
2. IgM：个体发育**最早**的 Ig，新生儿脐血 IgM 过高提示**宫内感染**，**6~8** 岁达成人水平。
3. IgA：个体发育**最晚**的 Ig，新生儿含量增高亦提示宫内感染；**sIgA 具有黏膜局部抗感染作用**。
4. IgD、IgE：不能通过胎盘，含量极低，**IgE 与Ⅰ型变态反应有关**。
2. 非特异性免疫特点：
1. 吞噬系统：包括单核/巨噬细胞、中性粒细胞，新生儿吞噬细胞功能暂时低下。
2. 补体系统：新生儿各补体成分和溶血活性低于成人，生后 **3~6 个月**可达成人水平。

## 原发性免疫缺陷病

1. **原发性免疫缺陷病（primary immunodeficiency，PID）：**不同基因缺陷导致的免疫功能损害。
1. 包括：50%**抗体缺陷**（**X 连锁无丙种球蛋白血症 XLA**、常见变异型免疫缺陷病、**婴儿暂时性低丙球血症、选择性 IgA 缺陷**、选择性 IgM 缺陷、选择性 IgG 亚类缺陷），20%联合免疫缺陷（**严重联合免疫缺陷病 SCID、湿疹血小板减少伴免疫缺陷综合征 WAS**、共济失调-毛细血管扩张症），18%吞噬细胞缺陷，10%细胞免疫缺陷（**DiGeorge 综合征**、Nezelof 综合征），2%补体缺陷。
2. 共同特点：**反复和慢性感染**、易发生自身免疫性疾病和肿瘤、可合并其他临床表现或先天畸形。
3. 实验室检查：
1. 初筛试验：免疫球蛋白、ASO、嗜异凝集素、外周血淋巴细胞计数、迟发皮肤过敏试验、胸片、白细胞计数及形态、NBT 试验、补体测定。
2. 进一步检查：B 细胞计数、IgG 亚类分析、T 细胞亚群、T 细胞增殖反应、白细胞移动及趋化性、杀菌功能、补体成分及活化片段测定、基因突变分析及产前、诊断。
3. **总 Ig<4g/L 或 IgG<2g/L** 时提示抗体缺陷，**CD3+CD4+细胞数<500/μL** 视为细胞免疫功能受损，

**CD4/CD8<1 时提示细胞免疫功能被抑制**，CD4/CD8<0.3 时则为严重 T 细胞功能缺陷。

1. 治疗原则：
1. **一般治疗：**预防和治疗感染、注重营养、**输血前低剂量放射照射**、细胞免疫缺陷者**禁用活疫苗**。
2. **替代治疗（缺什么补什么）：**静脉注射丙球（治疗前徐测定）、高效价免疫血清球蛋白、血浆、WBC、细胞因子治疗、酶替代治疗，但是**选择性 _IgA_ 缺乏症禁忌使用含 _IgA_ 的生物制品！**
3. 免疫重建：胸腺组织移植、干细胞移植、基因治疗。

## 风湿热

1. **风湿热（rheumatic fever）：**咽喉部感染 **A 组乙型溶血性链球菌**后发生的风湿性疾病，主要累及**关节、心脏、皮肤**，偶可累及 **CNS**、血管、浆膜、肺、肾。最常见的发病年龄是 **5~15 岁**。
2. 病因：**A 组乙型溶血性链球菌**，与与机体器官抗原存在同源性，引起**交叉免疫反应（分子模拟）**。
3. 临床表现：发病前 1~6 周有**链球菌感染后咽峡炎**病史，如发热、咽痛、咳嗽、颈淋巴结肿大。
1. **一般表现：发热**，可伴精神不振、疲倦、纳差、面色苍白、多汗、关节痛、腹痛等。
2. **心脏炎：心肌炎**（严重者心衰）**、心内膜炎**（二闭、主闭，反复发作引发风心）**、心包炎**。
3. **关节炎：多发性游走性关节炎**，以**大关节**为主（膝、踝、肘、腕），愈后**不留畸形**，此起彼伏。
4. **舞蹈病：**全身或部分肌肉不自主快速运动，如伸舌歪嘴、挤眉弄眼等，常伴肌无力、情绪不稳定。
5. **皮肤症状：**①**环形红斑**（躯干、四肢近端淡色红斑）；②**皮下结节**（**坚硬无痛**结节，与皮肤**不**粘连）。
4. 辅助检查：
1. 链球菌感染证据：**咽拭子培养**→A 组乙型溶血性链球菌，**感染 _1_ 周后 ASO↑**。
2. 风湿热活动指标：**WBC↑、N↑、ESR↑、CRP↑**。

#### Jones 诊断标准（1992）：

1. 鉴别诊断：JIA、急性化脓性关节炎、白血病、生长痛、感染性心内膜炎、病毒性心肌炎。
2. 治疗：
1. **卧床休息：**取决于心脏受累程度、心功能状态（**无心脏炎-2 周，心脏炎-4 周，心衰-至少 8 周**）。
2. **清除链球菌感染：青霉素 80 万 U 肌注**，持续 2 周。
3. 抗风湿热治疗：**心脏炎时使用糖皮质激素**，**无**心脏炎者使用 **NSAIDs（如阿司匹林）**。
4. 其他治疗：**心衰**时及时予**糖皮质激素**，**慎用**洋地黄类，低盐饮食，必要时吸氧、利尿、扩血管；**舞蹈病**时可予苯巴比妥、地西泮等**镇静剂**；关节肿痛时予制动。
3. 预防：曾患风湿热者每 3~4 周肌注**苄星青霉素（长效）**120 万U，拔牙/手术前后**预防性使用抗生素**。
4. 预后：主要取决于**心脏炎**程度。

1. 辅助检查：
1. 血液检查：**ESR↑、CRP↑**、IL-1↑、IL-6↑；**类风湿因子（RF）、抗核抗体（ANA）**等。
2. 其他检查：关节炎液分析、滑膜组织学检查、血常规、X 线检查、骨关节彩超、MRI。
2. 鉴别诊断：全身感染、肿瘤、风湿热、化脓性关节炎、关节结核、创伤性关节炎、SLE、HSP、KD 等。
3. **治疗：**不主张过度卧床休息，适当活动，眼部检查（虹膜睫状体炎）。
1. **NSAIDs：首选**，萘普生、布洛芬、双氯芬酸钠、尼美舒利等。
2. **缓解病情的抗风湿药（DMARDs）/慢作用抗风湿药：甲氨蝶呤（MTX）**、羟氯喹、柳氮磺吡啶等。
3. **肾上腺皮质激素：不作为首选**，应用指征：
1. 全身型：NSAIDs 及其他治疗无效者。
2. 多关节型：NSAIDs、DMARDs 无效者。
3. **少关节型、银屑病性：不主张使用**。
4. **虹膜睫状体炎：散瞳剂+激素**滴眼。
4. 其他：免疫抑制剂（环孢素 A、环磷酰胺等）、生物制剂（抗 TNF-α、抗 IL-6 等）、IVIG、理疗。
4. 并发症可并发关节功能丧失、虹膜睫状体炎，病情易反复，致死性并发症巨噬细胞活化综合征（MAS）。

## 过敏性紫癜

1. **过敏性紫癜（anaphylactoid purpura）/亨-舒综合征（HSP）：**以**小血管炎**为主要病变的系统性血管炎，临床特点为**血小板不减少性紫癜**。常伴**关节肿痛、腹痛、便血、血尿、蛋白尿**。
2. 病因：过敏、药物，微生物、疫苗、麻醉、肿瘤等，**A 组溶血性链球菌**感染是诱发 HSP 的重要原因。
3. 发病机制：感染源、过敏因素+遗传背景→B 细胞克隆扩增→分泌大量 IgA、IgE→**IgA 相关的血管炎**。
4. **临床表现：起病前 1~3 周常有上感史。**
1. **皮肤紫癜：**多见于**四肢、臀部**，伸侧较多，分批出现。初起为**紫红色皮疹**，高出皮面，**压之不褪色**，数日后变暗紫色，一般 **4~6 周**消退。少数重症患儿紫癜可融合成大疱伴出血性坏死。
2. **胃肠道症状：**一般以**阵发性腹痛**为主，可伴**呕吐**，部分出现**黑便/血便**。
3. **关节症状：**膝、踝、肘、腕等**大关节**肿痛、活动受限，关节腔有**浆液性**积液，**不遗留后遗症**。
4. **肾脏症状：**多数患儿出现**血尿、蛋白尿、管型尿（紫癜型肾炎）**，少数呈**肾病综合征**表现。
5. 其他：偶见颅内出血、出血倾向、心肌炎、心包炎，累及呼吸系统发生喉头水肿、哮喘、肺出血。
5. 辅助检查：
1. 血检：**PLT 正常**，出血时间、凝血时间正常，部分**毛细血管脆性试验**阳性，**血清 IgA 升高**。
2. 尿常规：可见**红细胞、蛋白质、管型**。 c) 粪常规：**隐血试验**阳性。

d) 其他：腹部超声（诊断肠套叠），头颅 MRI，肾穿刺活检等。

#### 治疗：

- 1. **一般治疗：**休息，去除病因。有荨麻疹或血管神经性水肿时应用**抗组胺药、钙剂**；腹痛时使用解痉剂；消化道出血时禁食+西咪替丁，必要时输血。
2. **糖皮质激素治疗：**可缓解**消化道症状（腹痛、出血）、关节痛**，**不能预防紫癜、肾脏损害！**
3. **免疫抑制剂：**严重的**过敏性紫癜肾炎**可使用**激素+免疫抑制剂**（环磷酰胺、硫唑嘌呤等）。
4. 其他：抗凝治疗（阿司匹林、双嘧达莫、肝素）、CCB（硝苯地平）、NSAIDs（萘普生）等。

## 川崎病

#### 川崎病（Kawasaki disease，KD）：黏膜皮肤淋巴结综合征（mucocutaneous lymph node syndrome）。

1. 病理：**全身性血管炎**，易累及**冠状动脉**。
2. **主要表现与诊断标准：发热>5 天+①~⑤中至少 4 项。皮肤**

| | | |
|---|---|---|
|**发热**|**高热**，至少持续 **5 天**（通常 7~14 天）| |
|①**皮肤 多形性红斑、猩红热样皮疹**，可有**肛周**皮肤发红、脱皮| | |
||②**手足症状** 手足**硬性水肿、掌跖红斑**，恢复期**膜状脱皮**，甚至**指甲脱落**| |
|**黏膜**|③**球结膜充血**|**无**脓性分泌物，热退后消散|
|④**唇、口腔**|**唇充血皲裂，口腔黏膜充血**，舌乳头凸起，**草莓舌/杨梅舌**|
|**淋巴结**|⑤**颈淋巴结肿大**|单侧或双侧，**非化脓性**|

1. 心脏表现：病程第 1~6 周出现**心包炎、心肌炎、心内膜炎、心律失常**，第 2~4 周/恢复期发生**冠状动脉损害**（d>3mm 为扩张，d>4mm 为动脉瘤；d≥8mm 为巨大动脉瘤；或冠状动脉狭窄）。
1. 心梗、冠状动脉瘤可致心源性休克、**猝死**。<2 岁男孩，ESR、PLT、CRP↑是冠脉病变的高危因素。
2. 其他表现：间质性肺炎、无菌性脑膜炎、消化系统症状、关节痛、关节炎等。
1. 原**接种卡介苗（BCG）瘢痕处再现红斑**，对不完全型 KD 诊断有重要价值。
3. 辅助检查：

| | |
|---|---|
|**血液检查**|**WBC↑、N↑**伴核左移，轻度贫血，第 2~3 周时 **PLT 增多，ESR↑、CRP↑**，转氨酶↑|
|**免疫学检查**|IgG、IgM、IgA、IgE 升高，IL-6 升高，补体正常或升高|
|**胸部 X 线**|肺纹理增多、模糊或片状阴影，心影可扩大|
|**ECG**|ST-T 段变化，心包炎时 ST 段抬高、低电压，心梗时 ST 段抬高、T 波倒置、病理性 Q 波|
|**冠脉病变**|**超声心动图（最重要的辅助检查手段）**、冠脉造影、冠脉 CT 等|

1. 鉴别诊断：渗出性多形性红斑、JIA 全身型、败血症、猩红热。
2. **治疗：首选阿司匹林+IVIG。**
1. **阿司匹林：**每日 **30~50mg/kg**，**热退 3 天**后减量，维持 **6~8 周**/冠脉病变消退（维持剂量 **3~5mg/kg**）。
1. 伴有冠状动脉病变者，服药时间需延长，**直到冠脉病变消失（小剂量维持）**。
2. **静脉注射丙种球蛋白：**推荐 **2g/kg**，发病早期应用，可退热、**预防冠脉病变**发生。
3. 糖皮质激素：**不宜单独使用**（可增加冠脉病变风险），仅用于 **IVIG 非敏感型** KD。
3. IVIG 非敏感型 KD：发病 10 天内接受 IVIG 2g/kg 治疗，**IVIG 使用后 36~48h**，仍 T>38℃或再次发热。
1. 治疗方案：①**再次应用 IVIG 2g/kg**；②**糖皮质激素+阿司匹林**。
4. 预后：**自限性**，多数预后良好。无冠脉病变者出院后**第 1、3、6、12 月后复查**（体检、ECG、心超），**冠脉者病变大多数于 2 年内自行消失**，但常遗留管壁增厚、弹性减弱，**巨大动脉瘤需外科手术介入**。
