## 麻疹

- 1. **麻疹（measles）：麻疹病毒**引起的传染病，以**发热、上呼吸道感染、结膜炎、Koplik 斑（口腔麻疹黏膜斑）、全身斑丘疹、疹退遗留色素斑糠皮样脱屑**为特征。病后多可获得终身免疫。
2. 病因：**麻疹病毒（RNA 病毒）**，通过**呼吸道传播（飞沫传播）**。冬春季节发病最常见。
3. **典型临床表现：**_“_烧三天、疹三天、退三天_”_

2. 治疗：**没有特异性治疗方法**。推荐补充大剂量**维生素 A**。
1. 对症治疗：镇静、止咳，高热时酌情使用物理退热、NSAIDs。**出疹期避免急骤退热！**

**球蛋白**；③隔离：一般隔离至出疹后 **5 天**，伴**肺炎**者隔离至出疹后 **10 天**，接触麻疹的易感儿隔离 **3 周**。

#### 附：水痘

- **水痘（chickenpox，varicella）**是由**水痘-带状疱疹病毒（VZV）**引起的传染性出疹性疾病。
- 病因：VZV 属于 **DNA 病毒**，**水痘患者**为传染源，通过**呼吸道飞沫传播或接触感染者皮损传播**。
- **典型临床表现：**发热 **1~2 天**后出疹，皮疹特点：①首发于**头、面、躯干**→四肢→末梢（稀少），呈**向心性分布**；②红色斑丘疹→**水疱（中央凹陷）→破溃后结痂**；③皮损**分批**出现，**瘙痒**明显，疾病高峰期可见**多种形态皮损同时存在**；④**黏膜皮疹**可出现在口腔、结膜、生殖器；⑤自限性，皮疹结痂后**不留疤痕**。
- 诊断：WBC 正常或稍低，疱疹刮片可见多核巨细胞、包涵体，病毒分离、血清学检查（IgM ↑>4 倍）。
- 治疗：自限性，对症处理为主。抗病毒药物无首选**阿昔洛韦**，皮疹出现的 48h 内使用。**不宜使用激素！**
- 预防：**水痘减毒活疫苗**，水痘患者隔离至**皮疹全部结痂**，接触水痘患者后 72h 内注射 **VZV-Ig**。

## 小儿结核病

#### （一）概述

1. **结核病（tuberculosis，TB）：**原发性结核病中**最常见**的是**原发性肺结核（primary pulmonary tuberculosis）**，是小儿肺结核的**主要类型**；**结核性脑膜炎（tuberculous meningitis）**是小儿结核病的**最严重**的类型。
2. 病原体：**结核分枝杆菌**属于**抗酸杆菌**，人型是人类结核病的主要类型。
3. 传染病学：**开放性肺结核（open pulmonary tuberculosis）患者**是主要传染源，**呼吸道传播**是主要途径。
4. 发病机制：是否发病与免疫力（**细胞免疫**）、毒力、细菌数量有关，**细胞免疫、迟发型变态反应**。
5. 临床表现——**中毒症状：长期低热、轻咳、盗汗、乏力、纳差、消瘦**等。
1. **急性传染病，特别是麻疹、百日咳**，可使机体免疫力降低，称为**结核病感染或活动、恶化的诱因**。
6. **结核菌素实验（PPD 试验）：**硬结**<5mm** 为(-)，**5~9mm** 为(+)，**10~19mm** 为(++)，**≥20mm** 为(+++)，出现水肿、破溃、淋巴管炎、双圈反应为**(++++)**。
1. 临床意义：

| | | |
|---|---|---|
|**阳性**||**阴性**|
|①**接种卡介苗（BCG）后**|①未感染结核|
|②**年长儿：**无明显症状，多为**既往感染结核**|②迟发型变态反应前期（**初次感染后<4~8 周**）|
|③**婴幼儿：**阳性多为**新近结核病灶**<br><br>**年龄越小，活动性结核可能性越大**|③**假阴性反应：**I. **免疫力低下或免疫抑制**<br><br>II. **重症结核（粟粒性、脑膜炎）**|
|④**强**阳性者，表示**活动性**肺结核|④技术误差、结核菌素失效|
|⑤阴性转阳性，或增幅>6mm 提示**新近结核感染**|

1. 实验室检查：结核分枝杆菌检查（**抗酸染色**、培养）、ELISA 测抗体、γ-干扰素释放试验、PCR、**ESR↑**。
2. 辅助检查：X 线（正侧位胸片）、胸部 CT、纤支镜、穿刺活检。
3. **抗结核药物治疗：**原则——早期、适量、联合、规律、全程、分段。

| | | | |
|---|---|---|---|
|**药物**|**抗菌机制**|**特点**|**副作用**|
|**异烟肼（INH，H）**|抑制 DNA、胞壁合成|**全**杀菌|**周围神经炎（处理：Vit B6）**、肝损|
|**利福平（RFP，R）**|抑制 mRNA 合成|**全**杀菌|**肝损（黄疸、ALT↑3 时停用）**、过敏|
|**链霉素（SM，S）**|抑制蛋白质合成|**半**杀菌|**耳毒性、肾毒性**、眩晕等|
|**吡嗪酰胺（PZA，Z）**|酸性环境抑菌|**半**杀菌|肝损、**高尿酸血症/痛风**、关节痛|
|**乙胺丁醇（EMB，E）**|干扰 RNA 合成|**抑菌**|**球后视神经炎（视力损害）**|
|**乙硫异烟胺（ETH）**|/|**抑菌**|/|

1. 预防：
1. **卡介苗（BCG）**接种：出生后即接种。
1. **禁止接种卡介苗：**①【**免疫力差**】先天性胸腺发育不全、严重联合免疫缺陷（SCID）、HIV；

②**急性传染病**恢复期；③【**皮肤**】注射部位局部湿疹或全身性皮肤病；④**PPD 试验阳性**者。

- 1. 预防性抗结核治疗：**异烟肼** 10mg/kg，**6~9 月**；或**异烟肼** 10mg/kg**+利福平** 10 mg/kg，3 个月。
1. 指征：①密切接触开放性肺结核者；②3 岁以下未接种 BCG+PPD 阳性；③PPD 阴性近期转阳性；④PPD 阳性+结核中毒症状；⑤PPD 阳性+**麻疹/百日咳**；⑥PPD 阳性+**激素/免疫抑制**治疗。

### （二）原发型肺结核（primary pulmonary tuberculosis）

1. **原发型肺结核（primary pulmonary tuberculosis）**包括**原发综合征**和**支气管淋巴结结核**。
2. **原发综合征（primary complex）：包括肺原发病灶、肺门/纵膈淋巴结病变、淋巴管炎。**

原发病灶多位于右肺的**上叶底部、下叶上部，靠近胸膜处**。典型表型为**“双极”或“哑铃”状**。

1. 临床表现：
1. 年龄较大儿童：症状轻微，可有低热、盗汗、纳差、疲乏等**结核中毒症状**。
2. 婴幼儿、症状加重者：**高热**但一般状况尚好，后转为**低热**，伴结合中毒症状、干咳、轻度呼吸困难。
3. 高度过敏状态者，可出现**眼疱疹性结膜炎、皮肤结节性红斑、多发性一过性关节炎**。
4. 胸内淋巴结肿大的压迫症状：①压迫气管分叉处→**百日咳样痉挛性咳喘**；②压迫支气管→部分阻塞→**喘鸣**；③压迫喉返神经→**声嘶**；④压迫静脉→胸部一侧或双侧**静脉怒张**。
2. 诊断：病史+临床表现+实验室检查+PPD+胸部 X 线/CT/支气管镜。
3. **抗结核治疗：**
1. 无症状：**9-12 月 INH、RFP±EMB**。 **b) 有症状：2HRZ/4HR 或 2HRZE/4HR 或 2HRZS/4HR。**

### （三）结核性脑膜炎（tuberculous meningitis）

1. **结核性脑膜炎（tuberculous meningitis）**是小儿结核病中最严重的类型，多为**血行传播**而来。

#### 临床表现：

| | | |
|---|---|---|
|**早期（前驱期）**|1~2 周|主要症状为**性格改变**（少言、少动、易怒、烦躁）；<br><br>可伴发热、头痛、纳差、盗汗、消瘦、呕吐、便秘等|
|**颅内压增高：**剧烈头痛、喷射性呕吐、嗜睡、烦躁；**脑膜刺激征**明显| | |
|**中期（脑膜刺激期）**|1~2 周|**脑神经损伤：面神经瘫痪**最常见，其次是**动眼神经、展神经瘫痪**|
|**眼底检查：**可见视盘水肿、视神经炎、**脉络膜粟粒状结节**| | |
|**晚期（昏迷期）**|1~3 周|**意识模糊、昏迷、惊厥**频发，最终发生脑疝而死亡|

1. **脑脊液检查：**①外观无色透明或**毛玻璃样**，静置后**蜘蛛网状薄膜形成**；②WBC **50~500×106/L**，以**淋巴细胞**为主；③**糖、氯化物降低，蛋白增高（1~3g/L）**；④脑脊液沉淀物**抗酸染色**镜检阳性。
2. 其他检查：结核抗原抗体检测、**腺苷脱氨酶（ADA，>9U/L）**、PPD（**强阳性或假阴性**）、脑脊液结核分枝杆菌培养、PCR、CT（基底核阴影增强、脑池密度增高、模糊、钙化，脑室扩大、脑水肿、脑梗灶）。

#### 胸片证明血性播散性结核病对确诊结核性脑膜炎有意义。

1. 并发症：**脑积水（最常见）**、脑实质损伤、脑出血、脑神经障碍（III、VI、**VII** 等），前三者是主要死因。
2. 后遗症：脑积水、肢体瘫痪、失明、失语症、智能低下、癫痫、尿崩症。

#### 治疗：

- 1. **抗结核治疗：**首选方案 **3HRZS/6~9HR**。
2. **糖皮质激素：**辅助疗法，用于降低颅内压，减轻中毒症状、脑膜刺激征，减少粘连、预防脑积水。
3. **降低颅内压：20%甘露醇**、乙酰唑胺、侧脑室穿刺引流、腰穿减压+鞘内给药、分流手术。

|**类型**|**机制**|**处理**|
