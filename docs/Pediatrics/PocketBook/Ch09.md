## 血液系统（Ch13）
1. 胚胎期造血：

## 小儿造血与血象特点

| | |
|---|---|
|**卵黄囊造血**|胚胎第 3 周开始，第 6 周开始减退|
|**肝脏造血**|胚胎第 6~8 周开始，后成为主要造血部位，4~5 个月达到高峰，6 个月后开始减退|
|**脾脏造血**|胚胎第 8 周开始造血，5 个月后逐渐减退|
|**胸腺、淋巴结**|胸腺第 6~7 周开始生成 T 细胞，淋巴结第 11 周开始生成 B 细胞|
|**骨髓造血**|胎儿第 4 月开始造血，迅速成为主要造血器官，出生后 2~5 周成为唯一的造血场所|

#### 出生后造血：

- - 1. 骨髓造血：婴幼儿期所有骨髓均为**红骨髓**，5~7 岁开始，**黄骨髓（脂肪组织）**开始替代红骨髓，年长儿、成年人红骨髓仅限于**肋骨、胸骨、脊椎、骨盆、颅骨、锁骨、肩胛骨**，黄骨髓有**造血潜能**。
2. 骨髓外造血：造血需求增加（感染、溶贫）时，**肝、脾、淋巴结**肿大、恢复造血状态，外周血出现**有核红细胞、幼稚中性粒细胞**，感染、溶贫纠正后恢复正常。

1. 血象特点：

| | |
|---|---|
|**RBC、Hb**|新生儿 **RBC 5~7×1012/L，Hb 150~220g/L**（新生儿贫血：_Hb<145g/L_）<br><br>**生理性贫血：2~3 月**时，RBC 降至 3**×1012/L**，Hb 降至 **100g/L** 左右，12 岁时达到成人水平<br><br>网织红细胞：出生 3 天内 4%~6%，|
|**WBC**|新生儿 WBC **15~20×109/L**，婴儿期 **10×109/L**，8 岁后接近成人水平<br><br>WBC 分类：出生时 N>L，**4~6 天、4~6 岁时 N=L**，期间 N<L，此外 N>L|
|**PLT**|100~300×109/L|
|**Hb 种类**|**胎儿型 HbF，成人型 HbA、HbA2**；出生时 HbF 占 70%，1 岁时HbF<5%，2 岁时HbF<2%|
|**血容量**|新生儿：**10%**体重，儿童：**8%~10%**体重，成人 6%~8%体重|

## 营养性缺铁性贫血

1. **缺铁性贫血（iron deficiency anemia，IDA）：**体内铁缺乏导致 Hb 合成↓，表现为**小细胞低色素性贫血、血清铁蛋白减少、铁剂治疗有效**。
2. 正常铁代谢：婴幼儿每日摄入 **1mg/kg**，排出量 **15μg/kg**，吸收部位为**十二指肠和空肠上段**（**Fe2+**形式）。

#### 功能性：血红蛋白、肌红蛋白、转铁蛋白（正常饱和率 1/3）、乳铁蛋白、酶/辅助因子结合的铁。

- 1. **贮存性：铁蛋白、含铁血黄素。**新生儿含量 75mg/kg。

1. 胎儿、婴幼儿、儿童期的铁代谢特点：
1. 胎儿期：同母体胎盘获得铁，**孕后期 3 个月**获得最多，**母体严重缺铁**可影响胎儿摄铁。
2. 婴幼儿期：**足月新生儿不易缺铁**（前 4~5 月），早产儿可早期出现缺铁。**6 月~2 岁** IDA 发病率高。
3. 儿童期：儿童期缺铁的主要原因是**偏食**。
2. 病因：**先天储存铁不足（早产儿）、铁摄入不足（主要原因）**、生长发育快、铁吸收障碍、铁丢失过多。
3. 临床表现：**6 月~2 岁**最多见。

| | |
|---|---|
|**一般表现**|皮肤黏膜**苍白**（口唇、甲床明显），易疲乏，可伴头晕、眼前发黑、耳鸣|
|**髓外造血**|**肝、脾轻度肿大**；年龄越小、病程越久、程度越重，肝、脾肿大越明显|
|**其他表现**|①食欲减退，**异食癖**，口腔炎，舌炎，吸收不良；②HR↑甚至心衰；③免疫力↓，可出现**反甲**|

1. 实验室检查：
1. 外周血象：**小细胞低色素性**贫血（**MCV<80fl，MCHC<320g/L，MCH<28pg**），RBC 中央浅染区↑。
2. 骨髓象：**增生活跃**（中、晚幼红细胞为主），各期红细胞偏小，**胞质成熟度晚于胞核（核老浆幼）**。
3. **铁代谢：SI、SF、TS、骨髓可染铁↓，TIBC、FEP↑。**

|**项目**|**生理意义**|**IDA**| |

| | | | | | |

|**状态**|**SF**|**骨髓铁染色**|**TS**|**FEP/Hb**|**贫血**|

1. **治疗：**
1. 一般治疗、去除病因。
2. 铁剂治疗：**口服铁剂（二价铁），两餐间**口服，**牛奶、钙剂等抑制吸收**；无效/不耐受者选**注射铁剂**。
1. 治疗反应：①补铁 **12~24h 后**，**细胞内含铁酶恢复**（最早出现），精神症状减轻，食欲增加；②**网织红细胞，2~3 天**开始上升，**5~7 天**达到高峰；③**Hb，1~2 周**开始上升，**3~4 周**恢复正常。
2. 治疗期限：**Hb 恢复正常后，再服用 6~8 周**。
3. 输血治疗：**一般不使用**，仅限于①贫血严重，尤其是发生**心衰**者；②合并**感染**者；③需外科**手术**者。

**Hb<30g/L 者，等量换血**；Hb 30~60g/L 者，输注红细胞悬液 **4~6mL/kg**，**_Hb>60g/L_ 者不必输血！**

1. 预防：婴幼儿**及时添加辅食，早产儿出生后 2 月左右**补充铁剂预防。

## 营养性巨幼细胞性贫血

#### 营养性巨幼细胞性贫血（nutritional megaloblastic anemia）：由于 Vit B12、叶酸缺乏导致的一种大细胞性贫血，特点是贫血、神经精神症状、骨髓中出现巨幼红细胞、Vit B12/叶酸治疗有效。

1. 病因：摄入不足（**单纯母乳喂养**，特别是**羊乳**喂养）、需求量增加、吸收代谢障碍（胃炎者**内因子**缺乏）。
2. 发病机制：叶酸、Vit B12 参与 **DNA 合成**，Vit B12 还可维持神经**髓鞘**完整性。

#### Vit B12 缺乏产生神经精神症状，叶酸缺乏主要引起情感改变。

1. 临床表现：

| | |
|---|---|
|**一般表现**|虚胖或轻度水肿，毛发纤细、稀疏、黄色，严重者有出血点、瘀斑|
|**贫血表现**|皮肤**蜡黄色**，结膜、口唇、指甲**苍白**，偶伴黄疸，疲乏无力，常伴**肝脾肿大**|
|**神经精神症状**|可有烦躁不安，易怒，**Vit B12** 缺乏可造成**表情呆滞、反应迟钝、智力/动作发育落后**<br><br>**/退步**（特征性），严重者**不规则震颤、手足无意识运动、抽搐、感觉异常、共济失调、**<br><br>**病理征阳性**；**叶酸**缺乏**不出现**神经症状，但可出现神经精神异常（**情感改变**）|
|**消化系统**|厌食、恶性、呕吐、腹泻、舌炎等|

1. 实验室检查：

| | |
|---|---|
|**外周血象**|**大细胞性贫血（MCV>94g/L）**，红细胞易见**嗜多色性、嗜酸性点彩**红细胞，可见**红细**<br><br>**胞巨幼变、中性粒细胞分叶过多**，可有**网织红细胞、WBC、PLT↓**|
|**骨髓象**|**增生明显活跃**，红系为主；**红系、粒系巨幼变**，中性粒细胞分叶过多，**巨大血小板**|
|**叶酸、Vit B12 测定**|血清 Vit B12<100ng/L、叶酸<3μg/L 为缺乏|

#### 治疗：

- 1. 一般治疗、去除病因。
2. **补充 Vit B12、叶酸**：有**神经精神症状**者以 **Vit B12** 治疗为主，**单用叶酸可能导致病情恶化！**
1. 治疗期限：治疗至**临床症状好转、血象恢复**为止。
2. 治疗反应：①治疗 6~7h/1d 内，**骨髓内巨幼红细胞恢复正常**；②**2~4 天，网织红细胞**开始增加

（_IDA 2~3_ 天），**4~7 天**达到高峰（_IDA 5~7_ 天）；③**2~6 周，Hb、RBC** 恢复正常（_IDA 3~4_ 周）。

- 1. **预防性补钾：**大量新生红细胞可导致细胞外钾转移至胞内，引起低钾血症甚至猝死，故需补钾。
