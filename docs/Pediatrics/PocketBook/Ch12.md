# 遗传病

## 遗传病（Ch16）

## 概述

- 1. **遗传性疾病（genetic disease）：**染色体病、单基因病、线粒体疾病、基因组印记、复杂遗传病。
1. 基因组印记：来自**不同亲代**的同一基因在子女中产生不同表型，如 PWS 和Angelman 综合征。
2. 实验室诊断技术：染色体核型分析、荧光原位杂交（FISH）、基因芯片、DNA 测序、生化检测等。
3. 三级预防：一级（避免近亲婚配；检出携带者，有效干预，**防止发生**）、二级（产前诊断，尽量**减少遗传性疾病患儿的出生**）、三级（**出生后**早期诊断、早期治疗，避免畸形）。

## 21-三体综合征

1. **唐氏综合征（DS）/21-三体综合征（trisomy 21 syndrome）/先天愚型：**母亲年龄越大，发生率越高。
2. **临床表现：**智能落后_+_外眦上斜_/_皮肤细腻_/_先心_/_通贯手

| | |
|---|---|
|**特殊面容**|**出生时即有**睑裂小、**眼距宽、外眦上斜**，可有**鼻梁低平、外耳小**、硬腭小、张口伸舌、<br><br>**头小而圆**、前囟大且关闭延迟、颈短而宽，常伴**嗜睡、喂养困难**|
|**智能落后**|**最突出、最严重**，随年龄增长日益明显，行为动作定型化，抽象思维能力损失最大|
|**生长发育迟缓**|体格发育、动作发育迟缓，身材矮小、骨龄落后，四肢短，肌张力低下，可伴脐疝等|
|**伴发畸形**|①隐睾/无月经，**生育力差**；②50%**先心**；③**甲低、急淋**发病率高；④**免疫力低**；⑤**早衰**|
|**皮纹特点**|**通贯手**（手掌出现猿线，atd 角度>45°）|

## 苯丙酮尿症

1. **苯丙酮尿症（phenylketonuria，PKU）：**一种**常染色体隐性**遗传病，由于**苯丙氨酸羟化酶（PAH）**缺乏致苯丙氨酸及其代谢产物在体内蓄积，临床特点为**智能发育落后、皮肤毛发色素浅淡、鼠尿臭味**。
2. 病因：**苯丙氨酸（Phe）是必需氨基酸**，通过**苯丙氨酸羟化酶（PAH）**转化为**酪氨酸（Tyr）**。PAH 缺乏者苯丙氨酸蓄积，通过**旁路代谢**产生大量**苯丙酮酸、苯乙酸**、苯乳酸、对羟基苯乙酸，导致脑损伤。
1. 不典型 PKU：辅酶**四氢生物蝶呤（BH4）**缺乏，可能是 GTP-CH、PTPS、DHPR 等基因缺陷。
3. **临床表现：出生时正常**，3~6 月出现，1 岁时明显。智能发育落后_+_白_/_鼠臭味_/_肌张力高_/_癫痫

| | |
|---|---|
|**神经系统**|**智力发育落后**最突出，可有**行为异常**（不安、抑郁、多动、孤僻）**、癫痫小发作、肌张力增高**|
|**皮肤**|黑色素合成不足，**头发由黑变黄，皮肤白皙**，皮肤湿疹多见|
|**体味**|尿液、汗液有**鼠臭味（苯乙酸）**|

1. 辅助检查：
1. **新生儿筛查：**足跟血测定**苯丙氨酸**浓度。
2. **氨基酸浓度测定：苯丙氨酸>1200μmol/L。**
3. 不典型 PKU：**尿蝶呤图谱分析**。
4. **DNA 分析：**PAH、PTPS、DHPR 等基因。
2. 治疗：**低苯丙氨酸饮食（可选母乳）**，至少持续到**青春期**，检测血 Phe 浓度。**怀孕时也需低 Phe 饮食**。
1. 四氢生物蝶呤（BH4）缺乏者，需补充 **BH4、5-HT、L-DOPA**。DHPR 基因缺陷者需低 Phe 饮食。
