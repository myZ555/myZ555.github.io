# 呼吸系统

## 呼吸系统（Ch10）
1. 生理特点：

## 概述

- - 1. 呼吸频率：**新生儿~40 次/min，~1 岁 ~30 次/min，~3 岁 ~24 次/min，学龄前~22 次/分**。
2. 呼吸类型：婴幼儿为腹式呼吸（abdominal respiration），后转为胸腹式呼吸，7 岁后接近成人。
3. 呼吸功能：肺活量（VC）约 50~70mL/kg，潮气量（TV）约 6~10mL/kg。
4. 免疫功能：**sIgA** 含量少，易发生感染。

#### 临床表现：

| | | |
|---|---|---|
|**呼吸急促**|呼吸困难的首要表现，**<2 月：R≥60bpm，2~12 月：R≥50bpm，1~5 岁：R≥40bpm**| |
|**发绀（cyanosis）**|血样下降的重要表现，中心性发绀（舌、黏膜）更有意义| |
|**吸气性胸廓凹陷**|**上呼吸道梗阻或严重肺部病变**时，出现**吸气性**胸骨上窝、锁骨上窝、肋间隙凹陷| |
|**吸气喘鸣（stridor）**|**上呼吸道梗阻**时，**吸气**时出现喘鸣音伴吸气相延长| |
|**呼气呻吟（grunting）**|**下呼吸道梗阻或肺扩张不良**时，出现呼气呻吟（常见于 RDS）| |
||**哮鸣音**|**呼气**相明显，提示**细小支气管梗阻**|
|**异常呼吸音**|**不固定的中、粗湿啰音**|提示支气管存在分泌物，常见于**支气管炎**|
|**固定的细湿啰音**| |提示肺泡内存在分泌物，常见于各种**肺炎**|
|**杵状指/趾**|支扩、慢性肺炎可见||

- 1. 血气分析：
1. **呼吸衰竭：PaO2<60mmHg、PaCO2>50mmHg、SaO2<85%。**

## 哮喘

1. **支气管哮喘（bronchial asthma）：**儿童期**最常见**的慢性呼吸道疾病。哮喘是由多处细胞与炎症介质参与的**气道慢性炎症性疾病**，导致**气道反应性增加（AHR）**，通常出现广泛多变的**可逆性气流受限**。
2. 发病机制：免疫因素、神经精神内分泌因素、遗传因素、神经信号通路。
3. 危险因素：吸入/使用过敏原、呼吸道感染、情绪变化、运动、过度通气、冷空气、药物、职业粉尘等。
4. 病生：**气流受阻**是核心改变（支气管痉挛、炎性肿胀、黏液栓、气道重塑），**气道高反应性**是基本特征。
5. **临床表现：发作间期无任何症状、体征。**

| | | |
|---|---|---|
|**一般症状**|**阵发性**的**呼气性呼吸困难**伴**喘鸣声**，夜间、清晨为重|**体征：**桶状胸、三凹征，双肺**呼吸性哮鸣音**，可伴不固定的粗湿啰音|
|**重症症状**|哮鸣音消失——**沉默肺/闭锁肺（silent lung）**|
|**哮喘持续状态/危重状态：**经支气管舒张剂、糖皮质激素治疗后**，仍有严重或进行性呼吸困难**| | |

1. **咳嗽变异型哮喘：**①**咳嗽>4 周，干咳**为主，不伴喘息；②**无感染征象/抗生素无效**；③抗哮喘治疗有效。
2. **诊断：典型临床表现+以下任意 1 条——**
1. **支气管舒张试验**阳性（吸入 SABA 后 **FEV1 增加≥12%**）或抗炎治疗肺通气改善（FEV1 增加≥12%）。
2. **支气管激发试验**阳性（**FEV1 下降≥20%**）。 c) **PEF 日间变异率≥13%**。
3. 临床分期：**急性发作期、慢性持续期**（3 月来出现不同程度的症状）**、临床缓解期**（症状体征消失>3 月）。
4. 鉴别诊断：毛细支管炎（RSV 感染）、肺结核、气道异物、先天性呼吸系统畸形/发育不良、先心病等。

#### 治疗：

| | |
|---|---|
|**哮喘急性发作期**|**速效 β2 受体激动剂（SABA）**：首选，如**沙丁胺醇、特布他林**（吸入）|
|**糖皮质激素：病情较严重**者**口服**泼尼松或**静注**氢化可的松/甲泼尼龙|
|其他：抗胆碱能药物（SAMA，如异丙托溴铵）、短效茶碱类|
|一般治疗：**吸氧**、补液、纠正酸中毒| |
||**糖皮质激素：全身应用（静注），不能吸入！**|
|**哮喘危重状态**|**支气管扩张剂：**①吸入速效 β2 受体激动剂（SABA）；②**氨茶碱**静注；③抗胆碱能药<br><br>物；④1:1000 肾上腺素 0.01mL/kg 皮下注射|
||其他：镇静、抗生素|
|**机械通气的指征：①严重呼吸困难；②呼吸音降低或听不大哮鸣音（沉默肺/闭锁肺）；**<br><br>**③呼吸肌疲劳、胸廓运动受限；④烦躁、意识障碍、昏迷；⑤发绀；⑥PaCO2≥65mmHg**| |
|**哮喘慢性持续期**|**吸入糖皮质激素（ICS）：**首选，如布地奈德、氟替卡松、倍氯米松|
|其他：白三烯调节剂、缓释茶碱、长效 β2 受体激动剂（LABA）、肥大细胞膜稳定剂<br><br>（色甘酸钠，预防运动、刺激因素诱发的哮喘）、抗 IgE 抗体、过敏原特异性免疫治疗|

## 肺炎

#### （一）概述

1. 分类：

| | |
|---|---|
|**病理分类**|大叶性肺炎、支气管肺炎（小叶性肺炎）、间质性肺炎|
|**病因分类**|病毒性（**呼吸道合胞病毒RSV** 最常见）、细菌性、支原体性、衣原体性、<br><br>原虫性、真菌性、非感染性（吸入性、坠积性、嗜酸性粒细胞性/过敏性）|
|**病程分类**|**急性<1 月，迁延性 1~3 月，慢性>3 月**（腹泻：急性_<2_ 周，慢性_>2_ 月）|
|**病情分类**|轻症（仅呼吸系统）、重症（其他系统受累，并发症、全身中毒症状明显）|
|**临床表现**|**典型肺炎、非典型肺炎**（支原体、衣原体、军团菌、SARS 等）|
|**发生地点**|**社区获得性肺炎（CAP）、医院获得性肺炎（HAP）**|

1. 病理生理：

| | |
|---|---|
|**呼吸功能不全**|通气、换气障碍→**PaO2、SaO2↓、PaCO2↑**→R、HR↑；可并发**呼吸衰竭**|
|**酸碱平衡失调、电解质紊乱**|**代酸、呼酸/呼碱**，可引发**低钠血症**（稀释性/SIADH）|
|**心血管系统**|**肺动脉高压、中毒性心肌炎→心衰**（最常见并发症），甚至出现休克、DIC|
|**神经系统**|脑水肿、颅内压增高、**缺氧中毒性脑病**|
|**胃肠道功能紊乱**|消化道出血、**缺氧中毒性肠麻痹**|

#### （二）临床表现

1. **主要表现：**①**发热**，热型不定；②**咳嗽**，早期干咳→极期减轻→恢复期有痰；③**气促**；④**全身不适**。
2. **体征：**①**呼吸增快**，R 40~80bpm；②**发绀**；③**肺部啰音：固定的中细湿啰音**，多位于背部两侧下方、脊柱两旁，**深吸气末**更明显。

#### 重症肺炎的表现：

| | |
|---|---|
|**心力衰竭**（最常见，全心衰）|【一大二快三突然】**诊断标准：**①平静时突然 **R>60 次/min**；②平静时突然 **HR>180 次/min**；③极度**烦躁**不安、**发绀**、面色苍白、**微血管再充盈时**<br><br>**间↑**；④**心音低钝、奔马律、颈静脉怒张**；⑤**肝脏迅速增大**；⑥**少尿/无尿**|
|**缺氧中毒性脑病**|**诊断标准：**①**烦躁、嗜睡**、眼球上窜/凝视；②**球结膜水肿、前囟隆起**；③**昏睡、昏迷、惊厥**；④**瞳孔对光反射迟钝/消失**；⑤**呼吸节律不整**，呼吸心<br><br>跳解离（有心跳、无呼吸）；⑥**脑膜刺激征**；⑦脑脊液检查压力↑，**余正常**|
|**缺氧中毒性肠麻痹**|频繁呕吐、严重**腹胀，呼吸困难加重，肠鸣音消失**；严重者**消化道出血**|
|**抗利尿激素异常分泌综合征**<br><br>**（SIADH）/稀释性低钠血症**|**诊断标准：**①**血钠≤130mmol/L**，**渗透压<275mOsm/L**；②**尿钠≥20mmol/L**；<br><br>③无血容量不足，皮肤弹性正常；④**尿渗透压>血渗透压**；⑤肾功能正常；<br><br>⑥肾上腺皮质功能正常；**ADH 升高者为 SIADH，否则为稀释性低钠血症**|
|**DIC**|血压下降、四肢冰凉、脉搏细弱、皮肤黏膜出血|

2. 并发症：**金葡菌**肺炎多见。

|---|---|---|
|**并发症**|**临床表现**|**胸部 X 线**|
|**脓胸（empyema）**|**高热**、呼吸困难，患侧呼吸运动受限，语颤减弱，叩诊**浊音**，呼吸音减弱/上方管状呼吸音，<br><br>气管、纵膈移向健侧，肋间隙饱满|肋膈角变钝或**胸腔积液征**|
|**脓气胸（pyopneumothorax）**|呼吸困难加重、咳嗽，叩诊**上方鼓音/下方浊音**|**气液平面**|
|**肺大疱（pneumatocele）**|体积大者引起呼吸困难|**薄壁空洞**|
|**肺脓肿（pulmonary abscess）**|多为**需氧化脓菌感染（金葡、肺克）**，**高热、**<br><br>**咳嗽、大量浓臭痰、咯血**、呼吸困难、胸痛|**圆形阴影或液气平面**|

|**好发季节**|/|冬春季|冬春季|

#### （四）诊断

1. 血常规：**细菌性肺炎，WBC↑、N↑**、核左移；**病毒性肺炎，WBC 正常或↓，部分 L↑**/异型淋巴细胞。

#### C-反应蛋白（CRP）、前降钙素（PCT）：上升多见于细菌感染。

1. 细菌病原学检查：**细菌涂片、培养**，抗体检测、PCR 等。
2. 病毒病原学检查：病毒分离、**抗体检测（IgM 早期诊断，IgG 升高 4 倍确诊）、抗原检测**、PCR。
3. 其他：①**支原体：冷凝集素试验、抗原/抗体测定**等；②衣原体：细胞培养、免疫荧光/Giemsa 染色等。
4. 鉴别诊断：

| | |
|---|---|
|**急性支气管炎**|无发热/低热，以咳嗽为主，**肺部干湿啰音位置不固定**，胸部 X 线提示**肺纹理增多**|
|**支气管异物**|**异物吸入史**，突然出现**呛咳**，可伴**肺不张、肺气肿**，可继发肺炎|
|**支气管哮喘**|可无明显喘息发作而表现为持续性咳嗽，胸部 X 线提示**肺纹理增多、肺气肿**等|
|**肺结核**|一般有结核接触史，**PPD(+)**，胸部 X 线或 CT 可鉴别|

#### （五）治疗

1. 一般治疗与对症治疗：休息，补充营养，注意隔离，补充水、电解质。
1. **氧疗：**缺氧者（烦躁、发绀、**SaO2<60mmHg**）予吸氧，**鼻导管吸氧 0.5~1L/min，面罩吸氧 2~4L/min**。
2. 气道管理：吸痰、雾化吸入。 c) 退热：首选**物理降温**。
2. 抗感染治疗：
1. 抗菌药物治疗：一般治疗至**热退、症状改善后 3~5 天**。

| | | |
|---|---|---|
|**病原体**|**药物选择**|**治疗时间**|
|**肺炎链球菌**|**青霉素**或阿莫西林；耐药者选**头孢类**；过敏者选**大环内酯类**|总疗程 **7~10 天**|
|**金黄色葡萄球菌**|不耐药者首选**苯唑西林**或氯唑西林，耐药者首选**万古霉素**|总疗程**≥6 周**|
|**支原体、衣原体**|首选**大环内酯类**（红霉素、阿奇霉素）|总疗程 **7~14 天**|

- 1. 抗病毒治疗：**利巴韦林**（病毒唑）**、α-干扰素（IFN-α）、奥司他韦**（抗流感）等。

1. **糖皮质激素：**甲泼尼龙、氢化可的松、地塞米松等，使用指征为**①严重憋喘、呼吸困难；②全身中毒症状明显；③合并感染中毒性休克；④脑水肿（缺氧中毒性脑病）；⑤胸腔短期内大量渗出**。
2. 并发症治疗：
