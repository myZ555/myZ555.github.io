# 风湿性疾病

## 第一节 | 概 述

## 第二节 | 风湿热

1. **风湿热（rheumatic fever）：**咽喉部感染 **A 组乙型溶血性链球菌**后发生的风湿性疾病，主要累及**关节、心脏、皮肤**，偶可累及 **CNS**、血管、浆膜、肺、肾。最常见的发病年龄是 **5~15 岁**。
2. 病因：**A 组乙型溶血性链球菌**，与与机体器官抗原存在同源性，引起**交叉免疫反应（分子模拟）**。
3. 临床表现：发病前 1~6 周有**链球菌感染后咽峡炎**病史，如发热、咽痛、咳嗽、颈淋巴结肿大。
4. **一般表现：发热**，可伴精神不振、疲倦、纳差、面色苍白、多汗、关节痛、腹痛等。
5. **心脏炎：心肌炎**（严重者心衰）**、心内膜炎**（二闭、主闭，反复发作引发风心）**、心包炎**。
6. **关节炎：多发性游走性关节炎**，以**大关节**为主（膝、踝、肘、腕），愈后**不留畸形**，此起彼伏。
7. **舞蹈病：**全身或部分肌肉不自主快速运动，如伸舌歪嘴、挤眉弄眼等，常伴肌无力、情绪不稳定。
8. **皮肤症状：**①**环形红斑**（躯干、四肢近端淡色红斑）；②**皮下结节**（**坚硬无痛**结节，与皮肤**不**粘连）。
9. 辅助检查：
10. 链球菌感染证据：**咽拭子培养**→A 组乙型溶血性链球菌，**感染 _1_ 周后 ASO↑**。
11. 风湿热活动指标：**WBC↑、N↑、ESR↑、CRP↑**。

##### Jones 诊断标准（1992）：

1. 鉴别诊断：JIA、急性化脓性关节炎、白血病、生长痛、感染性心内膜炎、病毒性心肌炎。
2. 治疗：
3. **卧床休息：**取决于心脏受累程度、心功能状态（**无心脏炎-2 周，心脏炎-4 周，心衰-至少 8 周**）。
4. **清除链球菌感染：青霉素 80 万 U 肌注**，持续 2 周。
5. 抗风湿热治疗：**心脏炎时使用糖皮质激素**，**无**心脏炎者使用 **NSAIDs（如阿司匹林）**。
6. 其他治疗：**心衰**时及时予**糖皮质激素**，**慎用**洋地黄类，低盐饮食，必要时吸氧、利尿、扩血管；**舞蹈病**时可予苯巴比妥、地西泮等**镇静剂**；关节肿痛时予制动。
7. 预防：曾患风湿热者每 3~4 周肌注**苄星青霉素（长效）**120 万U，拔牙/手术前后**预防性使用抗生素**。
8. 预后：主要取决于**心脏炎**程度。

## 第三节 | 幼年型特发性关节炎

1. **幼年特发性关节炎（juvenile idiopathic arthritis，JIA）：儿童时期（<16 岁）**不明原因关节肿胀、疼痛**>6周**，又称为幼年类风湿性关节炎（JRA）、Still 病、幼年慢性关节炎（JCA）、幼年型关节炎（JA）。
2. 分类：

| **分类**                                                     | **定义**                                                     | **临床表现**                                                 |
| ------------------------------------------------------------ | ------------------------------------------------------------ | ------------------------------------------------------------ |
| **全身型幼年特发性关节炎**（systematic JIA）                 | 关节炎+**发热>2 周**+①短暂红斑样**皮疹**；②**肝、脾、淋巴结肿大**；③**浆膜炎** | 弛张热，皮疹随体温升降出现消失，多/少关节炎，伴四肢酸痛      |
| **多关节型，类风湿因子阴性**（polyarthritis, RF negative）   | 发病**最初 _6_ 个月**有 **5 个及以上**关节受累<br>**RF(-)**  | 起病高峰为 1~3 岁、8~10 岁，女孩多见，可有颞颌关节受累       |
| **多关节型，类风湿因子阳性**（polyarthritis, RF positive）   | 发病**最初 _6_ 个月**有 **5 个及以上**关节受累<br>**RF(+)**  | 女孩多见，儿童后期起病，与成人 RA 相似，可出现类风湿结节     |
| **少关节炎型**（oligoarthritis）                             | 发病**最初 _6_ 个月**有 **1~4 个关节**受累<br>分为：**持续型/扩展型**少关节型 | <5 岁女孩多见，好发于大关节，非对称性，可伴虹膜睫状体炎      |
| **与附着点炎症相关的关节炎****（enthesitis-related arthritis） | ①**骶髂关节**压痛，或炎性腰背痛；<br>②**HLA-B27(+)**；<br />③**6 岁以上男性**患儿；<br>④一级亲属有 HLA-B27 相关疾病 | **男孩**多见，骶髂关节病变为主典型症状为下腰部疼痛、骶髂关节压痛，后期腰部活动受限 |
| **银屑病性关节炎**（psoriatic arthritis）                    | 关节炎**+银屑病**，或：<br/>①**指/趾炎**；②**指甲凹陷/脱离**；③家族史 | 女性为主，不对称性关节受累                                   |

1. 辅助检查：
	1. 血液检查：**ESR↑、CRP↑**、IL-1↑、IL-6↑；**类风湿因子（RF）、抗核抗体（ANA）**等。
	2. 其他检查：关节炎液分析、滑膜组织学检查、血常规、X 线检查、骨关节彩超、MRI。
2. 鉴别诊断：全身感染、肿瘤、风湿热、化脓性关节炎、关节结核、创伤性关节炎、SLE、HSP、KD 等。
3. **治疗：**不主张过度卧床休息，适当活动，眼部检查（虹膜睫状体炎）。
	1. **NSAIDs：首选**，萘普生、布洛芬、双氯芬酸钠、尼美舒利等。
	2. **缓解病情的抗风湿药（DMARDs）/慢作用抗风湿药：甲氨蝶呤（MTX）**、羟氯喹、柳氮磺吡啶等。
	3. **肾上腺皮质激素：不作为首选**，应用指征：
		1. 全身型：NSAIDs 及其他治疗无效者。
		2. 多关节型：NSAIDs、DMARDs 无效者。
		3. **少关节型、银屑病性：不主张使用**。
	4. **虹膜睫状体炎：散瞳剂+激素**滴眼。
	5. 其他：免疫抑制剂（环孢素 A、环磷酰胺等）、生物制剂（抗 TNF-α、抗 IL-6 等）、IVIG、理疗。
	6. 并发症可并发关节功能丧失、虹膜睫状体炎，病情易反复，致死性并发症巨噬细胞活化综合征（MAS）。

## 第四节 | 过敏性紫癜

1. **过敏性紫癜（anaphylactoid purpura）/亨-舒综合征（HSP）：**以**小血管炎**为主要病变的系统性血管炎，临床特点为**血小板不减少性紫癜**。常伴**关节肿痛、腹痛、便血、血尿、蛋白尿**。
2. 病因：过敏、药物，微生物、疫苗、麻醉、肿瘤等，**A 组溶血性链球菌**感染是诱发 HSP 的重要原因。
3. 发病机制：感染源、过敏因素+遗传背景→B 细胞克隆扩增→分泌大量 IgA、IgE→**IgA 相关的血管炎**。
4. **临床表现：起病前 1~3 周常有上感史。**
	1. **皮肤紫癜：**多见于**四肢、臀部**，伸侧较多，分批出现。初起为**紫红色皮疹**，高出皮面，**压之不褪色**，数日后变暗紫色，一般 **4~6 周**消退。少数重症患儿紫癜可融合成大疱伴出血性坏死。
	2. **胃肠道症状：**一般以**阵发性腹痛**为主，可伴**呕吐**，部分出现**黑便/血便**。
	3. **关节症状：**膝、踝、肘、腕等**大关节**肿痛、活动受限，关节腔有**浆液性**积液，**不遗留后遗症**。
	4. **肾脏症状：**多数患儿出现**血尿、蛋白尿、管型尿（紫癜型肾炎）**，少数呈**肾病综合征**表现。
	5. 其他：偶见颅内出血、出血倾向、心肌炎、心包炎，累及呼吸系统发生喉头水肿、哮喘、肺出血。
5. 辅助检查：
	1. 血检：**PLT 正常**，出血时间、凝血时间正常，部分**毛细血管脆性试验**阳性，**血清 IgA 升高**。
	2. 尿常规：可见**红细胞、蛋白质、管型**。 
	3. 粪常规：**隐血试验**阳性。
	4. 其他：腹部超声（诊断肠套叠），头颅 MRI，肾穿刺活检等。

- 治疗
	1. **一般治疗：**休息，去除病因。有荨麻疹或血管神经性水肿时应用**抗组胺药、钙剂**；腹痛时使用解痉剂；消化道出血时禁食+西咪替丁，必要时输血。
	2. **糖皮质激素治疗：**可缓解**消化道症状（腹痛、出血）、关节痛**，**不能预防紫癜、肾脏损害！**
	3. *免疫抑制剂：**严重的**过敏性紫癜肾炎**可使用**激素+免疫抑制剂**（环磷酰胺、硫唑嘌呤等）。
	4. 其他：抗凝治疗（阿司匹林、双嘧达莫、肝素）、CCB（硝苯地平）、NSAIDs（萘普生）等。

## 第五节 | 川崎病

- 川崎病（Kawasaki disease，KD）：黏膜皮肤淋巴结综合征（mucocutaneous lymph node syndrome）

1. 病理：**全身性血管炎**，易累及**冠状动脉**。

2. 自然病程

	|                    | 急性期d1-11                                                  | 亚急性期d11-21                                               | 恢复期d21-60                                                 | 恢复期                                 |
	| ------------------ | ------------------------------------------------------------ | ------------------------------------------------------------ | ------------------------------------------------------------ | -------------------------------------- |
	| 临床表现           | 高热、眼结膜充血、皮疹、口腔病变、淋巴结肿大、烦躁、血沉快、C反应蛋白和白细胞增高 | 热可能仍有余波，继续烦躁，但减轻消失，眼结膜充血末痊愈，指趾端脱皮，血小板增高 | 症状完全消失，眼结膜稍留充血，淋巴结消肿，血沉、白细胞渐正常 | 大多健好                               |
	| 冠脉及其他动脉病变 | 动脉周围炎，微血管及小动脉、小静脉炎，中型及大型内膜炎症     | 动脉瘤，血栓形成，中型动脉狭窄，血管壁水肿                   | 血管的炎症减轻，动脉瘤可逐渐消退                             | 瘢痕形成，内膜增厚                     |
	| 其他并发症         | 心肌炎，包括房室传导系统炎症。心包炎，二尖瓣关闭不全，心衰，虹膜睫状体炎，无菌脑膜炎，无菌脓尿，早发的关节炎(年长儿明显) | 冠状动脉瘤，冠状动脉血栓，梗塞，二尖瓣关闭不全，晚发的关节炎，胆囊积水 | 关节炎可未全消，婴儿患者恢复活泼成长                         | 少数有心绞痛，冠状动脉狭窄，心功能不全 |
	| 致命原因           | 心肌炎，心律不齐                                             | 心肌梗死，动脉瘤破裂，心肌炎，心律不齐                       | 心肌梗死，缺血性心脏病                                       | 心肌梗死                               |

	

3. ==完全川崎病诊断标准：发热>5 天+①~⑤中至少 4 项：==

  ①双侧球结膜充血

  ②口唇及口腔的变化：口唇干红，**草莓舌**，口咽部黏膜弥漫性充血

  ③皮疹（包括单独出现的卡疤红肿）

  ④四肢末梢改变：急性期手足发红、肿胀，恢复期甲周脱皮

  ⑤非化脓性颈部淋巴结肿大

  ==不完全KD==：⑴存在6个临床特征中的3个伴冠状动脉扩张并排除其他高热疾病；⑵存在3或4种主要临床特征，但无冠状动脉扩张，但具有其他重要临床特征列表中的特征

4. 临床表现

  1. **发热**：一般39°C以上，为最初表现，热程在5天以上，一般为一、二周，有的热退一、二天又高，热程长的可达三、四周，退热药仅短暂稍降。如阿司匹林口服加丙种球蛋白静脉滴注，热可在一、二天内下降
  2. **皮疹**：发热数日后掌跖面红肿且痛，躯干部出现大小不一斑丘疹，形态无特殊，面部四肢亦有，不痒，无疱疹或结痂
  3. **眼睑膜充血**：发热数日两侧眼结膜充血，裂隙灯可能查到前虹膜睫状体炎
  4. **口腔表现**：口唇红肿、干燥和皲裂，甚至出血。**杨梅舌**。口腔黏膜充血但无溃疡
  5. **颈部淋巴结肿大**：非化脓性，数日后消退
  6. 其他：病程第二周部分可有奔马律及心音低钝，偶有二尖瓣反流的收缩期杂音，X线心影略大；35%在早期有水泻和轻度腹痛及呕吐；呕吐持续伴脑膜刺激症状，应行腰穿；如右上腹有压痛，可能为胆囊积水，应行超声检查

  > - 心脏表现：病程第 1~6 周出现**心包炎、心肌炎、心内膜炎、心律失常**，第 2~4 周/恢复期发生**冠状动脉损害**（d>3mm 为扩张，d>4mm 为动脉瘤；d≥8mm 为巨大动脉瘤；或冠状动脉狭窄）。
  > - 心梗、冠状动脉瘤可致心源性休克、**猝死**。<2 岁男孩，ESR、PLT、CRP↑是冠脉病变的高危因素。
  > - 其他表现：间质性肺炎、无菌性脑膜炎、消化系统症状、关节痛、关节炎等。
  > - 原**接种卡介苗（BCG）瘢痕处再现红斑**，对不完全型 KD 诊断有重要价值。

5. 辅助检查：

  | 项目           | 要点                                                         |
  | -------------- | ------------------------------------------------------------ |
  | **血液检查**   | **WBC↑、N↑**伴核左移，轻度贫血，第 2~3 周时 **PLT 增多，ESR↑、CRP↑**，转氨酶↑ |
  | **免疫学检查** | IgG、IgM、IgA、IgE 升高，IL-6 升高，补体正常或升高           |
  | **胸部 X 线**  | 肺纹理增多、模糊或片状阴影，心影可扩大                       |
  | **ECG**        | ST-T 段变化，心包炎时 ST 段抬高、低电压，心梗时 ST 段抬高、T 波倒置、病理性 Q 波 |
  | **冠脉病变**   | **超声心动图（最重要的辅助检查手段）**、冠脉造影、冠脉 CT 等 |

6. 鉴别诊断：渗出性多形性红斑、JIA 全身型、败血症、猩红热。

7. **治疗：首选阿司匹林+IVIG。**
  1. **阿司匹林：**每日 **30~50mg/kg**，**热退 3 天**后减量，维持 **6~8 周**/冠脉病变消退（维持剂量 **3~5mg/kg**）。
  2. 伴有冠状动脉病变者，服药时间需延长，**直到冠脉病变消失（小剂量维持）**。
  3. **静脉注射丙种球蛋白：**推荐 **2g/kg**，发病早期应用，可退热、**预防冠脉病变**发生。
  4. 糖皮质激素：**不宜单独使用**（可增加冠脉病变风险），仅用于 **IVIG 非敏感型** KD。
  5. IVIG 非敏感型 KD：发病 10 天内接受 IVIG 2g/kg 治疗，**IVIG 使用后 36~48h**，仍 T>38℃或再次发热。
  6. 治疗方案：①**再次应用 IVIG 2g/kg**；②**糖皮质激素+阿司匹林**。

8. 预后：**自限性**，多数预后良好。无冠脉病变者出院后**第 1、3、6、12 月后复查**（体检、ECG、心超），**冠脉者病变大多数于 2 年内自行消失**，但常遗留管壁增厚、弹性减弱，**巨大动脉瘤需外科手术介入**。
