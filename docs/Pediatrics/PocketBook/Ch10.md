# 神经系统

## 神经系统（Ch14）

## 概述

- 1. 脑的发育特点：①新生儿神经元数目接近成人，但树突、轴突短而少；②胎儿期脑发育最快；③新生儿

髓鞘发育不完善，因此对外来刺激反应慢，且易于泛化，不易形成兴奋灶，易疲劳进入睡眠状态。

- 1. 脊髓的发育特点：**新生儿**脊髓末端位于 **L2**，**4 岁**左右脊髓末端位于 **L1**，婴幼儿腰穿位置选择 **L4/5**。
2. 神经反射：

| | | |
|---|---|---|
|**原始反射**|拥抱反射、吮吸反射、觅食反射、握持反射等|**出生时即出现，2~7 月**前陆续消失|
|**浅反射**|腹壁反射、提睾反射|出生时**无**，4 月~1 岁才开始出现|
|**深反射**|肱二头肌反射、膝反射、踝反射|**出生时即存在，**但婴幼儿**较弱**|
|**病理反射**|Babinski 征、Chaddock 征、Gordon 征、Oppenheim 征|**<2 岁 Babinski 征可双侧阳性**|
|**脑膜刺激征**|颈项强直、Kernig 征、Brudzinski 征|**<3~4 月 Kernig 征可为弱阳性**|

#### 附：热性惊厥

- **热性惊厥（febrile seizures，FS）：**婴幼儿期最常见的惊厥性疾病，需排除 CNS 感染及其他疾病。
- 特点：①多见于 **3 月~6 岁**，一般体质较好；②多发生于**病初体温骤升时**，发作前后一般状况良好；③

**无神经系统体征**；④热退 1 周后 EEG 正常；⑤**反复发作**倾向。（肺炎时不是 _FS_，而是缺氧中毒性脑病）

- - 单纯型：①**全面性发作**，无局灶发作特征；②发作时间**<15min**；③24h 内/同一病程中**仅发作 1 次**。
- 复杂型：①**局灶性发作**；②发作时间**>15min**；③24h 内/同一病程中发作**≥2 次**。
- 治疗：首选**苯二氮䓬类（地西泮）**；**新生儿**首选**苯巴比妥**；惊厥**持续状态**首选**苯妥英钠（鲁米那）**。

## 化脓性脑膜炎

#### 化脓性脑膜炎（purulent meningitis）/急性细菌性脑膜炎（acute bacterial meningitis）：各种化脓性细菌引起的脑膜炎，以急性发热、惊厥、意识障碍、颅内压增高、脑膜刺激征、脑脊液脓性改变为特征。

1. 病因：

| | |
|---|---|
|**<3 月婴儿**|G-（**大肠埃希菌**、铜绿假单胞菌）**、金黄色葡萄球菌**|
|**3 月~3 岁婴幼儿**|**流感嗜血杆菌、肺炎链球菌**、脑膜炎双球菌|
|**学龄前、学龄期**|**脑膜炎双球菌**、肺炎链球菌、流感嗜血杆菌、金黄色葡萄球菌|

1. 发病机制：**血行传播**（最常见）、邻近器官感染（中耳炎、乳突炎）、颅骨骨折、颅脑手术、皮肤窦道等。
2. **临床表现：**肺炎链球菌以冬春季为主，脑膜炎奈瑟菌、流感嗜血杆菌以春秋季为主。

| | |
|---|---|
|**感染中毒症状**|发热，烦躁不安；**脑膜炎双球菌**感染可见**淤点瘀斑**、休克|
|**脑功能障碍**|**烦躁、意识障碍（精神萎靡、嗜睡、昏迷）、惊厥**|
|**颅内压增高**|**头痛、呕吐**，婴儿出现**前囟饱满、头围增大**；合并**脑疝**时出现**呼吸不规则、瞳孔不等大**|
|**脑膜刺激征**|**颈项强直**（最常见）**、Kernig 征、Brudzinski 征**|

1. **新生儿、3 个月以下**婴儿的不典型表现：①体温**可高可低**，甚至体温不升；②颅内压增高**不明显**，可能有吐奶、尖叫、**颅缝分离/前囟饱满**；③惊厥不典型、不明显。（_≈_新生儿败血症_+_颅缝分离_/_前囟饱满）
2. **脑脊液检查：**严重颅内压增高者**必须先降低颅内压**，否则可能诱发脑疝。
1. 压力明显增高，外观**浑浊脓性**；
2. **WBC≥1000×106/L，中性粒细胞**为主；
3. **糖、氯化物明显↓，蛋白明显↑**；
4. 脑脊液涂片、培养可见细菌。
3. 其他：**WBC↑、N↑，PCT>0.5ng/mL**（细菌感染），**血培养、淤点瘀斑涂片（脑膜炎双球菌）**，CT、MRI。
4. 鉴别诊断：

#### 并发症：

| | |
|---|---|
|**硬脑膜下积液**|**最常见**，多见于<1 岁儿童，与①血管通透性↑、②脑膜静脉炎性栓塞→渗出、出血有关**临床表现：**有效治疗、脑脊液好转，但体温不退或**体温下降后再升高，或一般状况好转后又出现**意识障碍、惊厥、前囟隆起或颅内压增高症状应怀疑本并发症（好了又坏）<br><br>诊断：**头颅透光试验、头颅 CT**；确诊依赖于**硬膜下穿刺放液**（诊断+治疗）|
|**脑室管膜炎**|常见于**治疗被延误**的患儿，有效治疗下**发热不退，惊厥、意识障碍不改善，进行性颈项**<br><br>**强直，脑脊液无法正常化**（一直不好），CT 提示**“脑室扩大”**，确诊依赖于**侧脑室穿刺**|
|**SIADH**|炎症刺激垂体→**ADH↑→低钠血症、血渗透压↓**，可加重脑水肿，导致惊厥、意识障碍|
|**脑积水**|可引起**交通性脑积水**（脑脊液流出通道堵塞）**、非交通性脑积水**（脑脊液重吸收障碍） **临床表现：**患儿烦躁不安、嗜睡、呕吐、惊厥，头颅进行性增大、颅缝分离、前囟饱满、<br><br>头颅破瓮音、头皮静脉扩张，晚期大脑皮质进行性萎缩→**进行性智力、神经功能减退**|
|**神经功能障碍**|部分出现**神经性耳聋**，其他有智力障碍、脑性瘫痪、癫痫、视力障碍、行为异常等|

1. **治疗：**
1. **一般治疗：**密切监测生命体征，控制惊厥发作，维持水、电解质、渗透压、酸碱平衡。
2. **抗生素治疗：**首选药物为**三代头孢**（头孢曲松、头孢噻肟、头孢他啶）

| | | | | |
|---|---|---|---|---|
|**早期新生儿**|**氨苄西林+三代头孢**||**肺炎链球菌**|按未确定病原体用药，除非青霉素敏感|
|**晚期新生儿、>1 月**|**万古霉素+三代头孢**|**脑膜炎球菌**|首选**青霉素**，耐药者选择**三代头孢**|
|**颅脑基础疾病因素**|万古霉素+三代头孢|**B 族链球菌**|**青霉素、氨苄西林**，耐药者联用**美罗培南**|
|**颅底骨折**|万古霉素+三代头孢|**G-肠道菌**|**氨苄西林+头孢类**|

- - 1. 抗生素疗程：**脑膜炎双球菌 7 天；肺链、流感嗜血杆菌 10~14 天；金葡菌、G-杆菌≥21 天**。

1. **肾上腺皮质激素**的应用：抑制炎症反应，减轻脑水肿、颅内压增高。一般使用地塞米松 2~3 天。
2. 并发症治疗：

| | |
|---|---|
|**硬膜下积液**|积液量大、引起颅内压增高时**穿刺放液**，放液量**每次、每侧≤15mL**，迁延不愈者**手术引流**|
|**脑室管膜炎**|进行**侧脑室穿刺引流**以缓解症状，选择适宜**抗生素脑室内注入**|
|**脑积水**|**手术治疗**为主|
