# 艾滋病

## 艾滋病

1. **艾滋病/获得性免疫缺陷综合征（AIDS）：**由**人免疫缺陷病毒（HIV）**引起的慢性传染病。
2. 病原学：HIV 为 **RNA 病毒**，属于**逆转录病毒（retrovirus）**。核心包括两条正链 RNA，以及病毒复制所需的酶，核心蛋白 **P24**、P6、P9；包膜上有 **gp120（结合 CD4）、gp41**。HIV 主要感染 **CD4+ T 细胞**。
1. 分为 **HIV-1 型**（主要）、HIV-2 型。 b) 变异性强，其中 **_env_ 基因**变异率最高。
3. 流行病学：
1. 传染源：**HIV 感染者和艾滋病患者**是唯一传染源，无症状的 HIV 抗体阳性患者是重要传染源。
2. 传播途径：**性接触传播（主要）、血液/血制品传播、母婴传播**、医源性传播。
3. 人群易感性：普遍易感。
4. 发病机制：**gp120 与 CD4（第一受体）**结合，然后与 CXCR4/CCR5 等**第二受体**结合。HIV 感染的复制周期包括：**①吸附与穿入；②环化与整合；③转录与翻译；④装配、成熟与出芽**。
1. 主要为 **CD4+ T 细胞**减少、功能障碍，也见**单核-巨噬细胞**功能异常；B 细胞、NK 细胞可有异常。
5. 临床表现：潜伏期 8~9 年。

1. **HIV 相关症状：**持续>1 个月的**发热、盗汗、腹泻、体重减轻** 10%以上，部分表现为**神经精神症状、持续性全身淋巴结肿大**（①除腹股沟外≥2 个部位；②d≥1cm，无压痛、粘连；③持续>3 个月）。
2. 机会性感染、肿瘤：

|**呼吸系统**|肺孢子菌肺炎（PCP）、肺结核（TB、鸟型分枝杆菌）、病毒性/真菌性/复发性细菌性肺炎|
|---|---|
|**CNS**|隐球菌脑膜炎、结核性脑膜炎、弓形虫脑病、病毒性脑膜炎|
|**消化系统**|念珠菌食管炎、CMV 食管炎/肠炎、沙门菌/空肠弯曲菌/孢子虫肠炎|
|**口腔**|鹅口疮、舌毛状白斑、复发性口腔溃疡、牙龈炎|
|**皮肤**|带状疱疹、传染性软疣、尖锐湿疣、真菌性皮炎、甲癣|
|**眼部**|CMV 视网膜脉络膜炎、弓形虫视网膜炎（眼底絮状白斑）|
|**肿瘤**|恶性淋巴瘤、卡波西肉瘤|

1. 实验室检查：**WBC↓**、Hb↓、PLT↓，尿蛋白阳性，转氨酶升高，肾功能异常。
1. 免疫学检查：**CD4+ T 细胞进行性减少，CD4/CD8 比例倒置**。艾滋病期 **CD4+ T 细胞<200μL**。
2. 病毒分离：患者血浆、单核细胞、脑脊液可分离得到。

## 抗体检测：诊断金标准。初筛：ELISA 测定 gp24、gp120 抗体，确诊：Western blot（WB）。

1. **抗原检测：**测定血清 **P24** 抗原。 e) **病毒载量检测：**RT-PCR、核算扩增等。

f) 其他：耐药性检测（基因型检测）、蛋白质芯片（同时检测 HIV、HBV、HCV）。

1. **艾滋病的诊断标准：**①HIV **抗体阳性**；②**CD4+ T 细胞<200μL**，或出现——发热>1 月/腹泻>1 月/体重下降>10%/反复鹅口疮/反复 HSV 或VZV 感染/PCP/反复细菌性肺炎/结核/深部真菌感染/CNS 病变/中青年人痴呆/活动性 CMV 感染/弓形虫脑病/青霉菌感染/反复发作败血症/卡波西肉瘤/淋巴瘤。

## 治疗——高效抗反转录病毒治疗（highly active anti-retroviral therapy，HAART）：

1. 分类：**核苷类反转录酶抑制剂（NRTIs）、非核苷类反转录酶抑制剂（NNRTIs）、蛋白酶抑制剂（PIs）、**融合抑制剂（FIs）、整合酶抑制剂、CCR5 抑制剂。
1. **NRTIs：**齐多夫定（ZDV）/叠氮胸苷（AZT）、拉米夫定（LAM）、阿巴卡韦（ABC）、替诺福韦（TDF）、恩曲他滨（FTC）。
2. **NNRTIs：**奈韦拉平（NVP）、依非韦伦（EFZ）、依曲伟林（ETV）、利匹韦林（RPV）。
3. **PIs：**利托那韦（RTV）、替拉那伟（TPV）、阿扎那韦（ATV）、达茹那伟（DRV）。
4. 整合酶抑制剂：拉替拉伟（RAV）。
2. 治疗方案：**2NRTIs + PIs 或 2NRTIs + NNRTIs（职业暴露预防：TDF+FTC+LPV/r 或 RAL）**。
3. 不良反应：头痛、恶心、呕吐、腹泻。 d) 毒副作用：骨髓抑制、肝肾损害、代谢异常。
